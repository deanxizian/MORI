# 装配、打印与待解决接口

这是结构预研和候选试打模型。以下顺序包含明确的拆卸前提；未选型的紧固、压配和传动接口仍需按真实器件回修。可执行的路径检查记录以 validation.json 为准。

## 装配路径

1. 先试打孔径、嵌件孔和配合间隙小样，记录材料、层高、方向、温度与冷却后尺寸，再修改 params.json。0.3 mm 单边间隙只是起点。
2. 在机外组装内部承重框架。电机从支架轴向滑入；尚需真实电机止挡/固定孔及带张紧机构。电机主体和编码器合计 72 mm，不能在已闭合球壳内假定有轴向插入空间。
3. 从侧面插入独立轮轴与两只轴承；轮胎、轮毂和轮毂盖在外侧安装。轴承轴向保持、轴的键/夹紧、带轮轴套仍待选型。当前独立轴不把轮载直接交给电机输出轴，但其弯曲强度没有核算。
4. 将电池模块及吊杆安装在下部，绑带可解开；托架沿 Y 可调 ±4 mm。主控、驱动和 IMU 位于刚性框架。PCB 支撑孔只是试打孔位，真实 PCB 装配前须替换。
5. 身体上壳从下开口套入内部组件，安装四个框架固定螺钉。顶部承重环支座在内部组装，不能要求 Ø72 mm 支座穿过 Ø63 mm 顶孔。头部轴承与 Ø58.6 mm 转盘可从顶部安装。
6. 头部先在机外打开前后壳，装保护片、遮光环、显示模块、PCB、固定框与连接器。固定框从后方操作；线束通过空心转轴，保留服务弯曲空间。先做绝缘与应力释放，再闭合后壳。
7. 头部预装底部四个螺钉。转盘与轴承保持结构需按真实轴承定型；不能假定最后只靠一根舵机轴吊住头。拆卸头部底部螺钉时须先分离轴承组件，不能隔着承重环使用直柄工具。
8. 最后连接电源保护、充电和稳压模块，整理编码器与电机线，再合身体下壳。完整线束插拔路径、热压嵌件工具和全部螺钉手柄空间没有完成认证。

## 已建接口与仍欠缺的连接

| 接口 | 已建几何 | 尚需确认 |
|---|---|---|
| 身体上下壳 | 0.6 mm 分件缝、四组螺柱/贯通孔/底部沉孔 | 螺钉长度、嵌件尺寸、局部强度、装配定位细节 |
| 头部前后壳 | 0.6 mm 缝、后方工具孔、贯穿套管和前壳螺柱 | 真实 M2.5 等级/长度或替代接口、夹紧力 |
| 头部底座 | 四螺柱、转盘孔、空心承重主轴 | 轴承压配/轴向锁紧、螺钉入口顺序、线束固定 |
| 轮轴 | 每侧两个 Ø6/13×5 轴承包络；独立 Ø6 轮轴 | 实际轴承、隔套、卡簧、键/夹紧、轴弯曲核算 |
| 电机 | 两个 Ø25×60 主体，12 mm 编码器；0.3 mm 支架径向间隙 | 供应商尺寸、安装孔、轴向止挡、扭矩/转速/电流/编码器 |
| 同步带 | 两带轮和带的运动包络 | 带型、齿距、长度、张紧机构、传动比、保护措施 |
| 头部驱动 | 舵机包络、节圆传动、机械限位示意 | 非实际齿形；14:8 传动需约 210° 舵机总行程才能获得头部 ±60°，须选择足够行程的执行器或调整比值 |
| 电池/PCB | 托架、绑带、吊杆和板支架的包络 | 化学体系、2S 是否保留、真实连接器/孔位/绝缘/热管理 |
| 表面孔 | 后方 USB-C 和开关窗口 | 接口型号、固定耳、插拔受力与真实防护设计 |

固定限位块、限位旗片、轮毂、遮光薄片和传动件没有作为已确认的刚性打印件批量输出。尤其轮毂与轮胎目前有 0.3 mm 径向间隙；还没有可靠的胎圈/压紧设计，不能直接驱动实物。

## 候选试打方向

STL 保存装配坐标，导入切片器后须单独摆放、落台；脚本保证导出的是装配帧，不是爆炸坐标。不要因为高 Z 坐标而再缩放模型。检查器已回读每件 STL 的毫米尺寸。

| 部件 | 起始摆放建议 | 重点检查 |
|---|---|---|
| 头部前壳/后壳 | 前后分件平面朝床；必要时翻转后壳 | 螺柱、显示框座及后壳长套管的支撑；保护外球面 |
| 身体上壳 | 赤道分件平面朝床 | 顶孔、框架螺柱悬垂、侧截面与孔口 |
| 身体下壳 | 赤道分件平面朝床，腹部朝上 | 球底桥接与内螺柱，切片器评估支撑；不要切平腹部 |
| 承重框架 | 优先主平台面朝床，柱体向上；按实际切片转向 | 轴承孔、长柱层间强度、支撑可拆除；必要时后续细分框架 |
| 电机安装件 | 轴孔朝上或侧放，比较孔圆度与层向 | Ø25.6 孔、桥接、嵌件局部厚度；负载尚未批准 |
| 转盘/承重环 | 大平面朝床、轴竖直 | 主轴同轴度、轴承座收缩、薄环、孔深 |
| 电池托架/PCB 支架 | 大底面朝床 | 槽孔、绝缘间距、固定带、插拔方向 |
| 轮毂盖 | 外表面朝上，内表面朝床并按需支撑 | 表面平整、隐藏固定孔剩余厚度；仅外观试片 |
| 孔径和间隙小样 | 按正式件相同方向打印，至少覆盖水平/竖直孔 | 不要跨材料/机器套用一次测量值 |

试打小样：Clearance 左→右 Ø2.6/2.8/3.0/3.2/3.4/3.6 mm；Insert 左→右 Ø3.6/3.8/4.0/4.2/4.4 mm；Fit_Slots 对应 6×10 mm 凸块，单边 0.2/0.3/0.4/0.5 mm。模型本轮没有承诺任何卡接结构已定型。

## 后续硬件与实物验证

- 取得三执行器、显示模块、四轮轴承、头轴承、电池、控制/驱动/IMU、电源模块及连接器的实测尺寸图或 STEP，并记录供应商、版本、单位与来源。
- 更新包络、孔距、螺钉/嵌件/轴/卡簧/齿形/带张紧细节，重新生成所有视图、碰撞与 STL 报告。
- 用称重后的部件质量求重心，扫描电池位置，核算轮载、轴弯曲、轴承寿命、螺柱和层间强度；不能从塑料体积推定整机质量。
- 电气确认：电池串数与化学体系、保护/保险、充电路径与 USB-C 输入协商、稳压能力、堵转/峰值电流、连接器和线径。USB-C 只表示接口形状。
- IMU 按模型轴向固定于刚性机身，验证编码器方向和轮控反馈。现有两轮电机承担平衡；没有第四执行器。
- 使用外部测试夹具做静态/控制调试；夹具不属于机器运行时接地支撑。逐步测试平衡、停机保护、跌倒与线束应力，当前不承诺任何实物平衡性能。
