# 项目更新

## 1.3.0-dev.2 — 2026-10-25

正式机器人整体收拢到 `robot/`，与 `test_rig/` 分开。主模型固定名为 `mechanical/mori.blend`，运动源码固定入口 `firmware/motion/controller/`；更新脚本、构建和链接。模型 M1.58、PCB C3 R108P、软件实现 1.2.0-dev.1 及其未闭合状态不变，原生模型/PCB/历史证据字节保留。

## 硬件快照 C3 R108P · 2026-10-25

- 当前驱动板由 R98I 更新为 R108P，未连接项从 45 减至 40，剩余 27 个网络；保留 FAIL / PROTOTYPE / UNVALIDATED。
- 发布完整 KiCad 工程、规则、符号/封装库、候选 BOM、91 个接插件针位、原生检查和 14 张已审查局部图；工程库路径便携化，PCB/原理图原始字节保留。
- 同步 R110 A–J 未采用原因，未用失败候选替换当前 PCB。机械 M1.58、软件和正式 IF-C1-R4 合同保持原版本。
- 独立解压重跑 KiCad 检查，见[实际命令与结果](../hardware/driver/publication/README.md)。没有制造导出或下单。

## 1.3.0-dev.1 · 2026-10-25

- 用成品 UPS、成品 BMI323 和唯一 C3 载板形成当前架构，替代原自制电源/IMU/后接口多板方向。
- 发布已批准的 M1.56–M1.58：UPS 直固、居中主控、后壳上充电下开关，旧 Type-C 板及固定座退出；完整模型仍保留旧载板，等待新板适配。
- 发布 C3 R98I 开发快照和原始检查：45 项未连接、30 个网络，不可制造。独立机械接收检查仍止于 R86B。
- 加入 M1.58 带壳整机图、内部图、质量账目和轮驱走线研究摘要。
- 常用项目目录从原始归档更新到当前主线；移除旧 V1 文档入口，当前软件入口统一到 software/README.md，旧板资料仅作为 CAD 重建参考。
- 保留 test_rig 独立样机项目和原始实测记录；旧 M1.57-A1 视频明确标注不同步，未生成新视频。

`1.3` 表示架构变化，`dev.1` 表示开发快照；没有创建正式发布标签，没有采购或制造放行。成品软件版本仍为 1.2.0-dev.1 基线。
