# 当前产品需求

项目 1.3.0-dev.2 是新模块架构的开发快照，不是对实物性能的承诺。原始用户 [V1.2 规格](../MORI_SPEC_V1_2.md)保留原字节；以下后续明确决定优先于原文中的冲突项。

| 范围 | 已确认方向 |
|---|---|
| 成品主控 | WeAct STM32F412RET6 64Pin V1.1；树莓派只用于独立可行性验证车 |
| 执行器 | S288 ×2；SCS0009 / SC-0090-C001 ×2；恰好四个执行器 |
| 电源 | 微雪 UPS Module 3S；原配圆口充电和电源开关，上充电、下开关；取消自制 USB-C 接口板 |
| IMU | DFRobot BMI323 / SEN0693，板上小插座，无焊接竖直排针 |
| 自制 PCB | 只保留一块驱动/载板 C3；6 V 头部降压集成在板上。主模型中的外置 Buck 尚待退出 |
| 头部 | 微雪 CAM33700 / OV3660 与 LCD35079，摄像头独立视窗；无额外麦克风导管/保护片 |
| 喇叭 | 用户提供 SP3040；导线段 150 mm、已有插头；未标尺寸保留 ASSUMED |
| 结构 | PA12 首轮结构验证，简单连续面、少台阶；结构含义或改法有疑问先确认 |
| 走线 | 厂家压接；CAM 四芯身体端允许装机后入壳。完整长度、固定和带线装配仍待闭合 |
| 充电策略 | 用户取消自动充电禁驱，由用户管理充电/拔线；不把省略项写为 PASS。保留开机/故障禁驱、显式解锁、原配总开关与保护需求 |
| 验证 | 成品无断电站立、自动回正或自动回充承诺；需要独立维护底座。几何检查不等于强度、热、平衡或电池安全验证 |

机械参数只在 `config/geometry.json`，电气契约由硬件任务所有。项目版本号不重写已冻结的模型、PCB、固件和验证记录修订号。
