# R170：INA300 原朝向出口与成组旋转比较，未采用

当前采用入口仍是 **C3 R168G / 20 项未连接**。本研究没有降低规则、修改针表或更新正式发布；20/40 = 50% 只表示剩余未连接数量，不是工程或时间完成率。

原朝向 FAULT 出孔涉及四段原有 S2、BAT 取样和 WHEEL_TX 铜线。它们不是冗余线；拆除后必须全部恢复。B 将试孔移至 `(43.6,7.55)`，消除 A 的一处旧 5 V 参考地损失。C 把限流电阻移到左侧并接回 LIMIT，但轮电源支线围出一个孤立地焊盘。D 拆开该支线后恢复地平面连通，显式回地仍未完成。E 的 B/In3 回地虽然接通，却割裂 3.3 V，不能采用。

F 撤下失败的内层回路；G 将背面终点纠正到原生地孔中心 **`(39.9214,6.4064)`**。先前 `(39.95,6.4)` 是栅格搜索点，不能当作真实孔位。原孔从未移动。独立 GND 与 WHEEL 恢复提案占用同一内层通道，不能直接组合。

旋转方案把 U1701、R1701、C1701、R1706/R1707 与原 R1310 比较稿共同考虑。有限位置筛查依次扩展到 0.125 mm 网格、五个明确标识的非地换层点和旧右侧地引线，得到 500 项保留候选；这只是有限搜索，不是完整可布线结论。候选排序加入 R1701 到实际 GND 引脚的距离，避免只追求 LIMIT 引脚靠近。

H 实际采用的比较姿态是 U1701 背面原位 180°、R1701 背面 `(47.375,9.75)` / 0°、C1701 背面 `(43.25,12.125)` / 270°、R1707 背面 `(51.25,11)` / 270°、R1706 正面 `(47,8.875)` / 270°；R1310 沿用 R169D 正面 `(51.25,14.25)` / 0°。所有原过孔仍未移动。C1701 的 VS/GND 短引线已构建，I 进一步以 1.8 mm 背面短线接回 IN−。

J 恢复七段因假设移动过孔而临时拆掉的原线，5 V 与 UPS 原供电检查恢复。**J 仍为 28 项未连接、8 项其他 DRC、0 图板差异、0 启用 ERC**；155 个地焊盘单组、新旧参考地无新增缺口。ACT_BAT_SWITCHED、WHEEL_VM、3.3 V 原连通以及 RLIMIT 显式回地仍失败；`(46.3,11.85)` 的原 3.3 V 孔及其背面引线违反旋转后的原生禁布区。因此 J 不能替换入口。

十稿均精确保留当前源的 325 个过孔快照。最终局部审查另核对全部 114 个原 R108P 地孔；原入口及 77 个非 PCB 工程成员不变。J 的 2583 项明确差异检查仅在原连通和供电检查失败，不能把其他检查通过理解为接收。六张局部图已实际查看；新段名义本体检查不豁免 J 的保留旧线禁布违规。完整厂家布局、整板风格、热/耦合及实物仍未完成。

再次核对 [TI INA300 数据手册 SBOS613C](https://www.ti.com/lit/ds/symlink/ina300.pdf)第 3、28–30 页：4 是 ENABLE、8 是 GND、9 是 VS；原针位和检查阈值没有改变。去耦应靠近 VS/GND，RLIMIT 需要直接回到实际 GND 引脚；地网连通不能替代该回路要求。

下一步优先联合处理旋转方案的原 3.3 V 孔及 B/F 引线、C1701 供电、IN+、LIMIT 和直接回地；完整恢复功率取样、ENABLE、CT 与 FAULT 主干后再验证。固定 H 布局只得到 IN− 短路径，不能重复相同搜索而把无栅格通路当成无解。原朝向 B 也是未采用比较，不可遗漏四段原信号和 WHEEL 恢复。
