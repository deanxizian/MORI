## 查明的通道问题

R136A 的 0.05 mm 有界网格显示，U1001.8 与 R1003.1 分属不同可达区域；J101.7 与 R1003.2/R1033.2 也分属不同区域。U1001.8 所在区域有大量可用换层位置，并非单个引脚附近没有孔位。移除全线宽参考地覆盖的**诊断筛查**、仍保留原生障碍和新孔保护时，两条路径依然为 `NO_RASTER_CONNECTION`。这不是全局不可布通证明，也没有放宽验收。

后续只读诊断允许以高代价穿过旧细信号线，用于识别必须另行改道的具体对象；这些输出明确为 `INVALID_SOFT_OBSTACLE_PATH`，不能作为布线计划采用：

| 待接路径 | 诊断路径穿过的旧铜 |
|---|---|
| U1001 D3 → R1003.1 | In3 的 IMU_SCL `cb0f5a5a-bf31-4f16-a629-f1bbdea4a478`；HEAD_OE_REQ_N `99ffda08-4d6c-4b54-87aa-cb42922b2241` |
| J101.7 → ADC 共节点 | In3 的 WHEEL_TX `91c294f5-5004-48a4-8527-519fdf7e7e72`；WHEEL_ADC 的相邻两段 `677225f9-4561-4ed5-ad1c-623340290a74`、`6d85e0d6-0810-477b-a9e8-9a0bd595ab7f` |

保留整条诊断 ADC 路径后，IMU_SCL 和 HEAD_OE_REQ_N 的独立改道搜索均未找到路径。只保留局部交叉窗口的研究中，IMU_SCL 得到约 18.334 mm、无新孔的同层绕行提案；HEAD_OE_REQ_N 仍无提案。局部绕开窗口不等于为完整 ADC 路径建立通道，这一提案没有生成或采用为 PCB。

最后将原布局的可达区域加入电阻成组位置筛查：背面 x=8…47 mm、y=17…29.3 mm，0.1 mm 网格、四种方向，保留 courtyard/焊盘/孔约束并列出最多三段可能受影响的旧线。没有找到同时具有 U1001 D3 与 MCU 外向接入点的 R1003 位置；R1033 有九个乐观位置，但没有成组方案。这个筛查尚未模拟新本体对通道的阻断，且限定范围、面别、网格及旧铜状态，不能推广为所有位置均不可行。
