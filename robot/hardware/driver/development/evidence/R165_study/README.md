# R165 联合换层与保护支路恢复

本研究保留十块完成原生检查的候选及三次预检/保存前失败，共 212 份载荷逐字节核对；源数据和本地试验均保留。[汇总](summary.json) · [归档清单](archive_manifest.json) · [还原核对](archive_verification.json)。最终 **M 接收到独立开发入口，22 → 21 项未连接**，不构成工程或制造资格。

- C 修复 R164 缩短分压中间节点后出现的参考地缺口；供电铜宽保持。
- F 的地线穿入固定连接器本体禁区。G 改加地孔，又短接背面 D901/HEAD_BUCK_IN；均未采用。
- H 去掉失败的新地孔，保留 R1031 原向外引线和正面地铜；I 将 UV 孔下移 0.05 mm，消除两处原供电线参考地损失。所有原地孔不动。
- I 的固定通道搜索被两个既有供电孔之间的 OV 换层孔阻隔。约 48 mm、再加三孔的绕行提案未采用；有界搜索结果不代表整板无解。
- J 联合移动原 OV 孔和候选 FAULT 孔，保持 U1501.4 → C1501.1 滤波路径及全部供电、参考地检查，为下方两条信号腾出通道。
- K 接回 UV 输出；M 接回 FAULT。M 原生为 **21 opens / 0 other / 0 parity / 0 enabled ERC**，2807 项计划核对、全部旧连接、50 铜宽、155 地焊盘、63 邻接、新旧参考地和 INA300 回地必要条件通过。

B 和 L 在路线预检中被拒绝，随后构建因无计划失败，没有产生候选 PCB。E 因误要求重建不存在的独立过孔禁区，在保存修改前失败；归档中的 E PCB 是未变的 R159H 源副本。它们不计为完成原生检查的试稿。

M 实际查看了十二张原生几何图，并记录 16 组对侧/内层器件投影的检查边界。完整厂家布局、整板风格、热/耦合与实物仍未验证；六项历史回流提示未关闭。原生板、计划、检查命令、搜索、失败日志及所用辅助代码均可复现，M 图像位于 [接收记录](../R165M/README.md)。

**独立开发稿现为 R165M / 21 项 / 52.5%。正式发布仍 R108P，机械和软件未采用，不可制造。**
