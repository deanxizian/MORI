# R162 故障输出恢复与供电通道研究：未采用

当前采用的独立开发入口仍为 **R159H，22 项未连接**；22/40 = 55% 仅为剩余连接数量比例。R162A–G 全部未采用。正式发布仍为 R108P，机械和软件未同步，工程目标未完成。

R162D 将 R161T 的 U1301 故障输出接回原 FAULT 组，候选从 25 降至 **24 项未连接，另有 4 项悬空铜违规，0 图板差异，0 启用 ERC**。2730 项精确差异核对仅旧焊盘连接保持失败：HEAD_UV_N、HEAD_UV_ENABLE 和 UV 分压输入仍未恢复。源板所有 50 项供电铜宽检查、155 个地焊盘的一组连通、114 个原地过孔的身份和位置、新旧参考地检查均保持；历史换参考层提示仍为 6 项，INA300 回地必要条件筛查 PASS。

D 的 R1502 中间节点孔移至 `(67.65,25.15)`，同步重布 F/In3 支路和 OV 输入；U1301.6 从本体外侧引至 `(67.45,28.35)`，经 In3 和底部换层接到已有 FAULT。新增铜的同面名义 Fab 重叠为 0。61 项对侧/内层投影仍需逐项审查；本轮没有完成 D 的外层逐线看图、整板视觉或厂家布局资格，不能从几何筛查推导这些项目通过。

固定 D 的线路后，两路 UV 的有界搜索均未找到路径。E 改用原生规则已允许的 In2 来布 FAULT，虽保持 24/4 的原生结果，却使 MOTION_3V3 的 0.40 和 0.48 mm 通道回归各丢失 182 对原锚点连接。F 只删除末端竖线，两个失败均保留，说明问题不能仅归因于该竖线。E/F 均不可采用；没有降低宽度、间距或扩大 In2 白名单。

从原生填铜提取了一条约 17.744 mm 的中心线，其周围 0.48 mm 宽铜完整包含在源 In2 供电铜内。将它作为额外布线避让条件后，局部 In3 跨越仍未找到路径；这只代表已执行范围内的搜索结果。G 另在 `(54.3,33.9)` 给已有 FAULT 组设置短接入端，供电和参考地筛查保持，但尚未与 U1301 接通，为 25 项未连接、6 项悬空铜违规。

原生禁布区不能通过增加换层孔绕过：查询的 `(59.1,29.5)`、`(59.3,30.7)` 均碰到 J702 的既有禁孔区。现有 HEAD_VM 孔 `(58.6,28.6)` 相邻线路宽 0.20 mm；如继续调整，必须成组重布完整支路并重新验证，不能把其网络直接换成 FAULT，或假设整个 HEAD_VM 功率回路只有 0.20 mm。

使能偏置组的固定铜摆放搜索未找到两只电阻的可用组合。允许把非地铜冲突列为待处理项后，得到 2046 组名义组合，但当前首项碰到最近已验证的 UPS 取样孔和三段 UPS 铜线。它只是诊断候选，不能因排序靠前而采用；应比较更大的关联器件组，并明确需要移动的非地铜。

下一步联合恢复两路 UV 和使能连接，同时保留 FAULT、供电与回流。D 的已接通结果和 G 的另一接入端分别保留，不能混写为同一已通过版本。恢复旧连接后，还需继续当前 22 项清单、六项历史回流提示、完整逐线/逐层审查、功率与保护、BOM/针表及机械线束交接。
