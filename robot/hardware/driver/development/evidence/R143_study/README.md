# R143：ADC / CLR / 供电联合布局研究，未采用

有效开发入口仍是 **R142，29 项未连接**。本目录的所有 PCB 都是独立试验，不能替换原生入口、发布制造文件或提高工程资格。R108P 仍为已发布版本；机械和软件没有采用这些改动。

## 已得到的具体证据

- U1001 D2 的原始出线被邻近过孔的参考面避空限制。联合移动 U303/C303、复用原 CLR 孔并恢复 CLR 后，可以接出 D2。U303/C303 的焊盘距离在试验中为 1.976 mm，满足原有 4 mm 项目筛查值；不是厂家额定值或实测。
- R1022 不能仅按空位或单网可达区域选位置。R143E 的两条独立提案共享了同一走廊；R143F 改为顺序规划，第二条避开第一条及其过孔。全部原生约束继续保留。
- R143G/J 中 D2 和 WHEEL_ADC 两个网络均已连通，但 CAM_BAT_OUT 与 C1403 地连接退化，且 MOTION_3V3 的 0.48 mm 铜宽回归失败。这些连接不能计入有效完成量。
- R143M/O 暂时移除了新增的 WHEEL_ADC 内层线，**CAM 仍被候选过孔割断**。因此不能只调整那条内层线；必须同时解决过孔位置、供电通道及周边器件/走线。O 保留全部原有参考地回归，没有新的参考缺口，仍然不合格。
- U303 移位后，原电流采样线上两处 0.10 mm 偏移在试验中合并为直线；C1403 原曲折地桥仍需成组优化。未宣称整板外观、耦合、热或实物验证通过。

## 工具变更验证

构建器现在支持精确声明的废弃非地过孔删除：必须锁定源 PCB 哈希和完整过孔快照，在明确替换的旧线移除后，过孔最多只接触一层铜，并记录原因。地孔、仍跨层连接的孔、重复/冲突操作、缺少源哈希或不匹配快照均拒绝。原生填铜、原有焊盘连接、铜宽、参考地和独立计划差异核对仍必需。

- 六项拒绝用例通过，源文件哈希保持不变：`verification/R143-via-removal-checks/results.json`。
- G → J 的单项删除通过 2493 项精确差异检查：`verification/R143J-removal-proof/planned-delta.json.gz`。初次目录比较因各候选自己的 `edit_plan.json` / `edit_manifest.json` 不同而 FAIL，原报告保留；复核夹具只省略这两份另行保存的任务记录，全部纳入的原生工程成员逐字节复制并列出哈希。此 PASS 只证明删除操作，不证明 G/J 合格。
- 对既有 R142 接收计划的兼容复核通过 2623 项检查：`reports/R143-backwards-R142-review.json.gz`。

185 份归档载荷均通过哈希及解压逐字节核对。十份试验工程的 77 个原工程非 PCB 成员也已核对；只有已知的 KiCad 项目默认字段规范化，原理图、库和规则内容未变，详见 [成员检查](project_member_verification.json)。仓库、正式机器人和验证车三项完整性检查通过，范围见 [实际命令和输出](repository-checks.json)，不构成硬件资格。

## 后续起点

1. 以 R142 继续计量，以 J/O 作为可重现的失败研究材料。不要重复把 x=41 mm 附近的固定 R1022 空位视作可布通结论。
2. 联合比较 ADC、C1403/R1405 再生保护支路与 CAM 电源局部布局。C1403 的 B 面地岛被信号和器件阻隔；本轮 B 面 0.30 mm 地线搜索及岛内地孔筛查未找到通过方案，不是全局不可布的证明。
3. `(21.8,16.5)`、`(22.45,15.85)`、`(22.5,15.9)` 的 ADC 孔均有实际供电退化证据。后两个位置还涉及 F 面 C701 的 UPS_5V 馈线，不能忽略对侧铜线。O 已把该馈线整理为保留 0.50 mm 的直线 T 接，但没有解决 CAM 和地岛问题。
4. 只有原有连接、全部供电铜宽、155 地焊盘、原生 DRC/图板一致性、参考地和局部逐线审查均满足接收条件后，才可更新有效开发入口。完成全部剩余连接、六项历史回流提示、整板审查和工程/实物待办仍是原目标。

`boards/*.kicad_pcb.gz` 是原字节可恢复的失败研究快照；配套工程版本以 R142 原生工程及 `construction/` 记录为准。解压只应用于新的独立研究目录。没有制造导出、硬件连接、烧录或电机操作。
