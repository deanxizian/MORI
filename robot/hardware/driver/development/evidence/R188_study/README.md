# R188：比较器输入、采样换层及直接回地的三稿比较

从 R187F 构建 A/B/C，仅接收 **R188C**。三稿都保留全部原连接、50 项供电铜宽及 155 地焊盘单组；A/B 原生间距和新增参考缺口失败，不能采用。全轮未消除额外未连接项。

| 候选 | 未连接 | 其他 DRC | 图板差异 | 启用 ERC | 结论 |
|---|---:|---:|---:|---|---|
| A | 19 | 13 | 0 | NOT_RERUN | 地孔与 In2 控制线相交，采样孔间距不足，比较器有新参考缺口 |
| B | 19 | 2 | 0 | NOT_RERUN | 修正孔位后，错误的回地出口仍侵犯 C1002 焊盘间距；新参考缺口保留 |
| C | 19 | 0 | 0 | 0 | 完整局部审查后接收为开发入口 |

A/B 的比较器入口转折过早，在 U1302 CT 孔上方形成约 0.006536 mm² 新缺口，不能因面积小而豁免。B 猜测 x52.6 回地走廊，原生检查显示 C1002.1 间距仅 0.136 mm；源板实际出口是 x52.7。C 恢复真实出口，并在 x51.35 后转到新的比较器长桥，全部原规则不变。

C 的 2524 项明确修改检查、实际地填铜连接、全参考地扫描、局部耦合和十张源／最终图见 [接收记录](../R188C/README.md)。完整扫描减少一项原缺口（76/37 → 75/36 段／网），不代表所有原待审项或六项历史换层提示已经关闭。U1001 的电源针是 pin 14；采样线相邻电源面按实际原生网络审查。

[summary.json](summary.json)保留三稿原生数值；[archive_manifest.json](archive_manifest.json)记录 99 个归档载荷及解压后的源哈希。相同的非 PCB 工程成员按源提交／成员清单恢复，A/B 的非同字节工程文件单独保存；C 的全部 77 个原成员保持。大文件采用无时间戳 gzip，原本地候选未删除。[archive_verification.json](archive_verification.json)确认归档原字节与十张接收图哈希。

空间方面，两只 TVS 邻近过孔直接向上移动会违反 F 面焊盘间距；C 在原 70×35 板框内用联合移孔／改线修复了局部参考地。这个结果既未接通 UPS 等剩余 19 项，也没有证明整板需要扩框。R182 的 70×40 方向仍待回复，不作为已批准方案。
