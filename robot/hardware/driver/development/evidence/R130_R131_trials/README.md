# 未采用的 R130 / R131 比较

所有方案均从 R129D 源板构建，未覆盖开发基线。源哈希、候选哈希和原生计数见 [summary.json](summary.json)，每个子目录保留精确计划、实际填铜命令及原始结果；R130A/B 还保留完整 ERC/回归。完整试验工程和诊断脚本仍在本机 `robot/.state/c3-completion/trials/`。

| 候选 | 未连接 / 其他 DRC | 未采用原因 |
|---|---|---|
| R130A | 33 / 0 | LINK_RX 接通，但割裂 MOTION_3V3，供电铜宽、旧连接和 HEAD_OE 参考地退化。 |
| R130B | 33 / 3 | MOTION 桥接又切断 HEAD_VM，仍有禁布/间距和参考地失败。 |
| R131A | 33 / 4 | R1201 新位置侵犯通孔装配区，存在地热焊盘和丝印违规。 |
| R131B | 33 / 0 | 原位置旋转 90° 后，有界搜索仍未得到有效 ARMED 接线；不据此证明不可布通。 |
| R131C/D | 33 / 13 | 原位置 0°/180° 朝向导致短路、间距、装配区和阻焊违规。 |
| R131E | 33 / 5 | 成组位置靠近 DVDT / HEAD_VM 旧孔，并产生未接地铜岛。 |
| R131F | 33 / 0 | 已消除其他 DRC，但 R1201.1/R1207.1 仍是孤立地组。 |

R131G 在 F 的位置基础上增加局部地桥，单独通过完整回归和图审后才采用，见 [R131G](../R131G/README.md)。原生 DRC 为零或单一网络接通，都不足以接受一个候选；不能以牺牲已有供电或参考地换取更少飞线。
