只检查旧的 50 项供电连接不足以验收新支路。D 的反例因此保留；新增 C909 至主区及原电源孔的独立铜宽检查属于接收条件。解析圆形避空预测也没有捕获 B/E 的实际填铜参考缺口，最终以原生填铜和完整回归为准，没有提高容差。

G 的原功率孔保持 0.80/0.40 mm，移至 `(6.6,17.8)`；新孔为 `(4.55,17.05)` / 0.50/0.30 mm。C909 新位置和旋转、相邻 HEAD_VM 尾段、15.63 mm² 分配补片以及正面 C904 接入须整体保持，不可只抽取降低飞线的部分。原 U1201 输入支路仍为 0.30 mm；源板与 G 的 0.28 mm 筛查均通过，但没有因此获得载流、瞬态或热资格。
