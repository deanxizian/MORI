# R177：全部供电保护与 D302 出线比较，均未采用

采用入口仍为 **R168G / 20 项未连接**，源 PCB SHA-256 `7acdf187325f5eb86d44205b3276f316e08cfdc69ed5ff9e84308f0128fe155e`。原 40 项中剩余数量比例为 50%，不是工程或时间完成率。此次保留 11 块原生比较稿，没有修改板框、固定接口、原理图、规则或阈值。正式发布仍 R108P；机械、软件和实物没有因此获得资格。

## 已得到的证据

- 新规划保护覆盖 10 路供电的全部五档原锚点连通检查，共 50 项。保护几何从原生铜区中提取；七个不适合稀疏路径的区域保守保留原铜区，不把它们算成可用布线空间。最终 11 份几何载荷保存／读回后全部通过原检查器。
- 初版边界分割在重新合并后损失两项检查，已复现并保留。V3 仅在新增保护铜与固定铜接合处保留 1 µm 几何重叠，未放松检查器；删除必需的 3.3 V 保护铜这一反例使五档检查全部失败。见[正反例](raw/R177-supply-reservation-tests.json)和[最终保护数据](raw/R177-supply-reservations-v3/result.json)。
- D302 当前 CLR 引线已经不同于历史 R128G，使用本次实际五段旧铜的 UUID 和坐标重建，没有直接套用旧路径。

## G 的通过范围与未采用原因

D302 为 B 面 `(20.25, 7.5)`／270°。新 CLR 路径约 5.021 mm，FAULT 约 6.265 mm，均在 B 面，不新增过孔。原生 **19 / 0 / 0 / 0**（未连接／其他 DRC／图板差异／启用 ERC）；2516 项明确差异检查、全部旧连接、50 项供电铜宽、155 地焊盘单组、63 项邻接、新旧参考地及 114 原地孔保持。77 个非 PCB 工程成员仍为源字节。

新 CLR 经过对面 L701 和部分实际 SW 铜投影。原板 CLR 已有较小的重叠；本稿使总 CLR 投影从约 0.866 增至 1.882 mm²（L701）、从约 0.019 增至 0.238 mm²（实际 F 面 SW 铜）。新 CLR 全铜宽在 In1／In4 上均没有地铜覆盖缺口，但这不证明磁场耦合、噪声裕量或温升合格。见[局部计算与边界](raw/R177G-coupling-review.json)。

[TI TPS54302 数据表](https://www.ti.com/lit/ds/symlink/tps54302.pdf)第 21 页要求控制 SW 铜及反馈布置／屏蔽；并未规定所有背面 CLR 线均不得经过电感投影。此次避开 L701 是具体比较选择，**没有新增全层禁布规则**。G 保留为数字检查通过、局部设计判断尚未完成的候选，不把投影本身写成原生 DRC 违规，也不把两层地覆盖写成完整耦合资格。

## K 的明确失败

D302 为 B 面 `(5.5, 2.75)`／270°；FAULT 通过新孔 `(5.7, 0.9)` 接入原 In3 主干。两条新线避开 L701，50 项供电及新旧参考地检查保持，2514 项明确差异检查通过。但 B 面 CLR 线使 J102.2 地焊盘四条热连接只剩两条，违反原生 R25，不能采用。

原生 GND 区热间隙为 0.254 mm，B 面区间距为 0.30 mm。以这些实际值保留局部铜后，FAULT 仍有相同提案，CLR 在所查固定布局中没有栅格通路。先前 1 mm 整片邻域保护过于保守，其失败也保留；两种搜索都不能证明全板无解。K 的 D302 名义本体另有约 1.167 mm² 的 MOUNT_H1 投影，安装／针尾空间仍需核对，不能由 DRC 自动推定实物可装。

## 下一步

从 R168G 继续。对 G 做针对实际 CLR 功能、SW 铜、地层及电感的局部耦合／热设计判断；若继续追求避开电感，则联合调整相关可移动器件、旧引线和真实热连接，不重复 J 的不变布局搜索。保留固定针排、安装孔、全部地孔和原规则；必要的板框／固定接口变化须先形成静态对比供用户确认。

全目标仍包含 D302 以外的 19 项未连接，其中包含 INA300 FAULT 端点；不是 19 个独立网络。整板审查、历史六项回流提示、厂家／功率／保护、BOM／针表、机械线束和实物均未关闭。局部空间限制有证据，必须扩板尚未证明。
