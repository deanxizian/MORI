# R163 分压组重排研究，未采用

当前独立开发入口仍为 **R159H / 22 项未连接 / 55%**。本目录保存分压组重排、原生候选、工具正反例及局部视图；没有采用、制造或实物资格。

R163F 将 UV/OV 两组分压链重新成组，R1302 从 B 面移到 F 面，R1503 从 F 面移到 B 面。阻值、焊盘编号和电路网络均不变。UV 输入已接回；R1503 转向后，其 OV 下端经原有底部过孔接入新的 In2 回路，原长 In3 OV 干线退出。R716 转 180° 后直接向外接到 J702.1。原孔、禁布区和 In2 网络白名单未放宽。

F 原生结果为 **23 项未连接、2 项悬空铜违规、0 图板差异、0 启用 ERC**。50 项供电铜宽检查、155 地焊盘单组、114 个原地孔、新旧参考地、历史 6 项回流提示及 INA300 回地必要条件保持。两个旧连接仍未恢复：HEAD_UV_N 输出与 HEAD_UV_ENABLE 偏置支路，因此不能采用。五段 HEAD_VM 取样线由 0.20 加宽至 0.25 mm，下端 B 支路为 0.30 mm；这只恢复原铜宽筛查，不是载流资格。

| 试稿 | 未连接 / 其他 DRC | 结果 |
|---|---:|---|
| A | 未执行原生 DRC | 构建在保存前因 Shapely 原点类型错误退出；原 PCB 副本与错误日志保留。 |

| F | 23 / 2 | 两项均为 UV_N 悬空；仅旧连接保持未通过精确差异检查。 |

换面构建及检查仅允许显式声明的双焊盘 SMD 电阻，检查源面、源角、目标面、原焊盘网络/尺寸和对应禁布区。原生圆角焊盘的整数纳米多边形在镜像后约有 1.13e-6 mm² 离散差异；改用目标姿态的原生定义核对，并独立核对解析变换后的焊盘中心，原几何阈值未降低。原生保存重读、错误网络、错误尺寸、错误禁布层、范围拒绝和 R162D 重放等 **9 项测试通过**。B 的早期检查输出仍保留，不能把其中的镜像离散误报当成最终工具结果。

已实际查看 F 右下区域六层图及 B 初稿背面。新铜没有同面名义 Fab 本体重叠；74 项对侧/内层投影、厂家完整布局、热/耦合、整板和实物检查仍未完成。

继续从 F 的完整计划重建独立候选，恢复 UV_N 与 ENABLE。原 OV In3 干线移除后可重新评估中央通道；右侧 UV 中间节点、H4 原禁布区和 FAULT 路线仍须联合避让。固定铜前面偏置搜索针对旧 R162D，没有找到成组方案，不能将其视为当前全板不可布通证明。当前 R159H 的 UPS 取样方案及全部源地孔继续保护。
