## 用重填铜定位电源分裂

对 C 分别做单因素修改，每次都在独立副本中原生保存、重新填铜、执行 DRC 和源板回归。所有副本都有已知错误，均不是布局候选。

1. **只移除新 UPS 取样孔 `(45.3,8.6)`**：CAM UPS_5V 和 MOTION_3V3 的原供电宽度/连接检查全部恢复；R1001 输入断开。C 原有的 CAM 9＋1 和 3V3 39＋17 焊盘分组由该新孔割裂，不能归咎于仅移动了旧 3V3 孔。
2. 只把旧 3V3 孔放回原位：两路电源分裂仍在，并引入位置冲突。
3. 只把旧 UPS 孔放回原位：两路电源分裂仍在。
4. 在第 1 个副本上再去掉已变为单层接入的 3V3 孔：其余 3V3 锚点的 0、0.20、0.30、0.40、0.48 mm 原宽度关系全部保留，没有丢 3V3 焊盘连接。严格审计损失的每一对都包含被删除孔的 UUID；R1001 输入及其他原生错误仍未解决。

第 4 项是非地孔在电容已改用别处供电后可能冗余的证据，不是删除源孔的批准或完整电气接收。源板未变，地孔未删，现有检查器也未被放宽。后续若推进这条路线，必须从干净源板构造完整电容供电和精确删孔方案，验证所有保留的旧电气作用。

## 回地与搜索边界

C 有 R1701.1 → U1701.8 的显式背面铜路径，[必要路径筛查](raw/R158C-ina300-return.json)为 PASS。局部图仍显示它与大块背面地填铜相连；完整厂家布局、提前接入平面的支路、环路、寄生和耦合审查没有通过。来源仍是 [TI INA300 SBOS613C 第 10.1 节和 VSSOP 图](../R157_study/vendor/ina300.pdf)。源 R156G 的专项 FAIL 保持。

移孔搜索曾预测 `(46.825,10.625)` 与源 In2/In3 填铜都相交，C 原生重填铜却只留下 In3 接入。与源填铜相交只用于提出位置，不能代替新板填铜结果。现有 R13 允许 MOTION_3V3 的 In2 走线；0.50 mm 搜索给出一条约 11.91 mm 的远处路径，但它没有构建或采用，也没有证明不会再割裂其他电源。

保留原铜的 CAM 5V 搜索和 LIMIT 三层搜索均未找到路径，仅为有界结果。LIMIT 横线在旧 `(44.5,10.25)` 5 V 孔附近仍有参考地缺口，不可照搬。第一版 LIMIT 探针在同进程保存/重载时出现 KiCad SWIG 返回类型错误；原日志保留，第二版在新进程读取同一探针后完成搜索，不能把第一次软件错误写成布线无解。

下一步联合考虑 R1001 取样支路、正面 R1702/R1703 位置、S2 旧线和 0.40 mm MOTION_5V 背面干线；先解决取样孔切断电源及 LIMIT 的参考地通道。其他成组布局仍须独立构建，不直接沿用失败 C 或放宽规则。
