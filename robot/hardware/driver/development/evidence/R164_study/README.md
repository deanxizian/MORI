G 接通 UV_N 后，3.3 V 的七个原焊盘与其余 49 个分离，五档供电铜宽检查失败。2802 项计划核对在旧连接、铜宽、新参考铜三项失败；新分压线还有 0.217009 与 0.009823 mm² 参考地缺口。旧线参考地损失为零不能代替新增铜检查。初步读取漏看新增铜面积字段的解释已纠正，完整数值保留。
