# R152：BAT_ADC 接口连通与局部 FAULT / 电源调整

仅 **R152O** 采用到独立开发入口：26 → **25 项未连接**，相对最初 40 项剩 **62.5%**。这不是工程或时间完成率；发布仍 R108P，机械与软件未采用。

先检查已有 Freerouting 2.5.0 / Temurin 25.0.5 的实际交换行为。该构建中 DSN `type route` 会把旧线导入为 USER_FIXED，`type normal` 才可参与改道；`autoroute_settings` 的位置错误会导致载入零器件而流程仍报告结束。修正后实际核对 215 器件、651 焊盘、323 孔、156 网络及锁定状态。SES 的孔名有截断，按输入 padstack 的实际圆形尺寸恢复，不能由名字猜孔径。自动布线器未连接统计与 KiCad 原生统计不同，始终只提取明确差异，从可信 R148E 重建，没有全量 SES 回导。

O 的 2535 项精确计划检查、旧连接、供电、GND、邻接和参考地回归通过；15 张局部图实际查看。[接收说明](../R152O/README.md)记录准确修改范围和限制。BAT_ADC 接口一组已闭合，但 `Net-(U1001-D1_{slash}_BAT_ADC)` 仍两组；FAULT 仍四组，不能宣称完整采样或故障链完成。

HEAD_BUCK_IN In2 补片恢复了两个实际铜颈；只拓宽 FAULT 孔附近区域不足以恢复另一处约 `(41.62,26.95)` 的 0.48 mm 走廊。0.80/0.40 mm 电源孔右移 0.08 mm、0.80 mm 背面尾段及新接地孔必须连同整套方案检查，不可只抄信号线。

新增工具只接受已有正优先级 In2 电源区域的精确连续扩展，不改规则、禁布或填铜/热连接设置。18 项原生正反例通过；`raw/R152-zone-validation/altered-clearance/` 是故意降低间距以验证拒绝行为的测试夹具，绝不是工程候选或允许的规则。既有 R148E 计划在更严格工具下兼容核对通过。

254 份原始载荷已归档，较大文件、板文件和 DSN/SES 使用 gzip；[清单](archive_manifest.json)同时记录存储字节和解压后原始哈希，[复核](archive_verification.json)通过。原生交换文件的行尾空白保持原字节，改用无损压缩封装，[封装记录](exchange_packaging.json)另行复核全部 254 份载荷。完整试验工程、UI 文件及重复运行日志/缓存继续保留在本机 `.state`，未删除。已有原生板、原厂资料、77 个非 PCB 源成员和其他工作树保持。所有有界搜索的无路径结果都不构成全局不可布通证明。
