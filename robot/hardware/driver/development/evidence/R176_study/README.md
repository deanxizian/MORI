# R176：按原生针位重排输入外围，回地与供电仍未闭合

采用入口仍为 **C3 R168G / 20 项未连接**，没有采用本轮 11 块候选。20/40 = 50% 仅为剩余连通数量比例；正式发布仍是 R108P，机械与软件未采用，不可制造。源板及 77 个非 PCB 工程成员保持原字节。

本轮先比较原朝向 INA300 与同面输入电阻，明确退出因移件失效的旧引线。C 已恢复两路短输入和去耦回地，但 LIMIT、供电及限流电阻地未恢复。原生端口诊断显示旧 LIMIT 线围住 FAULT 出口；退出该段后找到的 42.46 mm FAULT 提案在 E 中割裂其他供电，因此拒绝。有限网格搜索的失败或成功都不能替代原生全网检查。

**H 恢复了完整局部输入／LIMIT 回路，但仍不是可采用方案。** R1707 为 B `(43.125,12.25)` / 270°，R1706 为 B `(44.75,15)` / 0°，R1701 为 B `(43.25,9.125)` / 270°；U1701 保留原位置／朝向。155 个地焊盘为单组，63 项邻接通过，原生为 21 opens / 0 other DRC / 0 parity / 0 enabled ERC。新增地线合计 25.593 mm，模拟回路质量尚未资格化；它将原 3.3 V 分配分成 39／17 焊盘两组。H 的 2561 项计划核对仅在原连接和供电失败。

K 使用 11.732 mm、0.30 mm In2 提案，搜索显式保护了候选 GND 线下的参考铜。新旧参考地没有新增损失，但供电失败仍然存在，不能因零普通 DRC 接收。C／H／J／K 均完成启用 ERC 检查，结果为零；精确计划核对分别为 2581／2561／2565／2564 项，各自仍保留真实失败。

这轮也确认了局部空间限制：R1707 左移 0.25 mm 与 C1601 庭院重叠；R1706 在 `(44.5,14.6)` 横放与 U1701 庭院及丝印冲突。原生姿态筛查找到七个 B 面 R1706 位置，选用 `(44.75,15)` 后上述碰撞消失。**这些结果说明当前邻居固定时局部拥挤，不证明必须扩大整板。** 后续应联合较短回地、FAULT 出口、供电分配及必要相邻器件；板框／固定接口变更须先提交具体模型和静态比较供确认。

构建工具修复了微小平移导致一个禁布分区完全落入原固定孔窗口的情况：重用该区域 UUID，保持所有区域身份、原规则、固定窗口和精确并集；没有新增孔窗口或放宽限制。18 项检查、四次原生保存／重读及旧布局重放通过。初版 GND 参考保护包装器替换时机错误、实际未改变搜索，其重复结果按失败工具实验保留；修正版在源代码组装后断言替换一次，再执行实际搜索。

C／H／J／K 的 114 原地孔保持，同面新增名义本体穿线均为零。实际查看了 A 背面、G 背面及 H In3 三张局部原生铜图；对侧／内层耦合、温升、完整厂家布局、全板逐线逐孔和实物验证仍未完成。新孔必须同时保护原信号和候选 GND 线的参考铜；四条局部 0.48 mm 保护带不能代表全部供电连接和铜宽。
