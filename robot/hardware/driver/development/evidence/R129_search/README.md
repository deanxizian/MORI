# R129 搜索和未采用方案

本轮搜索以 R127B（PCB SHA256 `94613985cb2082fb9ea5e7161b04bbdaff1e73eb03f7e06a1c9024b0cb187352`）为源。固定布局的有界网格搜索没有证明任何网络不可布通。

`plan_layered_route.py` 现在可选择 In2.Cu，但仅接受原生 R13 精确白名单中的网络；默认仍为 B/In3/F。R13 规则文件完全未改，解析遇到不识别的表达式会停止。`R13-policy-check.json` 核实 FAULT_N 在 In2 可搜索，BAT_ADC 的可用单元为零。该工具改动不等于新线获得工程资格。

`comparison.json` 汇总实际报告；A/B/C 子目录保留计划、原生命令、DRC 和完整回归。原始 PCB 副本及完整分析脚本/图像仍保留在本机忽略目录 `robot/.state/c3-completion/trials/`；新电脑不能假设这些本地副本已迁移，可按源提交和明确计划重新构建。

`endpoint-access-summary.json` 定位了 U301、U1001、U402 等局部出线区域。`return-diagnostic.json` 是暂不筛选回流地孔距离的诊断，唯一 LINK_RX 提案仍需规划合格地孔、原生填铜、参考/电源回归和图审；它不是可采用布线。R129A 还提示旧过孔切到新参考层同样需要回流检查，不能只筛新增孔。

全部规则、源包和未采用证据保留。33 项连接和六项回流提示仍未关闭；没有制造、EMC、热或实物放行。
