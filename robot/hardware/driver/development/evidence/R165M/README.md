## 联合通道

UV 输出左侧新孔为 `(46.3,29.65)`，Q1301 仅下移 0.05 mm。R1031 保留原正面向外引线，继续通过同一正面地铜接入 `(45.65,30)`、`(47,30)` 两个原地孔。失败 G 稿的新地孔已退出，未沿用其与 D901 输入铜的短路。

U1501 的原 OV 孔从 `(54.4,31.8)` 移到 `(55.9,33.9)`，原 U1501.4 → C1501.1 背面滤波连线保持；新的 FAULT 孔位为 `(54.3,33.9)`。由此在两个原 3.3 V 孔之间腾出有参考地的 In3 通道。

UV 输出 In3 路径约 19.844077 mm，FAULT 恢复路径约 18.257926 mm。FAULT 末端绕开原 3.3 V 孔的参考地缺口，最后约 0.206155 mm 中心线位于已有过孔焊环外轮廓内；直接简化到孔中心的 L 方案因参考地缺口被拒绝，不能替换回来。

[局部数值检查](metrics.json)确认上侧 In3 的原 0.48 mm 供电通道保持，四个原供电孔及下侧 `(54.4,33.05)` 均通过到 `(54.4,31)` 的 0.48 mm 连通筛查。下侧孔在 In3 只有局部铜岛，其供电由原 In2 连续铜区承担，不能称该处 In3 连续供电。铜宽筛查不等于载流或过孔温升合格。
