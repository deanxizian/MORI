# R144：联合布局研究及 R144M 接收边界

本轮实际构建 12 块板。只有 [R144M](../R144M/README.md)采用到独立开发入口；其余候选均未采用。当前仍为 **29 项未连接**，工程 FAIL / PROTOTYPE / UNVALIDATED；已发布版本仍 R108P。

## 改变后续行动的证据

- R144A 从 R143O 出发，将 U1401 OUT 的 In3 整条斜线平行移动 0.075 mm，恢复 CAM 原生 0.25 mm 最小填铜宽度通道。50 项供电铜宽通过，但 C1403 地岛和未完成的 WHEEL_ADC 支路仍在，不能采用。
- B 补回旧 ADC 内层路径后再次切断 CAM；C 改向上绕行仍割断 CAM，并有一处新增参考缺口。必须同时处理实际电源通路，不能将 A 的恢复结论沿用给补线后的板。
- E 的两孔 In2 CAM 绕接接通了 CAM 的零宽连接，但 0.20 mm 铜宽仍失败；HEAD_VM、UPS_5V 铜宽、地连接和参考地也退化。E 的普通 DRC 为 0，仍不得采用。
- D/F/H 比较了 C1403、R1404、C1208 成组位置。H 的 29 opens / 0 other DRC、供电、接地和邻接数字回归通过，但实际滤波连接绕经 F 面旧桥，较原局部路径绕长，视觉／电气路径审查拒绝；欧氏焊盘距离不能代替真实关键路径审查。
- I/J 尝试给该滤波支路建立直接 B 面接入，并另布 OUT。I 的手工过孔位置 `(27.8,22.75)` 侵入 U1402 原生禁布区并碰到 F 面 R902.2；J 去掉该错误孔，原生 30 opens / 0 other DRC，OUT 仍断开。J 的有限原生几何搜索没有获得完整提案，不是全局不可布证明。
- K 固定全部器件，把 C1403 地桥改为三段，原生 DRC 通过，但两段完整线宽进入 OUT 孔的 In4 参考避空，拒绝。L 将 U303 左移 0.20 mm，使四段地桥同时避开焊盘和完整参考缺口。M 进一步利用该移位将上方 ADC 的五段线合并为一条；仅 M 完成独立接收。

## 后续

以 R144M 为新的有效起点；旧 R142 的 ADC 五段线与 C1403 七段地桥已经替换，不要直接套用旧 UUID 删除计划。继续剩余 ACT_CURRENT_FILTERED、D1/D2、BAT_ADC、FAULT、ARMED、供电和接口信号，并处理全板审查及工程待办。后续若重新布 CAM／ADC，须同时保留全部供电铜宽和旧连接，并检查真实滤波／反馈路径；不能只靠直线距离、飞线减少或普通 DRC 0 接收。
