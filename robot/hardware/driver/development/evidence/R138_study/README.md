# R138 近源 ADC 位置与旧线障碍：未采用

开发入口仍是 **R134N / 31 项未连接**。本目录保留一次原生位置比较和只读诊断，没有采用候选，也没有修改正式规则。源文件、原生命令及结果见[字节清单](manifest.json)；完整 R138A 原生副本留在本机 `robot/.state/c3-completion/trials/R138A/`，没有伪称已在本归档提供。

## 原生 R138A

以 R134N 为源，两只电阻均在 B 面：R1003 `(28.6,12.9)` / 270°，R1033 `(21.1,28.6)` / 180°。精确移除原 ADC 公共端、旧 GND 短线，以及待改道的 CLR_N / FAULT_N 各一段；数值、焊盘网络和固定接口不变。

填铜后 **35 项未连接、4 个旧线悬空端、0 图板差异**。相对 R134N，50 项供电铜宽、63 项关键邻接通过，155 个地焊盘仍为一组，旧走线参考地无损失。旧 ADC 公共端、CLR_N、FAULT_N 连接尚未恢复，严格审计仍 FAIL；没有执行完整候选接收或实物验证。

这次明确发现：删除 CLR_N 的 `(27.4,13.8)→(30.2,13.8)` 段会产生 **三个连接组**，不能只按两端补线而漏掉 `D302.2 / R301.1` 分支。

## 已定位的限制

- 同时要求候选两端在“旧布局可达区”内，会把整个上部布局排除。取消这个诊断筛选不等于路线成立；R138A 实际移动和填铜后，D3 在 B 面及三层搜索均未找到完整路径，ADC 公共端也尚未到达 MCU。
- 把每个器件排序后各截取 500 个位置，会让稠密候选区挤掉邻近成组组合。保留前 40 个近源 R1003、全部 2370 个 R1033，再限制两中心距离 6 mm，仍未找到符合本次几何筛选的背面紧邻组合。这是有界位置筛选，不是所有布局不可行的证明。
- `R1033.2→J101.7` 有约 6.14 mm、无新孔的背面提案；CLR_N 三个组之间也有短背面提案。它们尚未组合、填铜和复核，不能计为恢复。
- 允许跨旧细信号线的诊断把近源 D3 出口障碍定位到 **CLR_N**：`c45ec6a2-3688-439a-afd8-51208d74a904`，B 面 `(29.1,6.5125)→(27.5,6.5125)`。这类输出全部标为 `INVALID_SOFT_OBSTACLE_PATH`，不允许直接布成实线。
- 单独移除“保护旧走线参考地”的新孔代理筛选后，D3 约 31.76 mm 的诊断提案会影响 MOTION_3V3、CAM_REG_3V87 和另一段 CLR_N 的旧参考地；ADC 公共端约 34.97 mm 的诊断提案会影响 **U701 BOOT** 走线。原生间距、禁布区、原有地平面覆盖及近地孔筛查仍保留，但这些提案同样是 `INVALID_DIAGNOSTIC`，没有放宽实际验收要求。

## 下一步

先检查 CLR_N 上方横线、右侧竖线及各分支能否联合改道，明确将恢复的所有旧连接；同时比较 ADC 两端的完整路径。不能只删旧线、只接通 D3，或将诊断中临时省略的筛选变成设计豁免。

若使用涉及 U701 BOOT / CAM 稳压输出的过孔位置，必须先按真实电源电路和厂家布局要求准备具体替代路径，重新检查关键环路、实际填铜、全部旧供电及参考地。不能仅因某个候选飞线较少就采用，也不能从这份几何研究推断电源载流、热或 EMC 合格。
