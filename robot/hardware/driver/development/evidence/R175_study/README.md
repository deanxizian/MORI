# R175：保护供电通道后的原生布局比较，全部未采用

采用入口仍为 **C3 R168G / 20 项未连接**，源板和 77 个非 PCB 工程成员保持原字节。20/40 = 50% 只表示剩余未连接数量比例。本轮保存九块独立原生候选，不能据此关闭收尾目标或制造放行。

从已填铜的 R174B 提取四段 0.48 mm 规划保护带：UPS 的 In2 中央／右侧通道、3.3 V 的 In3 上／下通道。每条保护带的完整几何均包含在原生铜中。第一次 UPS 搜索的窗口遗漏 y < 4 mm 的铜区；扩大窗口后得到路径。这是有界搜索范围问题，不是断线或全局无解证据，也不证明载流能力。

**R175A 恢复了 R174 的两处供电回归。** IN− 孔改为 `(46.35,10.325)`，显式 In3 回地绕过 3.3 V 宽铜。原生 UPS 0.48 mm，以及 3.3 V 0.30／0.40／0.48 mm 检查恢复；新旧参考地没有新增缺失。A 仍为 31 opens / 7 dangling / 0 parity / 0 enabled ERC，2637 项明确差异复核仅在原连接和供电两类失败，不能采用。

**R175G 恢复全部 155 个地焊盘连通。** U1302 转至 180°，C1304 转至 0°，原生构建了约 3.677 mm 的电容至监控器显式 B 面回地，以及 VS／SENSE 支路。G 仍为 31 opens / 7 dangling / 0 parity / 0 enabled ERC；2630 项明确差异复核同样只在原连接和供电失败。CT、正输入、供电及受影响旧支路未恢复；短局部回路和填铜连通不等于完整厂家布局资格。

A／G 的 114 个原地孔逐一保持，同面名义本体穿线新增数均为 0；对侧／内层投影分别 9／4 项仍待完整耦合、热与厂家布局审查。实际查看了 A 的 B／F 和 G 的 B 面三张局部原生铜图，未做完整全板视觉或实物资格判定。

固定邻居的正输入电阻位置筛查得到 11 个 F 面位置、无 B 面位置；限流电阻得到 7 个 B 面位置，延时电阻在该轮 4 mm 探索范围内没有位置。它们都是有限网格／固定邻居的结果，不是全部可能布局的证明。A 原生端口诊断明确显示 R1706.2 可达 F 面区域没有通过当轮几何限制的换层点；监控器旧朝向地脚也处于无换层出口的局部区域。

后续应同时筛查**完整器件组、真实出线口和换层位置**。保留本轮实际供电保护带，继续恢复 INA+、CT、ACT／WHEEL／3.3 V、U1702 INA+ 及其他原支路，不能重复不变布局搜索。H 的实际针位和碰撞也说明不能凭旋转直觉推断坐标。是否需要扩大板框仍未证明；若提出板框或固定接口变更，先准备具体原生模型和静态比较供确认。
