# R137 ADC 跨面布局与供电恢复研究：未采用

当前开发入口仍是 **R134N / 31 项未连接**，本目录没有改变 PCB、规则、原理图或工程资格。R137 全部是独立试验，不能作为可制造源。完整本机试验仍保留在 `robot/.state/c3-completion/trials/`；[清单](manifest.json)记录源路径、原字节哈希、归档哈希及未归档原生板的哈希。压缩文件解压后与原文件逐字节一致。

以上候选没有执行完整接收流程；没有用未执行的 ERC、完整计划复核或实物检查补成 PASS。C 的 ADC 公共端及 FAULT 已有拆线，K 相对 C 的检查并不证明相对 R134N 保留了它们。

## 这次证据改变了什么

- 0.10 mm 可达性网格漏掉了窄通道；0.05 mm 网格在下半区找到九个 R1003 背面位置。位置及旧板可达性都只是提案，必须在实际移动器件、填铜后重新检查。
- CAM 断点位于新增 D3 纵线穿过原供电铜区的位置。允许跨旧线的诊断明确标为 `INVALID_SOFT_OBSTACLE_PATH`，从未作为合法布线。
- 原搜索要求换参考面处已有近地孔，不能发现“同时增加合规地孔”的方案。加入地孔后找到约 10.8 mm 的 CAM 路径；孔的位置还必须同时保住其他电源和外层地岛，不能只通过距离筛查。
- 独立恢复路径不能直接组合：I 的三条 3.3 V 路径切断其他供电铜区。J 的保留全部其他电源填铜搜索，对四个 3.3 V 孤立组均未找到路径；这是有限、偏保守搜索，不是不可布通证明。
- K 证明 CAM / 地和参考地可以恢复，但没有解决该长 ADC 路径对 3.3 V 的切割。下一步应比较靠近模拟开关的成组位置，并明确改道受影响旧信号；不能继续把更少飞线或单个局部 PASS 当作采用理由。

## 静态观察的边界

已查看 K 的 [F.Cu](R137K-views/F.Cu.png)、[In3.Cu](R137K-views/In3.Cu.png)、[B.Cu](R137K-views/B.Cu.png) 原生几何诊断图，SVG 原字节压缩保留。这些不是 KiCad 截屏，也不是装配后的实物尺寸模型。

F 面 CAM 横线中心 Y=15.4 mm、宽 0.50 mm，距 L701 名义 Fab 下边只有 0.05 mm。BOM 给出的该轴最大本体尺寸 8.5 mm 会使本体投影与该线重叠约 0.10 mm；**名义 Fab 搜索通过不等于避开厂家最大本体，更不等于实物验证**。本候选没有通过所在面最大本体、热或耦合接收，复用此路径时还必须调整。
