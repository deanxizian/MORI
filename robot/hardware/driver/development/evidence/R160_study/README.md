# R160 检测器与分压滤波组联合布局研究

**全部未采用；当前开发入口仍为 R159H，22 项未连接，剩余数量比例 55%。** 这里的 A/B 是保留旧铜的摆放诊断，不是完成布线的候选。原入口全部原生文件保持原字节。

| 诊断稿 | 未连接 | 其他 DRC | 图板差异 | 结果 |
|---|---:|---:|---:|---|
| R160A | 32 | 76 | 0 | C1303 压到原地孔，旧线与新位置冲突，未采用 |
| R160B | 34 | 51 | 0 | 保持原地孔及网络归属，仍有旧线冲突和热连接不足，未采用 |

两稿都没有器件装配边界重叠违规，但不能据此接收。B 的 14 项短路、6 项间距、4 项孔间距、17 项阻焊桥、7 项悬空线，以及禁布、热连接、丝印问题各一项均保留。J702.2 在背面的原生热连接要求为四条，B 实际只有两条；不降低要求，需结合完整改线后重新填铜检查。ERC 未重跑。

单独移动 U1301 的 4092 个有界姿态没有通过空间筛查。把 C1303、R1303、R1307、R1502 纳入可移动组后，仍固定所有过孔的同范围筛查也没有候选；将非地过孔冲突明确列为待重布工作后得到五个位置。随后对六只无源器件以 0.1 mm 网格筛查，保留全部通过静态筛查的位置域，得到八组相容摆放。B 使用其中一组。八组是提前返回的局部结果，不能称全局最优或已证明可布通。

必须以源 R159H 的网络身份为准：原地孔 `0e3037d9-c29e-4eda-9f7f-a8ef15dfb01e` 位于 `(66.5,26.125)`，A 中被 C1303 正端压住后，原生保存结果将其标为 MOTION_3V3。这属于失败试稿的非计划改网，不能当成可移动的电源孔。B 从 R159H 重新构建，原保留铜对象没有改网；所有原地孔保持。

第一次联合摆放脚本用钻孔外形筛查本体，却用完整焊盘环复核，断言揭示了模型口径不一致。修正版统一使用源地孔完整环形铜；失败脚本和日志保留，没有放宽地孔检查。

下一步需要把 U1301 两个输入、去耦和输出的出线一起规划，再决定摆放；仅按器件距离评分不足。需要联合处理 0.80 mm WHEEL_VM 至 TVS 的支路、U1501 分压/OV 旧线及冲突非地过孔，并恢复所有旧连接、原供电铜宽、参考地和 J702 热连接。若当前局部组无法提供清晰通道，应比较更大范围的器件组，不强行拉长线或放宽规则。

六张局部正背面图已实际查看：A/B 各两张及源板两张；没有声称六层或整板审查通过。77 份原始载荷、两块原生板按存储与还原双哈希检查通过，完整本机试验目录保留。重建使用 R159H 的 77 个未变非 PCB 成员，加上归档板文件及明确保留的工程元数据差异。
