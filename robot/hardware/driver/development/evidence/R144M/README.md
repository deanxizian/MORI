# R144M：U303 局部移位与 ADC／地桥简化

已采用到独立开发入口，**29 项未连接，工程仍 FAIL / PROTOTYPE / UNVALIDATED**。发布仍为 R108P；机械主模型和软件未采用本稿，不可制造。

从 R142 `2a7c04b8430875a0f8f9e4bdde4b789da6b8efb5f84ee991a360f1d5b6d006dd` 构建，R144M 板哈希为 `f783cf5dfad0ff8020aac8906f12dd018287af6a6d548600d4776fb3603225a5`。旧板可从 [原字节压缩副本](source-R142.kicad_pcb.gz) 或 Git 历史恢复。

- U303 仅左移 0.20 mm，角度与面不变；所属原生 BODY 区同步移动。C303 旁路焊盘距离为约 2.558 mm，满足原有 4 mm 项目筛查值，该值不是厂家资格。
- 上方 ACT_CURRENT_ADC 的 5 段线替换为一条 0.20 mm 斜线，消除两处 0.10 mm 偏移；该段中心线长度约 2.498 → 2.440 mm。
- C1403 的 7 段地桥替换为 4 段 0.30 mm 走线，去掉短折返，完整避开 OUT 过孔的参考面避空。中心线约 4.284 → 4.746 mm；略增加的长度用于保留原生间距和完整参考覆盖，没有宣称寄生或 EMC 合格。
- C1403、R1404、R1405 及原有比较器滤波接入路径保持不变。没有新增／移动过孔、修改网络映射、器件值、板框、固定接口或原生规则。12 段旧铜替换为 5 段；全板为 1251 段、322 孔、215 个器件。

## 验证范围

原生全严重级 DRC：29 未连接 / 0 其他违规 / 0 图板差异；启用项 ERC 0。旧连接、50 项供电铜宽、155 个地焊盘、63 项邻接及新旧参考地回归通过，6 项历史参考层切换提示仍未关闭。所有 77 个原工程非 PCB 输入保持原字节；忽略的 `.kicad_prl` 会话状态另列且未删除。

[精确计划核对](planned-delta.json)通过 **2513 项**检查。严格几何审计仍保留预期的 FAIL，明确对应 U303／三个焊盘／所属区域和 12 段旧铜替换；没有把原始 FAIL 覆盖成整板 PASS。

五条新增线的所在面名义 Fab 本体筛查无穿越。三条地线与对侧 R702／C913 投影相交，已经结合正面几何和 In4 连续参考地查看；正面 Buck 铜线与器件不变。耦合、热、瞬态与实物仍 NOT_TESTED，不给对侧投影全局豁免。

实际命令见 [原生复核](commands.json)和[构建记录](construction-commands.json)；[计划](plan.json)、[局部度量](local-metrics.json)、[回归](regression.json)、[视觉审查](visual_review.json)及[剩余连接](remaining_connections.csv)分别保留。归档载荷均经过原字节／解压哈希核对。
