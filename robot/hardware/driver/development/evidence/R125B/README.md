`commands.json` 记录最终原生命令；`edit_plan.json`/`edit_manifest.json` 记录修改；`regression.json` 对比 R108P，`step-regression.json` 对比 R124G。比较脚本保存的是当时实际运行的源码：`compare_placement.py` 要求 `development/native` 为记录的 R124G 源板；`review_placement.py` 要求方案重建到 `.state/c3-completion/trials/R125B`。复现时应在独立工作副本满足这些输入哈希，不能直接拿后续 native 版覆盖旧输入。全部旧试验保留。
