# 通孔焊盘参考避空模型修正

当前原生开发稿仍为 **R127B，33 项未连接**。本次只修正离线布线/检查工具，保存未采用试验；没有再采用 R128 系列 PCB。

J102.7 的外层焊盘为 1.70 mm，圆形镀通孔为 1.02 mm，In4 铜环未闪出。原生填铜的最近地边距孔中心约 0.9105 mm，与孔半径 0.51 mm 加未修改的 R17 约 0.40 mm 相符。旧工具只处理过孔自身避空，把外层焊盘外约 0.0605 mm 的这段固有避空错误当成额外参考地缺口，导致直接从既有针位出线的搜索被阻断。

修正使用参考层实际铜环；对未闪出内层铜环的圆形 PTH 使用真实镀孔几何，不用更大的外层焊盘代替。审计只对与当前走线同网、且实际连接到同一表层铜岛的镀通点扣除其固有避空。SMD、NPTH、未支持的槽孔、其他网络孔和一般平面缺口没有新增豁免。原生规则、禁布区、板框、孔位、当前 native PCB 和原发布工程均未因工具修正改变。

`model_check.json` 六项原生几何核对通过，包含 SMD 和四个 NPTH 的反例。`R127B-regression-replay.json` 相对 R126C 的严格回归仍 PASS；`regression_crosscheck.json` 逐项确认旧供电、旧连接、参考地、关键邻接、几何差异和未连接数等结果未改变。原有报告保留。

初次复查误把两份试验目录中的 edit_plan/edit_manifest 一起比较，原始 FAIL 保留在 `comparison/`；正式复查使用原包相同的 77 个非 PCB 工程成员，不能把输入差异解释成电气检查通过或失败。命令、脚本哈希和输入边界在 `commands.json`。

## 未采用的 R128 试验

- R128A 只给 Q1701 增加短出线和孔，孔仍单层悬空，33 未连接 / 1 警告；没有接入主干，不采用。
- D302 共比较八组姿态。原位 90°/270° 遇 DISARMED 铜线；更低位置遇 U303/U1001/C1403。向下 0.40 mm、90° 的局部姿态可作候选，但并未采用。
- R128C 接通 D302，却切开两组 MOTION_3V3，34 未连接；电源宽度和 U701 FB 参考地退化，不采用。
- 修正 PTH 后可以从 J102.7 直接出线，少一个孔。R128D 仍有一组供电开路及两项间距违规。
- R128E 已到 32 未连接 / 0 其他 DRC，但 0.40/0.48 mm 的 3.3 V 铜宽筛查各丢失 21 对旧连接，另有反馈参考地退化及新线缺口；不采用。
- R128F/G 比较扩大电源桥接、移动新孔和精确替换邻近 CLR 走廊。G 虽为 32 未连接 / 0 其他 DRC，铜宽和旧 CAM_REG_3V87 参考地仍退化，新电源/CLR 线仍有参考缺口；不采用。

各试验的计划、删除对象快照、原生输出、已执行的回归与实际命令在 `rejected_trials/`，汇总在 `rejected_trials.json`；所有原始试验副本仍在忽略的 `.state` 目录。上述数据再次说明未连接数下降或其他 DRC 为零不足以接收方案。

下一步应按实际 0.48 mm 腐蚀后的供电连接区寻找完整宽度的恢复路径，同时联合检查新增孔对 U701 FB、CAM 输出和 CLR 的参考地影响。In2 对 FAULT_N、MOTION_3V3 等网络已有精确白名单；若考虑该层，必须按原生名单、所有层孔壁和换参考层接地审查，不能直接扩大名单。当前通用搜索仍限制 F/B/In3；R128 的单独 In2 供电搜索明确检查了已允许的网络。

复现工具核对时从仓库根目录运行（输出路径必须不存在）：

```sh
robot/.state/c3-completion/venv/bin/python \
  robot/hardware/driver/development/scripts/check_transfer_model.py \
  robot/hardware/driver/development/native/MORI_Interface_C3.kicad_pcb \
  robot/.state/c3-completion/transfer-model-new-check.json
```

局部工具核对和铜几何回归不等于完整回流、电气、热、EMC 或实物资格。工程保持 FAIL / PROTOTYPE / UNVALIDATED，目标继续，不能制造。
