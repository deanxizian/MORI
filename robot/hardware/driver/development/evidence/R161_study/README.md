# R161 联合布局研究：未采用

当前采用的独立开发入口仍为 R159H，22 项未连接；22/40 = 55% 仅为剩余连接数量比例。R161A–T 全部保留为未采用候选，正式发布仍为 R108P，机械和软件未同步。

最后工作稿 R161T 为 **25 项未连接、4 项悬空铜违规、0 图板差异、0 启用 ERC**。2710 项精确差异核对中，失败项为旧焊盘连接保持：FAULT、HEAD_UV_N、HEAD_UV_ENABLE 和 UV 分压输入四处原连接尚未接回，因此不能采用。不是将断开的旧线当作完成项。

本轮完成的候选工作包括 U1301 与输入滤波、分压、去耦的联合摆放，C1301 至实际 U1301.3 的局部连接，以及上游 OV 输入接通。C1301 路径名义中心线约 5.454 mm，经过一次换层；该几何记录不证明滤波性能。J401 地焊盘热连接不足、若干电源铜割裂和参考地缺口都在后续候选中修正，失败原稿未删除。

R161T 保持全部 50 项供电铜宽检查、155 个地焊盘的一组连通、114 个源地过孔的位置和身份，以及旧线和新增铜的参考地检查。历史换参考层提示仍为 6 项，没有新增提示；INA300 回地必要条件筛查 PASS，完整厂家布局资格仍 NOT_TESTED。两处局部六层图和偏置组背面图共 13 张已实际查看；新增走线在自身焊盘之外没有同面名义 Fab 本体重叠。53 项对侧/内层投影候选仍须纳入逐项耦合和热审查，不能用参考地连续推导全部通过。

R160 文本中把 D1803 称为 TVS/SMB 不准确：原生 D1803 是 B340LA-13-F、Diodes_SMA 肖特基回流支路，D1802 才是 SMBJ13CA-13-F、Diodes_SMB TVS。原生器件选择和封装没有改错；本轮工作稿保持两者的原位及原 0.80 mm WHEEL_VM 支路。R160 冻结记录保留，此处追加更正。

下一步接回上述四处原连接。U1301.6 受 R1502 中间节点过孔和正面 R1503 支路共同限制，应联合比较过孔和两面支路；偏置组需要比较靠近实际 ENABLE 源的位置，不采用约 50.86 mm 且割裂供电的搜索绕行。独立搜索提案不能直接合并：R161F 的合并试验已经产生短路和供电回归。
