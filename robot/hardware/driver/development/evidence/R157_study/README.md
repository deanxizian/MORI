本轮三个试稿均未采用。独立开发入口保持 **R156G / 23 项未连接 / 57.5%**，PCB SHA-256 为 `83d86e884816d8d5422775d79624ff3db09793066103cba90c762caa4febc8e7`。该比例仅衡量原 40 项连接缺口；工程仍 FAIL / PROTOTYPE / UNVALIDATED，制造为 false，实物 NOT_TESTED。正式发布仍 R108P，机械和软件未采用这些开发稿。

## 新发现的基线缺口

核对 [TI INA300 数据手册](vendor/ina300.pdf)（SBOS613C，June 2021，印刷页 29–30，第 10.1 节、VSSOP 图 10-2）后，补查 RLIMIT 回地。厂家要求这条连接直接返回器件地端；需要换层时，也不能只让电阻接入地平面。这里实际地端是 **U1701.8**；U1701.6 是 LATCH，其接地不能替代地端回路。

当前 R156G 和 B 的结果相同：完整地网是连通的，但 R1701.1 与 U1701.8 不在同一背面填铜组件中，除去填铜后也没有原生走线／焊盘／孔路径。R156G 原地网连通、邻接和铜宽检查此前没有覆盖这项厂家要求；原冻结结果保持原义，不覆盖或改写旧记录。

新增 [专项检查](../../scripts/audit_ina300_return.py)并接入 [验证入口](../../scripts/verify_trial.py)。输出分别记录整体连通、同面填铜和显式路径。找到显式路径只通过必要条件筛查，仍须人工审查路径长度、提前接入平面的支路、环路、寄生、电气和热/耦合；不会自动授予厂家布局或实物资格。

检查器用三项真实几何对照验证：R156G 与 B 的限流返回均被判为 FAIL，而两块板已有 C1701.2 → U1701.8 去耦地线均被识别；另在独立副本中仅移除 U1701.8 原地线，去耦显式路径随之消失。该反例只是算法控制，不是布局候选，未重填铜或执行原生 DRC。完整 B 验证又确认 22 opens / 0 other / 0 parity / 0 enabled ERC，与专项 FAIL / engineering FAIL 同时记录。

## 搜索与后续方向

固定旧铜、保留实际所在面本体、原生禁布和参考地的搜索，没有找到独立轮取样路径或不增加孔的直接回地路径。另一次 0.05 mm 全部剩余网络搜索覆盖 19 网、28 组：27 次没有栅格连通，1 次达到有界搜索上限，零可用提案。这些结果不证明全板无解，不应重复同一固定布局搜索。

后续从 R156G 联合比较 R1701、U1701 周边及 U1302/R1706 的局部布局和旧铜，先形成到 U1701.8 的短返回，再处理 R1002.1。不能以到 LATCH 的连接、到旧地孔的地桥或放宽现有邻接距离代替回路设计。仍需保住旧电源分配、所有地孔和参考铜，保留完整原生填铜及回归证据。
