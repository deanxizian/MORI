新的生产工具 `scripts/audit_reference_coverage.py` 对全部非 GND 走线检查其映射地层，保留原自身焊盘／已连接换层的明确豁免及 1e-6 mm² 阈值。与 R186 冻结源板 1296 段结果逐段一致，最大面积差为 0；原 R186 独立审计对照亦保留。F 覆盖 1302 段，待审从 81/38 降为 76/37 段／网，不能把计数当作已证实电气故障。

R187F 的[供电规划保护](raw/R187-supply-reservations/result.json)重新计算并通过 50 项原宽度／连接及 50 项序列化读回检查；11 份 WKB，6 处保守原铜区回退。不是生产铜或可布线剩余面积，不替代每个后续试稿的原生填铜和完整回归。旧 R182 数据保留为历史，不能仅换来源哈希使用。
