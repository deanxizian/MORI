# R168 联合出口、回地与 FAULT 研究

从 R165M 开始，最终仅 G 接收到独立开发入口。A 的保存重读失败以及 B–F 未采用结果全部保留；六稿完成原生 DRC/铜层审计，G 另完成 ERC、2566 项明确差异核对和十二张局部图检查。

| 稿 | 原生未连接 / 其他 DRC | 结果 |
|---|---|---|
| A | 未完成检查 | 无引线的已移动 ACT 孔在保存后读回为 GND，构建器拒绝；该错误板保留 |
| B | 21 / 2 | 旧连接、供电和接地恢复；Q1701 禁布/本体及电容参考地问题，FAULT 悬空 |
