# R141 ADC、FAULT 与 CAM 连续性研究

2026-10-27 归档。七块原生试验板和 A/D 两次构建失败记录均保留；没有直接采用任何试验工程。R141I 的明确差异经过独立合并计划，从 R134N 重新构建为 [R142](../R142/README.md)。本记录不是整板、制造或实物验收。

| 试验 | 未连接 / 其他 DRC | 主要结果 |
|---|---|---|
| B | 31 / 2 | 精确移除 FAULT 两个既有孔之间的七段旧背面线；FAULT 与 CAM 尚未恢复 |
| C | 30 / 1 | 两个既有孔间的 In2 路径恢复 FAULT；CAM 仍断开，新增一项换参考层提示 |
| E | 30 / 2 | 移除三段 U1401 OUT 内层旧线后，CAM、50 项供电铜宽及 155 个地焊盘恢复；OUT 本身仍断开 |
| F | 30 / 3 | R903 平移及地孔 `(32.9,28.4)` 引起 courtyard、HEAD_BUCK_IN 铜宽及 ARMED 参考地问题，拒绝 |
| G | 29 / 0 | OUT 下方路径恢复原网；供电、接地、旧连接及参考地通过，仍新增一项 FAULT 换参考层提示 |

| I | 29 / 0 | ARMED 从右侧接入 J101；旧连接、50 项供电铜宽、63 项邻接、155 GND 及新旧参考地回归通过，仅剩原六项历史提示 |

以上图板差异均为零；原生 DRC 全量原始报告保留，不能仅看普通违规数。A 的准备计划不存在，构建记录为 FileNotFound；D 的接地孔搜索无提案，没有生成计划，随后构建也因缺少计划失败。A/D 没有原生候选板，不补写不存在的几何结果。

FAULT 复用原有两孔，没有增加信号过孔。U1401 OUT 的四段 In3 新路径保留其原有两孔，并恢复 CAM 连续性。R903 成组位置/旋转、接地孔的供电切割和 ARMED 入口分别经过失败比较；精确尺寸、UUID、计划、命令及报告在归档载荷中。

`manifest.json` 记录 **88 份载荷**及 **7 块本机原生板的哈希**。大 JSON/log/SVG 用确定性 gzip 无损保存；每份均记录原始/压缩哈希并做解压字节核对。完整试验工程继续留在本机 `robot/.state/c3-completion/trials/`，未包含在此归档中。重放历史脚本须恢复其指定源哈希并使用新的输出目录，不能在已更新的 native 上原样运行。

七块 R141 试验各有 76 个非 PCB 成员保持原字节，`.kicad_pro` 仅有已识别的三类默认值规范化；原试验文件未回写。完整逐成员哈希在 `payload/R141-project-member-review.json.gz`，并同时证明最终 R142 的 77 个非 PCB 原成员全部保持原字节。没有放宽规则、严重级或禁布区。

静态直线化比较仍未关闭所有局部小折线问题。2365 个 FAULT 固定布局简化提案未通过已有物理/参考地筛查，只代表该有界方案族的结果，不证明全局无可优化方案。对侧/内层磁耦合、噪声、热与实物性能仍未验证；剩余布局工作见 R142 和开发目录的 NEXT.md。
