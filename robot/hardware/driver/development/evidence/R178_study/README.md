# R178：D302 换面、朝向与原连接联合比较

源为 R168G，最终仅 [R178L](../R178L/README.md)采用到独立开发入口。十一块完成原生检查的比较板、一次未形成 PCB 的预检拒绝、脚本及真实输出共 433 个负载已按原字节校验保存；源工程、厂家资料与本地试验目录保持。

|---|---:|---|
| A / C | 21 / 0 | 背面 `(4,10.5)` 两种朝向的准备稿 |
| B | 22 / 8 | 独立路径相交，并有未对中过孔；拒绝 |
| D | 21 / 0 | 两条信号接通，但 C909.2、R714.1 被隔成地岛；拒绝 |

I 的规划预检仍有 DVDT 无地覆盖投影，计划没有写出；随后原生构建拒绝缺失计划，没有生成 PCB。此项与已完成的十一块原生稿分开记录。G/H/K/L 的启用项 ERC 均为 0；其余稿没有重跑 ERC，不能统称全部检查通过。

双面筛选包含实际原生朝向、通孔庭院、安装范围、阻焊开窗、丝印、保留铜与 50 项供电保护；可达性只是乐观筛选，不是布通或面积充分证明。坐标和朝向必须作为同一姿态使用。B 的独立路径不能直接组合，J 的无效朝向也不能借用同坐标其他朝向的结论。

翻面构建与独立复核现在仅对原有两焊盘 SMD 电阻及 **D302 / BAT54WS-7-F / C3_Packages:D_SOD-323 / 1=FAULT、2=CLR** 开放。13 项测试覆盖原生保存读回、焊盘网络/尺寸、禁布区所在面、错误来源朝向、缺失理由、固定接口、其他二极管、型号/封装/极性替换及原电阻行为。单独翻面夹具不恢复原引线，因此整体电气结果仍为 FAIL；测试 PASS 仅指应当通过或拒绝的结构条件。v1 结果名称误写来源角度，v2 使用实际来源 0° 重跑通过，两份原始记录都保留。

L 的逐项局部判断见[视觉与叠层审查](../R178L/visual_review.json)。本轮确认局部空间限制并找到无需改板框的 D302 方案，没有证明整板面积充足或不足。固定接口/板框若确需改变，仍先准备具体模型与静态对比。整板工程和实物资格未完成。
