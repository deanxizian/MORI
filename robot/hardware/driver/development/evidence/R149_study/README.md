# R149：电流采样出线、CLR 与滤波器位置研究

**没有采用新 PCB。** 可信入口仍为 R148E，26 项未连接，剩余连通数量比例 65%；发布仍 R108P，工程/实物资格未完成。本轮修正了构建器的坐标转换，并保留三个未采用的出线候选及诊断结果。

## 工具修正与验证

KiCad Python 的 `FromMM(32.3)` 在本环境返回 32299999，而精确目标是 32300000 个原生单位。A 的保存重读检查正确拒绝了这一差异。构建器现在将毫米坐标四舍五入到整数纳米格点，用于过孔、走线端点及器件/区域变换；没有放宽源快照、网络、孔径或保存重读比较。

[9 项原生检查](raw/R149-coordinate-checks/result.json)覆盖新孔、移孔、改网后移孔、走线端点的实际保存重读，以及 8 类无效移动计划的拒绝。旧 R148E 计划重新构建、填铜、DRC/ERC 和 [2528 项精确差异核对](raw/R149-compat-planned-delta.json)通过；重建 PCB 与现行 R148E **字节哈希完全相同**。这验证工具兼容性，不增加硬件资格。

## 未采用候选

| 候选 | 原生结果 | 主要问题 |
| --- | --- | --- |
| A | 构建保存重读被拒绝 | CLR 孔目标 X=32.3 mm 被截断 1 nm；未运行原生 DRC |
| B | 26 opens / 12 other / 0 parity | 顶部 CLR 孔触碰排针禁布区；下方 CLR、ARMED 与 D301 支路冲突；参考地退化 |
| C | 26 opens / 3 other / 0 parity | D301 移动后碰原 ARMED 孔；背面 CLR 斜段进入 D301 禁布区；采样新孔仍只有单层连接；1 段旧参考地及 7 段新线参考地仍有缺口 |

C 的 U1001、D301 各下移 0.15 mm；上方 CLR 孔为 `(31.86,5.75)`，下方 CLR 孔为 `(32.45,14.0)`，新增采样孔为 `(31.05,5.85)`。C 哈希 `0ffc8f0d5b94cedeb6fafae15729c26a978f96585092c3ba06115f29076dd10b`。原有焊盘连接、50 供电铜宽、155 GND 与 63 邻接筛查无退化，但上述失败足以阻止采用。精确参考地缺口在 [定位记录](raw/R149C-reference-gaps.json)。没有把新孔或局部出线计为已接通整个采样链。

## 诊断改变了下一步

- 固定布局与 C 均没有找到合规的完整 `ACT_CURRENT_FILTERED` 路径；有限网格无解不证明无法布通。
- U1001 四朝向和小平移比较已记录。旋转破坏多个旧连接；下移会挤到下方 K/CLR 支路，必须成组修复，不能只移动芯片。
- 上方窄区域没有同时满足两个信号与地接入的滤波器位置。全板前面筛查得到 R1102 的 984 个、C1102 的 1013 个初步位置，但只落在 X=1–20.4、Y=16.3–23.4 mm；最优组合的几何距离代价约 68.62 mm，且新增器件/填铜/完整走线尚未验证，全部未采用。原窄区报告中沿用的 `back_cell_count` 字段实际对应本次层序第一层 F.Cu；宽区报告已明确写为 `front_cell_count`。
- [只读交叉障碍诊断](raw/R149-soft-obstacle-diagnostic/diagnosis.json)保留焊盘、孔、禁布区、电源铜和参考地约束，仅允许搜索穿过细信号线以定位需重设计的对象。它找到约 48.682 mm 的**不合法路径**：穿过 OV 网络的 In3 段 `8bc8d6c2-cfce-4b18-a22d-1c1e34ec824c`，从 `(57.375,18.9)` 到 `(55.75,20.525)`，交叉范围约 X=56.50–57.07、Y=19.20–19.77 mm。该路径不得直接构建或计入通过。
- [OV 完整连接记录](raw/R149-OV-diagnosis.json)确认它已有 In2 段，原 R13 也允许该网络使用 In2；其 C1302/R1306/R1307 组到 U1301.4 本身仍未完成。下一步联合设计采样与 OV 交叉处，比较完整 OV 支路改道/换层，同时修复 C 的本地失败；不是仅删除被穿过的一段旧线。

另外两处本地问题有精确对象：D301 下移触碰的原 ARMED 孔为 `(32.86,15.85)` / `b049d7c8-9984-50be-a63c-ab8f19b37c43`；旧 WHEEL_sense 参考地受影响段为 In3 `(31.3,14.0)→(32.2,14.9)` / `6c51600a-4b78-428f-b7e7-33a6ba033450`。调整相关孔时须同时保住 ARMED、WHEEL_sense、供电和所有层参考地。

布局依据来自 [TI INA180 数据手册](https://www.ti.com/lit/ds/symlink/ina180.pdf) SBOS741H §9.1.3、§9.4.1：输出 RC 滤波、Kelvin 取样和近端供电旁路分别审查；[TI TMUX1511 数据手册](https://www.ti.com/lit/ds/symlink/tmux1511.pdf) SCDS390B §9、§10 的去耦和布线指导亦保留。未改变任何电路值、针脚或源原理图，也未据此声称噪声、热或采样动态已验证。
