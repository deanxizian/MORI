# R145：D1601 布局、参考地与供电通道研究

本轮保留八块原生板 A/B/C/D/E/F/H/I；仅 [R145I](../R145I/README.md)采用到独立开发入口，未连接从 29 降至 28 项。G 是未通过的快捷路径预查，没有生成 PCB。发布仍 R108P，工程仍 FAIL / PROTOTYPE / UNVALIDATED。

## 试验结论

- A 的 D1601 候选位置侵入原 GND 孔，原生保存把该孔归入 EN，出现六项违规；拒绝。几何空位提案不能代替原生填铜和旧铜网络核对。
- B 接通 K 端局部支路，但旧 ARMED 接入尚未恢复；29 未连接、0 普通 DRC，仍不可接收。
- C 的新孔切窄 HEAD_VM 0.48 mm 通道，并使替换 EN 线出现参考缺口。D 尝试移动 C912/C913 并走 In3，出现 13 项违规、CAM 供电损失；电容移位未采用。
- E 以 D301 小幅移位、新 ARMED 孔及 SOURCE 孔右移恢复 HEAD_VM，但 In3 ARMED 路径仍割断 CAM，D301 局部间距也不足。F 继续小幅调整 D301 并撤去 In3 提案，恢复供电及参考地，ARMED 背面连接尚未完成。
- G 的直接捷径碰到固定 J105 通孔／参考面避空，预查拒绝；后续运行器因计划未生成而退出，相关日志保留，没有 G 板。
- H 在背面完成 ARMED 路径，保持真实通孔铜环、参考地及全部供电铜宽；29 → 28，普通 DRC 0。I 将全部明确改动合并为从 R144M 独立构建的计划，并完成精确差异、原生、回归与局部六层图审后接收。

板级结果见 [summary.json](summary.json)。搜索比较过原件朝向、位置和多层路径；有界搜索失败不能当作全板不可布通的证明。最终 C912/C913/R1602 不动，未放宽原生禁布区、供电铜宽或参考地要求。
