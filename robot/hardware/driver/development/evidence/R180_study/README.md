## 局部拥挤的证据与下一步

R 的 DISARMED 焊盘所在可达区域，在 0.05 mm 保守网格上只有 70 个单元，没有合规的新过孔位置；右侧 CLR 绕线、器件本体及原供电孔附近的参考地空洞共同封住出口。Q 尚未恢复 CLR 时，DISARMED 能接近上方通道，但被新 ARMED 横线隔开。S/T 更换出线顺序仍只恢复了部分连接。这些是具体候选的失败，不是连续几何全局不可解证明。

下一步应联合比较 **U301 / C301、CLK 换层、3.3 V 出线与 ARMED / CLR / DISARMED 的拓扑**，先保留多根信号的出口，再完成各段。不要重复固定姿态的独立单网搜索并直接拼接。任何继续使用 R 的 ARMED 正面路径的方案，还须先解决 J102 同面本体投影。需要改变板框或固定机械接口时，应先给出实际候选模型和静态比较供确认。

本轮已按 R179I 实际铜重新生成完整供电规划保护：50 项原生铜宽检查及 50 项序列化往返检查通过，保留 11 个 WKB 文件和七个保守回退区域。它们只约束路径规划，不能代替候选填铜后的电源检查，也不是制造铜层。

U301 的引脚和去耦要求以 [TI SN74LVC1G74 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc1g74.pdf)为依据；4 mm 邻接筛选是项目假设，并非厂家规定的最大去耦距离。对侧/内层耦合、完整去耦回路、热、EMC、时序和整板实物仍未完成资格验证。
