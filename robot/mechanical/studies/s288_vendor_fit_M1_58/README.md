## 复现

在产品工作树运行 `python3 mechanical/studies/s288_vendor_fit_M1_58/run.py`，然后运行同目录 `publish.py`。Blender 5.2.2 LTS / Python 3.13.13 / numpy 2.3.4 / manifold3d 3.5.3；CAD Python 3.12.14 / cadquery-ocp 7.8.1.1.post1。精确命令、时间、返回码和日志 SHA 在 commands.json。

最初两次很薄的负向内边界体积比较未通过，原日志保留；相应曲面的线性细分收紧到 0.0001 mm、角度 0.02 rad 后通过，没有放宽该校验门槛。过宽的三角距离搜索被停止，最终改用有明确含义的 1.6 mm 包围盒距离下界，未冒称精确最小间距。
