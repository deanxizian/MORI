# S288 插头空间、局部线尾与实物线长记录

2026-10-13；基准 M1.58。独立研究，**未应用主模型**。

## 已收到的实物数据

用户确认 S288 原配三芯线的**导线段约 190 mm，不含两端插头**。用户随后补充三根线、单根含绝缘外径约 1 mm，插头几乎全部藏入舵机。长度和线径均为用户约值，仪器和误差未提供；外伸毫米数仍未知，不能填成 0 mm。不是总长、不是插头外伸量，也不是供应商下单裁线长度；不推定每根随货线都相同。

原始记录：[JSON（证据包内）](evidence.zip)。[测量示意](measurement_guide.svg) 区分仍待补的 A 外伸量及已获约值的 B 单根绝缘线外径。

## 来源与方法

- 电机使用上一轮接收的原厂 STEP 网格（原研究引用，未随本次静态快照收录）及已记录的轴线变换；原网格、实体开口限制和机壳形状均保留，未缩放。
- 对比塑壳采用 JST 官方 PH 目录第 3 页的 PHR-3：宽 7.8、厚 4.5、长 6.85、针距 2 mm。PDF（原研究引用，未随本次静态快照收录） · [可读页图](sources/JST_PH_housing_page.png) · [来源收据（证据包内）](evidence.zip)。**只是目录尺寸对比，未识别或选定它为 S288 实际配套插头。**详细 3D 下载要求登记，本次没有提交资料或取得连接器 CAD。
- 插口基准为电机 STEP 插座外包框中心、口外 0.05 mm，未宣称真实触点或导线出口坐标。初轮容量试算为直径 1.5 mm、2 mm 间距的圆管。收到用户补充后，另加直径 1 mm 的独立系列，并保留原系列不混称实物。
- 塑壳外伸试值 1/2/3/4 mm，直线尾段 1/3 mm，弯曲中心半径 2/3/4/5 mm，转弯后直线 10 mm；沿针排转弯时用同心半径，防止三根线在转弯后重合。各截面与四分之一圆各 32 段；管体体积与解析值误差 <0.9%。参数是容量样本，不是实际线径、压接或动态弯折资格。
- 四个插口逐一与完整主模型硬件/打印件及原厂电机实体检查，原简化 S288 排除。未做四口同时装线，也未确定 U03/U04 应使用的物理插口。

新增系列按用户约值采用直径 1 mm，外伸量 0 / 0.5 / 1 mm 为试值，直尾 1 / 3 mm、中心半径 3 / 4 / 5 mm、四个转弯方向；2 mm 针排及出口坐标仍为目录/外包框假设。

## 有限样本结果

| 检查 | 结果与边界 |
| --- | --- |
| 目录最大外包框从插座口直接起始 | 4 口均接触本机插座唇边，名义交叠约 1.147 mm³；横向增加 0.2 mm 后约 3.14 mm³。外包框保守，不能据此判定实际阶梯塑壳不兼容 |
| 外包框完全在口外的偏移位置 | 60 个静态位置中 8 个无交叠；起点外移 0.5 或 1 mm、上下偏移 0.3 mm。未验证这些位置等于真实插到底的位置，或其插入过程 |
| 用户约 1 mm 线径的补充系列 | 288 个样本中 56 个无实体相交，各口 14 个；试值外伸 0 / 0.5 / 1 mm 分别有 24 / 20 / 12 个通过。仍不等于真实插头、端子直出或完整路线通过 |
| 初轮 1.5 mm 三芯容量 | 448 个样本中 4 个无实体相交，各插口 1 个。均为假设外伸 1 mm、直尾 1 mm、中心半径 5 mm，单线实际半径 3/5/7 mm；左电机向机身前方、右电机向后方 |
| 上述局部线尾增加间隙包络 | 每根半径增加 0.1、0.2 mm，8/8 个采样无实体相交；仅限该名义多边形几何 |
| 原模型与交付保护 | 主模型、几何配置、机械契约、电子细模、20 STL、动画源及视频等 26 文件 SHA 不变 |

其余样本相交只说明本次采样形状未通过，不排除其他转弯形式。图中把四口的独立样本放在一起方便定位，**并非实际完整线束或同时装线验证**。没有完整建模 190 mm 导线的余线、固定、应力释放、插拔或带线拆装。实际线束状态 **BLOCKED**，实物验证 **NOT_TESTED**，制造放行 false。

## 复现与记录

在产品工作树根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b mechanical/mori.blend -t 4 --python-exit-code 1 --python mechanical/studies/s288_plug_space_M1_58/check.py
/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --python-exit-code 1 --python mechanical/studies/s288_plug_space_M1_58/render.py
python3 mechanical/studies/s288_plug_space_M1_58/publish.py
```

[commands.json（证据包内）](evidence.zip)保存实际执行命令、退出码及日志 SHA。Blender 5.2.2 LTS / Python 3.13.13 / numpy 2.3.4 / manifold3d 3.5.3。首次独立渲染因未加入项目依赖路径而失败，日志保留为 render_failed_import.log；修正路径后退出码 0。随后因新收到约 1 mm 实物线径而补充了 288 个局部样本，重新生成检查和静态图；旧结果与原 source_fields 保留为 *_before_wire_od 文件。

Poppler 渲染源 PDF 缺 Adobe-Japan1 字体包，失败输出保留 pdf_render.log；最终使用 macOS PDFKit 渲染第 3 页，文字及尺寸已目视核对。截图仅展示目录，未改动源 PDF。

新 Blender 文件 S288_local_space_UNADOPTED.blend（原研究引用，未随本次静态快照收录） 仅含两台原厂电机和局部容量样本，不是完整机器人或最新主模型。工程入口仍是 mechanical/mori.blend。
