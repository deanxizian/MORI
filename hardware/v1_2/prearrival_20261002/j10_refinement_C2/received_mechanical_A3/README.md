# A3 机械补查接收 · 2026-10-02

本目录保留机械任务原始报告、脚本快照和硬件接收校验。接收时核对 A3、正式 16 个工程文件、C2 原生工程/报告及机械主模型 hash；硬件本次没有独立重跑几何仿真，也没有修改板卡、机械文件或已发出的 A3。

| 对象 | 接收结果 | 对下一步的影响 |
|---|---|---|
| D30 / F70 / R50 背面包络 | 无名义实体交叠；向下余量下界分别 1.84 / 1.40 / 3.50 mm | 可以保留局部摆放候选；R50 仍是 2×1×1 mm 的 ASSUMED 分配，热/焊接/公差未验证 |
| JP70 针座 | 无外部零件交叠；与旧正式 PCB 的交叠单独记录 | 旧板未含候选新孔，因此这项检查不能确认新孔尺寸或插装 |
| JP70 操作 | Ø3/5 mm 直进工具分配被 Yaw_Base/Yaw_Bearing 挡住；Ø8 mm 另受 J4/J5 阻挡 | 小工具走廊在装入这两个结构件前才清楚；实际帽、夹持和维护步骤仍需确认，不能宣称整机装好后可操作 |
| TP71 测量 | Ø1/2/3 mm 直进探针分配被 Yaw_Base 挡住 | 仅装桥前的上述走廊无已报告阻挡；真实探针接触与装配后测量尚未验证 |
| J10 裸插头 | 退出 5.35 mm、上提 12 mm 的两段连续箱体扫掠无交叠 | 未包括真实线束、夹持和带线取件 |

JP70 在原生候选中连接 `C5_EN` 与 GND，短接关闭 U70 的交互 5 V 电源；它不是轮/头执行器急停。TP71 是 GND 测试点。尚未因本次工具走廊结果擅自移动这两个接口。

八芯线局部比较均保持 **5 mm 直段、0.3 mm 目标间隙**；障碍物距离代码另留 0.1 mm 采样缓冲。所有声明通过的情景均含 8 根单线和完整 28 对线间检查。转弯角是脚本的局部 Y 参考，不是插座旋转角。

| 线材候选 | 假定线芯距 PCB 顶面 | 八根线同时通过的局部转弯角 |
|---|---:|---|
| Alpha 5853 | 2.4 mm | 无 |
| Alpha 5853 | 3.0 mm | 60°、75°、90°、105° |
| Alpha 6711，未选定 | 1.2 / 1.8 mm | 无 |
| Alpha 6711，未选定 | 2.4 mm | 60°、75°、90°、105° |

**出线高度仍是未知量，上表不能把 2.4 或 3.0 mm 变为实际产品尺寸。** 检查只覆盖首个转弯，未同时加入既有 H01–H03、IMU 及其他线束。完整 H05、绑束/应力释放、带线拆装及实际服务工具仍为 BLOCKED。

当前 C2 仍有 26 处未连接、14 条 DRC 警告；四块正式板的 18 个 PH 成品孔问题仍待修正。以上局部空间结论不会解除电气或制造阻断。
