# MORI 两路执行器降压：国产替代研究

日期：2026-09-26。基线：V1.2-H0.5-P5R6。性质：选型研究，PROTOTYPE / NOT_TESTED。

**有值得验证的国内模块候选，但目前还没有“报价、尺寸、带载能力均闭合”的直接替代件。建议优先验证：9V 用优信 XL4015-60689，6V 用好盈 UBEC3A（86010010）。** 两款的所选国内 SKU 结算价均未核实，因此本报告不声称已经省下多少元，也不把未知费用记成零。

本次只新增这个研究目录；主 BOM、原理图、PCB、共享契约和机械模型未因本研究更换器件。原 Pololu D36V50F9 #4094、D24V22F6 #2859 仍是现有工程参考，并不因此成为建议购买的最终方案。

## 电流与低电量条件

沿用项目 `reports/power_states.csv` 的**假设**：并发峰值轮驱30W、头部12W；这些数值不是实测持续负载。筛选计算见 `screen.py` / `screening.json`。

| 项目 | 轮驱 | 头部 |
|---|---:|---:|
| 按9V/6V换算的峰值电流 | 3.33A | 2.00A |
| 按旧模型隔离二极管后低端电压8.09V/5.21V进行敏感性估算 | 3.71A | 2.30A |
| 在上述低端估算上另加25%筛选余量 | 4.64A | 2.88A |
| 建议考察的电流等级 | 5A级，须核实整板连续与瞬态 | 厂商持续3A，须验证双舵机并发 |

25%是本次选型筛选假设，不是标准条文。旧模型的±4%输出误差和0.2–0.55V隔离二极管压降**不是新模块的已知性能**。电流区间是敏感性分析，不证明电机会保持恒功率，也不证明台架能站稳。后续应以实测负载波形确定持续、峰值和脉冲时长。

3S在10.2V时到9V只有1.2V压差；9.9V时只有0.9V，且这还是未扣除电池至模块的保险、开关、采样电阻和线束压降。XL4015手册首页的0.3V最低压差不能作为60689整板在高温/大电流时的保证。需要在模块输入端实测9.9/10.2/10.8/11.1/12.6V条件，尤其低输入下启动、负载阶跃和限流恢复。

芯片资料为[XL4015 Rev2.0](https://www.xlsemi.com/datasheet/XL4015-EN.pdf)，外置续流二极管的非同步降压拓扑。原厂[221046A01演示板](https://www.xlsemi.com/demo/XL4015-DEMO.pdf)是5V/5A应用，**不是优信60689的制造文件或9V热验证记录**。没有依据把演示板的参数照搬为候选模块实测结果。

## 替换会影响什么

- 电气连接仍采用四端模块方式：电源板送出受保护的3S和GND，模块返回9V或6V及GND；沿用对应支路，绝不并联两模块输出。现有B540C反向隔离、ARM门控、母线电容及制动吸能均保留。未证明模块能吸收电机回灌。
- 两路输出先离线设定并带假负载核对，再接执行器。优信可调电位器需要防误调方案；不猜测反馈电阻值或直接改板。好盈跳帽位置需按实物/手册复核。
- 当前外置接口未依赖模块EN脚。新候选不应被假定与Pololu的EN/PG功能或静态电流相同；需核实总开关、上电、ARM开断和1000µF后级电容浪涌。
- 原9V模块包络约25.4×25.4×9.525mm/7g，原6V约17.8×17.8×8mm/2.3g，来自现有BOM。候选不能直接沿用这些尺寸。UBEC的厂商重量对应增加约8.7或9.2g，但是否含线束的口径仍需核实。
- 好盈至少应先按51×17×8.5mm这一**合并资料的临时分配包络**考虑，再另计插头、磁环、线缆弯曲和固定空间；此数值不是某一实物的已验证外形。优信完整外形未知，不先画“精确”支架。
- 新增固定结构、线束/插头、散热件和运费都应计入节省比较。原模块不一定原位可换，机械适配需另经用户确认。
- 按总负载42W、假设转换效率85%/90%/95%估算，两路转换器自身合计损耗约7.41/4.67/2.21W，**尚未包含外部隔离二极管和开关损耗**。低价模块不能沿用Pololu效率来声称续航不变。
