# P5R6 局部修改验收计划

所有实物项目目前 **NOT_TESTED**。用户现有万用表和限流电源；本计划不把未具备的示波器、可控负载、温度测量设备记为已有。继承 [完整四板/系统计划](../layout_P5R4/test_plan.md) 和 [电源计划](../layout_P5R5/test_plan.md)，以下补本轮关键项。

前提：先取得最终加工/贴装工艺确认；电池、PD/3S模块、RAW保护未定前不得进行整机充电试验。电机和舵机插头断开，维护托架固定，所有驱动默认禁用。各测试通过不授权跳过后续台架顺序。
