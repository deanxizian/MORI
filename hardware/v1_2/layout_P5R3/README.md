## 已修改的电气细节

**R2 的两路采样改为分别从电阻焊盘独立分出。** 正端不再从Q1载流支路取样，负端不再从下游主铜线取样；R3/R4之后的INA180接口不变。为使负端采样与主负载铜真正分开，R2.2至主换层区采用1.0mm短颈，不能继续把该路径称为全程2mm。该短颈中心线约2.713mm，按70µm铜、20°C电阻率假设估算约0.668mΩ，在6.48A场景约4.33mV、28mW；这不是允许持续电流或温升测量。两端子分流电阻仍需电流校准，不能等同四端精密分流器。

**输入电容和反馈下臂改为就近接入内层GND。** 下面的距离来自重新填充后的实际F.Cu铜区：仅统计确实接在同一铜区的过孔／通孔焊盘，非“附近看到的过孔”。

C76.2和R71.2原有就近连接分别为1.562mm、1.020mm，复核后保留。U60地过孔外径由0.6增至0.8mm，钻孔仍0.3mm；U70原0.8/0.3mm地过孔保留。两路IC与电容仍分别位于不同顶层铜区，**通过连续内层GND返回**，没有伪称已合为同一顶层铜岛。各局部接点均实际接到同一内层地铜区；不增加地平面分割。上述数值是直线距离，不是高频路径求解或环路电感结果。[填铜连接证据](reports/power/ground_returns_evidence.json)。

审查建议的较大范围电容／反馈单元重排曾试验，但引入其它地岛和采样路径问题，已撤回；最终采用现有器件位置下的局部回流修正。反馈地通过独立局部过孔进入连续参考面，没有宣称形成了专用四线Kelvin地或完成噪声签核。输入纹波、负载跃变、反馈稳定性与IC地过孔温升仍需台架验证。

**五个主换层点分别改为4、3、2、3、3颗并联过孔，F/B两面用局部实心铜区连接。** 采用现有并发峰值场景及明确的孔铜假设，计算方法见[功率换层计算](via_budget.md)。在临时副本中同时移除原来的五颗单独换层过孔，重新填铜并运行原生DRC后仍无断线；原工程随后恢复，哈希核对一致。这只证明替代连接存在，不证明实际均流、温升或故障容错额定。[拓扑试验](reports/power/parallel_topology_test.json)。

M5_FB删除一颗冗余的相邻过孔，保留2颗物理过孔；出口合并为明确直段与斜段。网络中心线合计14.547→15.047mm，含新增到焊盘中心的约0.6mm段，**不声称整个网络变短**。C5_FB为9.159mm、0过孔，保持原布局，避免为两路形式一致而重绕。
