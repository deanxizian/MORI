# CAM FPC/FFC 出线方向独立复核

2026-10-06 · `CAM-FPC-EXIT-R1` · 只读资料交接。主机械仍为 M1.49 C5 + K1；本包没有修改 PCB、BOM、引脚、固件、主模型或 CAM-PH-RECON-R1。

**照片支持相机 J2 向 +V / 全局 +Z 出线，以及 CAM 屏幕 L3 向 −U / 全局 −X 出线。后者已有官方接屏实拍佐证，不再只依靠白色/黑色部件位置推断。但这不支持将两个重建连接器整体一起旋转 180°。**

这里的“出线”指排线离开插座的方向，插入运动与之相反；全局方向仅指当前头部机械零姿态，不适用于所有 yaw/pitch 姿态。U/V 是 CAM 主板坐标，不是独立 OV3660 镜头组件的局部坐标。

## 1. 两个方向分别有何证据

|---|---|---|---|
| CAM J2 / CAMERA_FPC_24 | −V → −Z | **+V → +Z，朝 SD 卡** | [OV3660 官方已插线照片](sources/esp32-s3-cam-ov3660-1.jpg)及[官方装机图](sources/ESP32-S3-CAM-OVxxxx-details-5-2.jpg)。橙色 FPC 从黑色盖所在的上缘伸出。照片没有给出实际接触面、插入深度或供货版次。 |

## 2. 为什么不能一起翻转 180°

当前 `waveshare_detail.py` 的通用 `fpc` 用一种形状同时表示两个插座：白色主体位于 +V，黑色窄盖与模拟触点偏 −V；DISPLAY 分支又固定绕 W 轴转 +90°，再仅沿 W 镜像到 IC 面。该分支实际未用 `turn_deg` 的数值驱动任意角度，而是把非零值作为进入固定 +90° 分支的条件。因此也不能只把配置的角度改成 270，就假定模型已旋转到 270°。

- **相机座：**当前白色 +V、黑盖 −V 与实拍相反。绕自身中心转 180°可以作为独立外观候选，使黑盖和候选出线变到 +V；仍不能据此认定内部接触片、焊尾和 1–24 顺序已正确。
- **屏幕座：**当前重建已经是白色 −U（板外）、黑盖 +U（板内），与未插线及已插线照片一致。把整个模型转 180°虽然会把通用模型的候选槽口变到 −U，却会把原本正确的黑白布局反转。应在独立候选中分别定义入口与盖体，不能将“槽口方向”“活动盖位置”“接触片/焊尾方向”当作同一个属性。
- 实拍中相机线从黑盖一侧伸出，屏幕线从白色主体外侧伸出，已经说明通用颜色规则不足。这里没有把外观观察升级成两个插座的厂家机构型号或精确转轴定义。

[V1 原理图](sources/CAM_V1.pdf)给 J2 写明 `0.5-24pin`、后翻盖式、`2.0H`，但没有完整连接器 MPN 或机械图。L3 是 18 针电气符号，没有相应机构说明。[V1.1 原理图](sources/CAM_V11.pdf)同样不能提供完整机构及安装方向。

[官方版本说明](https://docs.waveshare.com/ESP32-S3-CAM-OVxxxx)列出了相机电路等修改，未明确列出 J2/L3 更换料号、旋转或翻盖机构变化。**没有记录不等于两版连接器保证相同。**所查看的实拍不能可靠识别背面版本后缀，因此本次结论是这些官方照片所示硬件的方向证据；不宣称覆盖全部 V1/V1.1 或当前供货批次。

建议机械的独立对比采用“当前”“仅相机转向”“相机转向且 DISPLAY 单独修正入口”的明确方案名。“两者整体翻转”可留作反例，不能因路径碰撞更少就作为正确器件模型。没有在本包应用任何候选，也没有授权更改主模型。

## 3. 逻辑映射与待确认项

**CAM 摄像头端是 J2；CAM 屏幕端是 L3；LCD35079 的外部端是 L1。CAM 原理图自己的 L1 是 24 nH 电感。**不能把同名 L1 或模型 contact index 当成物理针腔编号。

既有 CAM L3 ↔ LCD L1 逻辑表按原文件保存于 [inputs/06_屏幕FFC待核对.csv](inputs/06_屏幕FFC待核对.csv)，没有重新编号或镜像。CAM 的第 10 针 NC 对 LCD TE 不采用同步；16–18 的屏幕端定义仍待核实。此次入口方向证据不解除逻辑表中物理接触面、针序对应及导通的 BLOCKED。

完整缺项见 [missing_fields.csv](missing_fields.csv)，包括：实际 CAM/LCD 版次；三只座的完整 MPN/机械图；插槽 Z 高度和公差、插入深度、接触面及针 1 视图；排线厚度/补强/端头；相机完整 FPC 外形和可弯区；屏幕线准确规格及 16–18 定义；开盖与插拔操作空间；直段、弯曲、固定和拆装；实物逐针导通及通电验证。

照片支持方向是一个字段的证据，不是完整连接器尺寸资格。尺寸沿用的照片估算仍为 ASSUMED；物理插合及运行均 NOT_TESTED，制造仍 BLOCKED。
