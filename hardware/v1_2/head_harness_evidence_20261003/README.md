# 头部线束：厂家证据补充 A7

2026-10-03。继承 P5R7 端口定义和 A2/A4 线束研究；本补充没有修改 GPIO、电路、正式 PCB、机械主模型或打印件。未采购、未发询价，实物均 NOT_TESTED。

本轮逐图核对 CAM 原版与 Rev1.1 原理图、FEETECH A/0 第 4/8 页、JST SH 第 1–3 页及 GH 第 1–3 页。原文件、下载状态、访问时间和 SHA 在 `sources_manifest.json` / `evidence.json`；[逐针定义](head_interface_pinmap_revA.csv) 仅补充已核实电气功能，**不把符号针号当成已确认的实物线端视角**。

## 已核实的接口

| 接口 | 电气定义 | 可确认的连接器信息 | 仍缺 |
|---|---|---|---|
| CAM J11 UART | 1=CAM RX / IO44；2=CAM TX / IO43；3=CAM 本地 3V3；4=GND | 原版图写 SH1.0、4P、卧贴；Rev1.1 电气针序相同 | 座子厂商完整料号、实际 pin1/触点朝向、配套线 SKU 与尾部尺寸 |
| CAM J6 I2C | 1=SCL；2=SDA；3=3V3；4=GND | 与 UART 外观相似的 4P 接口 | 不能将其当成 UART 接入 |
| CAM J5 SPK | 1=PA_OUTL+；2=PA_OUTL− | 图写 GH1.25、2P、立贴 | 正品/兼容厂牌、插合图、线 SKU、出线/锁扣操作空间 |
| CAM Type-C1 | 标准 VBUS/GND；USB D+/D−；CC1、CC2 各 5.1k 下拉 | 经 D3 MBR230LSFT1G 从 VBUS 向 VSYS 供电；VSYS 图注最大 5.5V | 内部供电插头完整型号/包络、CC 处理、线规/压降及弯折数据 |
| CAM J2 摄像头 | 24P 功能表见 CSV；传输为 DVP/SCCB | 原版图写 0.5mm、24P、后翻盖、2.0H | 原配 OV3660 完整 FPC、插座料号及接触面、所有折弯数据 |
| SCS0009 | A/0 p4：1=GND、2=VCC、3=TTL；15cm 尾线 | 写 5264-3P；图示针距 2.5mm、部分侧面尺寸 | 完整配对图与料号、尾线线径/外径、供货三通板、两舵机并发载流及动态弯折 |

H06 保持 **运动 J5.1→CAM J11.1、2→2、3→3、4→4**；板端已定义为 CAM_RX/CAM_TX，不再额外交叉一次。J11.3 只给运动端电平转换器的 CAM 侧参考供电，不能由运动端 3.3V 反向给整块 CAM 供电。正式接线证据是 `hardware/v1_2/wiring_P5R7/03_逐针接线表.csv`。

SPK 是桥接输出，两条线都不是 GND。不要接到旁边电池座 J4：其功能为单节 VBAT/GND，且原版与 Rev1.1 的电池回路有变化。MORI 的 3S 电池不能接 CAM 的该电池座。这里只核实接口，不将旧接线表中的喇叭型号重新批准；当前用户 SP3040 选择和实际负载/音量仍须单独同步验证。

CAM 原版和 Rev1.1 的摄像头外部针序一致，但内部滤波/供电细节不同：Rev1.1 的 AVDD 路增加 R50=5.1Ω，AGND 经 R53，AF_GND 的 R1 标为 NC，原版 R1 为 0Ω。**CAM_D5 对应 GPIO40，PCLK 对应 GPIO41**，两版表一致。软件按具体板版本核对，未在本任务改固件。

来源：[Waveshare 原版原理图](https://files.waveshare.com/wiki/ESP32-S3-CAM-OVxxxx/ESP32-S3-CAM-XXXX-schematic.pdf)、[Rev1.1 原理图](https://files.waveshare.com/wiki/ESP32-S3-CAM-OVxxxx/ESP32-S3-CAM-OVxxxx_Rev1.1.pdf)、[当前官方说明](https://docs.waveshare.com/ESP32-S3-CAM-OVxxxx)。

## 对插候选与出线几何

原理图只写 SH/GH 系列描述，不能因此声称板上装的是某一完整 JST 料号。以下是**目录候选/兼容性待确认**，没有替换厂配线，也没有采购放行。

- UART：JST **SHR-04V-S + SSH-003T-P0.2-H**。4P 塑壳目录宽 5.0、插入轴向长度 5.0、厚 2.8mm；带凸耳的 SHR-04V-S-B 宽 7.0mm，不能与无耳版本混建模。候选卧贴座 SM04B-SRSS-TB 的宽 6.0、深 4.25、高 2.9mm 为目录壳体尺寸，脚端/插合另计。目录侧插总成约长 6.25、高 2.95mm，是参考装配图，**不是 CAM 端实测坐标**。端子支持 AWG32–28、绝缘外径 0.4–0.8mm。此前 Alpha 5853 的 0.889–1.0922mm 外径不能直接压进这个 SH 端子；H06 两端端子不同，不能把 PH 端线材原样套到 CAM 端。
- SPK：JST **GHR-02V-S + SSHL-002T-P0.2**。目录壳体宽 3.75、插入轴向 5.7、厚 4.15mm；匹配顶插座候选 BM02B-GHS-TBT 的宽 5.75、深 4.25、高 4.05mm，脚端另计；目录顶插总成参考高度 7.3mm。端子支持 AWG30–26、绝缘外径 0.76–1.0mm。不要使用 SSHL-003 系列端子代替，该目录明确指出其不适用 GH。
- 目录的 No.1 circuit 视图只对对应 JST 件有效。必须先取得 CAM 实际座料号/顶视和配合面图，再把它映射到板上 pin1；背看线端会镜像，不能根据线色猜左右。插头握持、退锁、拔出、线根直段及弯折都超出裸塑壳包络。

来源：[JST SH 目录](https://www.jst-mfg.com/product/pdf/eng/eSH.pdf)、[JST GH 目录](https://www.jst-mfg.com/product/pdf/eng/eGH.pdf)。上述范围用于压接兼容筛查，不是动态寿命或整机电流批准。

Type-C 供电继续以受控 5V_CAM→CAM VBUS、GND 回流为功能连接。CC 下拉在 CAM 端；具体供电插头/源端 CC 方案尚未选择，不能拿未核验的“两根线 USB-C 头”直接认定可用。也未给 USB 数据线在关节间穿行增加默认要求；需要板级 USB 调试时按维护态操作，不能未经检查并接两个供电源。

## SCS0009 尾线证据不能越过的界限

FEETECH A/0 p4 的表和示意是 1=G、2=V、3=S；p8 的示例控制电路 P2/P5 却画 1=DATA、2=电源、3=GND。这可能涉及端口编号或配合视角，资料没有明确消除差异，不能自行镜像后放行。MORI J9 的 1=GND、2=H_VM(6V)、3=H_BUS 保持；先按功能核对原厂尾线和分线板，再确认一一腔位。

p4 确实提供部分 5264 外形：侧面整体长 8.9mm、深 4.7mm，另有 3.9/3.3/4.2mm 局部尺寸。完整正面总宽、锁扣全包络、实际配套板及线根形状仍未齐全，不能从 2.5mm 针距补算整件宽度后写“厂家确认”。p8 包装照片出现分线板和延长线；照片不证明当前国内 SKU 必然附带它们，也不给安装孔尺寸。

两舵机共用一条总线，但上游电源线要承担两只并发电流，分线接头需要真实固定和拆装路径。两只舵机机身都在 yaw 组时，之间尾线不跨 pitch；机身到 yaw 的三线仍需有限服务环。原厂 15cm 是公布线长，不含一套已确认的测量基准/公差，也不是安装后够长的证明。

来源：[FEETECH SCS0009 A/0](https://www.feetechrc.com/Data/feetechrc/upload/file/20220915/6379883463905538176347522.pdf) p4/p8。本次重复下载遇到 TLS 错误，采用 2026-10-02 已保存且 SHA 匹配的原文件，不伪报本次下载成功。

## OV3660 FPC：查询结果仍未达到选型条件

已检查 Waveshare 官方概览、资源页、使用页、FAQ、两版原理图，并检索该型号的官方加长线/延长方案。公开资料能确认接口功能，却没有找到可核验的原配 FPC 完整长度/独立 SKU、接触面/补强板及折弯限制，也没有找到厂家明确认可 CAM33700 的延长件。**这表示本轮未找到证据，不表示产品绝不存在。**

机械报告的 **58.23mm** 只是当前 CAM 插座与摄像头包络间的名义距离下界，直线路径还有遮挡。模型中 10.5mm 只是照片可见软板段，不能作为完整尾长。不能直接选 60mm、80mm 或任意 24P/0.5mm 排线；同针数/针距不能证明相机供电、针序、接触面、插入厚度及高速信号兼容。

处理顺序：先取得 **CAM33700 随附 OV3660 模组的完整软板图及 SKU**；若实际路径不够，再要求厂家给出同接口长尾模组或明确支持的延长方案。若必须增加中继座/转接板，需要重新审查固定、插拔与信号质量，并先呈现候选，不在当前模型上擅自添加零件。当前这三类方案都未获得采购/制造放行。

[待补字段及供应商问题](supplier_questions_DRAFT_NOT_SENT.md) 已逐项写好；未知数在 JSON 中为 null。没有发给厂家，也没有要求用户凭估计填写。

## 给机械的接收说明

已接收 `HEAD_HARNESS_REQUIREMENTS.md` 及 `loop_source_solids.json` 快照和 SHA。后者的两个有限服务环（CAM供电+SPK、SERVO）在 130 个姿态样本中通过其几何筛查，采用的表面间距 0.3mm/组间下界约0.386mm 都属于该研究的规划分配。报告明确不包含第三条 UART 成功路线，不证明端子接近、固定点、整束长度或动态寿命。本补充没有将它们改称已装配线束。

对机械可交付的是：接口功能、上述目录候选的独立尺寸、确定/未知字段、活动组归属与待测要求。UART/USB/SPK/SCS 的实际线型、端部视角和相机完整 FPC 是当前具体缺口；未知时保留 PLACEHOLDER/ASSUMED，主模型和已经收到的板位不动。

上电前的针序/极性/相邻线短路检查可用现有万用表；首上电用限流电源。DVP 延长、USB 质量、并发供电瞬态及关节循环寿命还需要对应的观测与试验，现阶段一律 NOT_TESTED。
