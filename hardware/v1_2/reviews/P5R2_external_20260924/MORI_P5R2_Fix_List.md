# MORI P5R2 · 给 Codex 的 Layout 整改任务

请基于原始 MORI_motion_P5R2 和 MORI_power_P5R2 工程创建新的审查分支/副本，不覆盖 P5R2。先读取全部源文件与项目规则；不修改电气拓扑、不替换芯片、不移动机械接口/安装孔，除非明确说明必要性并单独确认。下面的坐标单位为 mm，使用 PCB 文件原始坐标。

## 必须先处理

### PWR-01：纠正 R2 的两侧取样
- R2 = 10mΩ，位于 (33,12)。R2.1=(30.0375,12)，R2.2=(35.9625,12)。
- R3.1 目前通过 (26.375,13.905) 的 BAT_REV 载流铜支路取样；R4.1 目前通过 (36.576,13.8176) 的 BAT_MON 载流铜支路取样。
- 将两条采样输入独立从 R2 对应焊盘合适取样位置引出，经 R3/R4 到 U1。不要只缩短 KELVIN_P/N 这两个 0Ω 电阻之后的网络。
- 结合分流电阻建议检查取点，收紧两路采样，避免包含主电流铜阻。
- 验收：分别高亮 BAT_REV、BAT_MON、KELVIN_P、KELVIN_N，导出放大截图，显示采样从分流焊盘独立分出。

### PWR-02：重整 U60/U70 输入高频回路和地
- U60/U70 为 TPS54302。U60 位于(25,26)，U70 位于(25,40)。
- U60 顶层局部地岛目前只经 (23.45,24) 的 0.60/0.30 mm 过孔接入其它层；U70 只经(24,38)的0.80/0.30 mm过孔。
- C61/C71 输入旁路地没有和对应 IC 地形成紧凑的局部回路；大面积地不等于局部返回路径短。
- 参照当前 TPS54302 官方参考布局重排主要输入电容、100nF、芯片地与相应局部走线；两端都应就近、低阻抗返回。
- 反馈下臂参考回到芯片安静地；按同一单元优化 R60/R61/C65 与 R70/R71/C75。
- 保留连续内层 GND，不随意切地。不要只机械“多打几颗孔”，应重新检查实际铜区连接。
- 验收：重新填铜后，展示 F.Cu 局部地与内层接入点，确保电容地不会依赖远处连接器返回。

### PWR-03：校核五个主功率换层点
1. BAT_MON (35.7632,14.6304)，1.00/0.45：R2 后主分配。
2. BAT_MON (30.6324,6.5024)，1.00/0.45：轮部外接降压输入。
3. BAT_MON (32.0040,20.7264)，0.80/0.30：F60 输入。
4. W_VM (58.3184,10.6172)，1.00/0.45：轮部母线。
5. W_VM (61.2648,22.8600)，1.00/0.45：右轮 J8 支路。

以上外径/钻孔单位 mm。没有持续/峰值电流、孔铜、允许温升时，不得宣称电流裕量通过，也不要捏造确定的过孔数量。优先取消不必要换层；需要换层时设置就近同网并联孔与足够连接铜，并记录设计依据。不要把小信号检测支路过孔当成整路负载瓶颈。

## 第二轮优化

- DFM-01：核对两板全局 pad_to_paste_clearance=+0.05 mm。运动板0.5 mm间距DCU封装铜焊盘0.85×0.30 mm，正扩张会扩大锡膏开口；按封装/钢网工艺确认。区分 Paste 与 Mask，不统一盲改为负值。
- MOT-01：保留已存在、靠近源端的R10/R11/R12=33Ω。不要重复加串阻或为“等长”制造蛇形线。优化明显绕行，结合外部IMU线束、时钟和GPIO边沿验证。
- MOT-02：HEAD_BUS约52.90 mm、3过孔，可考虑U2/R2向J3靠近；不能破坏去耦/参考路径。按是否热插拔、可接触及线束长度，评估接口ESD保护。
- 运动板In1为GND，In2为+3V3；参考层转换需考虑本地去耦，不把+3V3当成第二个GND层。
- 复核 BODY_*_OPPOSITE 规则区的必要性，不在没有规则说明时批量删除。
- 同步电源板机械注释：实际80×55 mm，而非旧注释80×45 mm。

## 必须交付的验证结果

提交修改前后差异、实际改变的器件/铜段/过孔清单，以及关键区放大图。使用完整KiCad 10工程重新填铜并运行原生DRC/ERC；保存报告，逐条解释例外。无工具或缺少工程规则时明确标为未执行，禁止声称“DRC通过”。

复核两板接口一一对应：运动J1↔电源J17，运动J2↔电源J13，运动J3↔电源J14，运动J7↔电源J10。不能依外观左右顺序猜测线束针序。

原始审查只包含自定义静态检查，不能替代原生DRC、制造规则、热/信号仿真或实测。无实测时继续保持 PROTOTYPE / NOT_TESTED 标记。
