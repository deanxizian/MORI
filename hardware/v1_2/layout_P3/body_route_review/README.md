# P3 向外出线与器件下穿审查

2026-09-23，用户指出仍有大量线路位于器件下方。**布局偏好验收：FAIL。** 撤回“上一版已满足用户向外出线要求”的判断。既有 ERC/DRC 的零违规结果仍对应已保存的电气 CAD，但不证明布线方式符合要求。

本次为读取原生 PCB 的审查，**未修改铜线或器件摆放，也未宣称下穿问题已修复**。原板和原检查证据保留，供修订前后比较。

## 确认的问题

| 板 | 器件 | 同层穿过其本体区域的网络 | 说明 |
|---|---|---|---|
| 运动 | R19 | IMU_DRDY | 与 R19 引脚无关的线路从本体中间经过。 |
| 运动 | D1 | IMU_MOSI | 与 D1 引脚无关的线路切过本体边角。 |
| 电源 | R2、R3 | REV_GATE | 非本器件网络下穿，其中 R2 为一段较长穿越。 |
| 电源 | L60 | +3V3 | 非电感网络在电感本体下方经过。 |
| 电源 | D10 | W_GATE_LOW | 本体边缘存在非本器件门极控制线。 |

以上来自原生文件中的位号、网络和坐标，并与 Fab 外形核对；不是把地覆铜当成线路，也不是把背面线误看成正面线。

## 漏检原因

1. `layout_P3.py` 的 OUTWARD 约束只覆盖部分 IC，未逐一覆盖阻容、二极管、功率器件及接插件。
2. 部分 IC 区域对 GND、+3V3、CAM_3V3 采用了过宽的例外，没有逐条证明其必要性。
3. 检查重点落在原生电气 DRC，缺少每个器件的出线方向、无关网络穿越、位置/旋转和短折返复核。

**候选数量不是已确认违规数。** 脚本采用原生 Fab 形状的保守外接矩形，排除该器件的焊盘区域，以不大于 0.025 mm 步长筛查走线中心线；多个段可能属于同一条线路。LGA 焊盘向封装外侧的必要引出、连接器焊脚本来位于外壳投影下方等，需要逐项判断，不能直接当成违规，也不能整体豁免。另一铜层投影及 WeAct 堆叠模块投影单独记录。地覆铜不在统计内。
