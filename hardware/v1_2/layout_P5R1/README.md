# MORI 运动板 P5R1：七处圈选修正

本次只修改用户截图中的运动承载板。P5 源文件保留；IMU、电源和后接口三板保持 P5。先打开 [七处同尺度前后对比](index.html)。

| 圈选 | 位号 / 网络 | 实际处理 |
|---|---|---|
| A | U5.1 / ARM_CLK | 引脚改为先向外引出，在上方分支；不再贴着芯片边沿横接。 |
| B | J1/J2/J7 / 5V、FAULT_N、CHG_N | 5V 端点对齐；两条状态线整段重画，去掉短错位和绕 C8 的局部凸起。 |
| C | U3.3 → U2.1 / HEAD_OE_N | 合并 0.0556 mm 错位的竖线，使用同一中心线。 |
| D | U2.5 / HEAD_BUS | 移动过孔，使用一条竖直通道和一次引脚入口转向，删除连续小台阶。 |
| E | U2.8 / C2 去耦供电 | C2 向 U2 移动 0.25 mm；电源先向外走，供电过孔放在明确的转角，地线对齐。旋转方案未采用。 |
| F | U2.3 → U100.A14 / HEAD_RX | 换层点移近 U2，正面直接以 45° 连到 A14，去掉底部横向绕行。 |
| G | J4.3/J4.4 / IMU_SCK、IMU_MOSI | 从通孔端子直接走背面，删除重叠折返、两颗过孔及多余短线。 |

实际铜线总长度由 1222.135 mm 降至 1205.263 mm；过孔由 98 减为 96，线段由 507 减为 488。长度是 KiCad 铜线几何统计，不包含过孔电气长度，不代表时延或 EMC 实测。

KiCad 10.0.6 实际运行 ERC、DRC、未连接与原理图一致性检查，均为 0。检查包含重新填充、全部铜线错误、全部严重度；没有新增 DRC 忽略项。引脚与网络逐针比较相同，板框 70×35×1.6 mm、四层、安装孔与连接器位置不变。只有 C2 向左移动 0.25 mm；几种旋转/组合摆位试验因相邻采样线、焊盘/过孔间距或回流路径冲突未采用。

已复查两面本体投影，不相关网络下穿候选为 0。U100 架高模块投影下的承载电路，以及连接器自身端子引出，仍按 P5 的明确例外记录；不能宣称所有器件投影内无铜。自由直角检查没有新增未处理项，完整47条编辑器策略等价性和用户视觉验收仍不自动标为 PASS。

之前 DRC 未检出圈选问题的原因：同网重叠与错位仍能电气连通，短小偏移也可能满足间距。P5 的外观复核漏掉了它们。本次把圈选截图、网络/线段、原生前后图和规则检查分别记录，避免只用 DRC 作为外观结论。

电路/引脚仍沿用 V1.2-H0.5-P5，原理图标题中的电路版本保持 P5；布线修订为 P5R1，当前硬件共享索引与版本化引脚/线束表已更新。没有改变软件协议或机械模型。机械交接见 [mechanical_P5R1.json](../handoff/mechanical_P5R1.json)。
