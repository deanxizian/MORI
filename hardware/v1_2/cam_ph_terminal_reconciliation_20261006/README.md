# CAM 身体端 PH 端子字段复核

CAM-PH-RECON-R1 · 2026-10-06 · 独立硬件交接说明。

**机械提出的冲突成立。** 当前候选线外径上限 0.6604 mm，小于正式交接 SPH-002T-P0.5S 的 0.8 mm 下限。硬件此前已收到 **Alpha 2841/7＋SPH-004T-P0.5S／SSH-003T-P0.2-H** 的明确研究组合，但从未批准为完整制造选型。这次统一的是记录含义；正式 BOM、原生 PCB、针序和机械主模型均未修改。

机械可读入口：[handoff.json](handoff.json)；目录范围复算：[compatibility.csv](compatibility.csv)；待补字段：[missing_inputs.csv](missing_inputs.csv)。资料核对 **PASS**，组合认可及制造放行 **BLOCKED**，压接、穿线和动态寿命 **NOT_TESTED**。

## 压接工艺资料已有多少

完整数值及来源分开保存在 [process_sources.json](process_sources.json)。30 AWG 的旧指导表（H4009/017-00，2001-01-29）给剥线 2.3 mm、导体高度 0.53±0.05 mm、导体宽 1.00±0.05 mm、绝缘宽 1.20±0.10 mm；绝缘高度明确取决于具体线。旧表自身标明导体高度只是构造/公差相关的指导值，不是 Alpha 专用工艺。

2026-10-03 存档的完整料号查询来自 **test-jst.jst.com**：SPH004 的 30 AWG 行为剥线 1.9–2.5 mm、导体高度 0.50–0.55 mm。两来源拉力栏均为 5 N，但均不足以确定当前线束验收方法。**不能把两个来源拼接成一张工艺卡，也不能把 5 N 当装配牵引力。** 原厂线材最大拉力字段同样不是端子拉脱验收标准。

PH 目录工具行：AP-K2N / MKS-L-10 / APLMK SPH004-05S。旧查询另有 CDS SPH004-05S/CMKS-L 和 YRS-243（AWG28–30）字段，按来源类别保留；供应商实际设备、模具、校准、工艺版次及首件截面/拉力/绝缘夹持尚未知。此次未重新取得生产站当前工艺认可。

## 裸端穿线包络不能从通用图得出

PH 目录第 2 页是**通用未压接端子图**，标注长 5.7 mm、图示横向 2.08 与 1.5 mm。未标它们为任意线材压接后的最大三轴包络；更没有给锁舌突出量、切断残留、毛刺、喇叭口和翘曲公差。因此即使给图示盒子另加 0.31 mm 余量，也不能升级为已包络实际端子的证明。

| 字段 | 本次结论 |
|---|---|
| 压接后完整最大长/宽/厚 | **未知（null）**，不是 5.7×2.08×1.5 mm |
| 锁舌突出、角度、变形限值 | 未取得型号专用数值；保持实际锁止功能，不得压平/修剪来通过路径 |
| 毛刺、料带切断残留、喇叭口、导体突出和偏转 | 通用资料给检查项目，没有本组合数值上限 |
| 保护套/护端后的最大外形和可拆空间 | 未选保护方法，仍未知；后续必须加入实际穿线路径 |
| 局部 PH 穿口 `PASS` | 只继承机械报告限定的名义盒子、方向和局部直线条件；完整穿线 NOT_TESTED |

[JST PH 产品页](https://www.jst-mfg.com/product/index.php?lang=2&series=199)确实列有 SPH004、SPH002、PHR-4 独立二维图，以及 CHM-1-105 / CHM-1-2201 手册入口。浏览工具点击后显示实名资料与邮件发文要求；直接 GET 的三份零件图入口也返回申请页，两次手册 GET 则返回产品栏目页，访问差异见 [记录](sources/web_access_observations.json)。**未提交表单、联系厂家，也未取得这些文件内容**。不能将“目录没有给”写成“原厂根本没有图”，更不能把 HTTP 200 当作已取得图纸。检索其他公开原厂入口未获得当前组合的压接后完整包络。

通用 [JST 压接注意事项第 2–4 页](https://www.jst-mfg.com/precaution/eP-Crimp.pdf)要求按工艺控制两处压接、检查翘曲/扭转/漏压股线和端部外观。现有旧表的绝缘高度尚且未知，不能从导体压接高度推算整体端子厚度。[连接器操作注意事项第 2–4 页](https://www.jst-mfg.com/precaution/eP-Handling.pdf)还要求避免接头受异常拉力和堆压，电测用正确配对接头，避免接点变形，并处理运动振动作用。

## 对离机预装候选的交接要求

本次只接收“CAM 板/线束先在离机 Pitch_Cradle 上固定，身体端 PH 暂不入 PHR-4，穿完再入壳”的**工序候选**。它没有自动替代以前 SH 端暂不入壳的方案，也没有应用 C6、导向或夹持结构。主模型仍按机械来源记录为 M1.49 C5＋K1，本次不重做整机几何验证。

1. 若该工序以后获批，线束图须明确 **BODY/motion J5 端不入壳、PHR-4 单独提供**；CAM 端按已确认的实际插座装配。供应商应在交货前完成压接检验及可实施的电测，用户装壳后仍需逐针复核。
2. 四个自由端逐一标识逻辑针号。临时保护须避免碰伤触点、锁舌和绝缘，不得让胶黏剂污染触点；具体保护件尚未选型，不能假设零厚度。全过程断电。
3. 不拿端子/锁舌作为穿线牵引钩，不强拉或折扁过口；不得靠压平锁舌、磨掉金属、缩模型或扩大未批准的孔来放行。装配允许牵引力仍未知。
4. 保护端及实际出线形态应完成全路径运动/穿线复核；通过后按已确认针腔视图入壳、核查锁止与外观，再使用配对测试接口查导通/短路。不要用万用表粗探针插入母端接触簧片。
5. 逻辑映射继续 **J5→CAM J11：1→1、2→2、3→3、4→4**；第 3 脚为本地 3V3 电平参考，不能给 CAM 主电源。保留既有板面照片证据，不把所有针号重新说成未知；线端插合面与针腔朝向仍需实物/型号资料确认。

供应商按图制作已获用户选择，不再等待制作方式答复。这里列的是后续图纸和验收所需字段，不是授权询价、送样或采购。

## 复核与复现

`prepare.py` 仅首次收存来源和保护基线；勿覆盖运行已有快照。`render_sources.swift` 用 macOS PDFKit 渲染；[visual_review.json](visual_review.json)记录本次实际看过的 12 页。`review.py` 复算外径范围、核对正式 J5/旧候选/工具参考、生成 JSON/CSV，并核对源哈希。`validate.py` 核对交付与链接，生成清单。

实际执行命令及解释器版本在 [results/validation.json](results/validation.json)。本次没有更改电路或 PCB，未重新运行 ERC/DRC，也不以既有 DRC 报告代替压接和穿线验证。正式源保护结果：[results/preservation.json](results/preservation.json)。
