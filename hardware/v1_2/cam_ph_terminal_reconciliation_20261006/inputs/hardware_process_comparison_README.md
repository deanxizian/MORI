## 来源与已解决的范围

两份查询完整标题确为 `SPH-004T-P0.5S` 和 `SSH-003T-P0.2-H`；字段单位由保存的 [Application Tooling Guide 页面](https://test-jst.jst.com/resources/application-tooling-guide/crimp-style/)核对为 mm、AWG、mm、N。因此现在已有完整料号的公开查询参考，无需继续把这项写成“只有系列简称”。查询还分别返回 `APLMK SPH004-05S`、`APLMK SSH/L003-02`；原始字段保留，不由此指定供应商的实际设备。

然而数据主机是 **test-jst.jst.com**。机械记录的生产站同类读取返回 403；本轮 FAQ 直接读取也返回 403，已改用机械保存的成功生产站 HTML 与官方搜索结果核对。没有修改访问控制，也没有宣称生产站当前工艺数据已验证。单条查询没有工艺修订号、批准日期或指定线材；页面元数据日期不当作零件工艺版次。

[JST 生产站 FAQ](https://www.jst.com/resources/faq/)确认 SSH 的 `-H` 为高接触压力版本，旧款与 `-H` 可使用同一套压接工具。这解决的是该后缀的工具兼容关系，不意味着任意线材、绝缘夹持或旧表参数都获批准。查询的 YRS 手工具字段明列 AWG28–30，不能因另有 32 AWG 数据行，就推断这些手工具也适合 32 AWG。
