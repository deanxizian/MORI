# P5R4 板级复核与实测计划

全部实测 **NOT_TESTED**。用户现有万用表、限流电源；没有假定已有示波器、逻辑分析仪、电子负载、温度探头或PD分析仪。以下数值是拟定验收目标/停止阈值，不是已测结果，也不替代器件额定。样件未制造，无温升、ESD、SPI或平衡通过记录。

进行任何通电前，外部模块、额定/极性、RAW源端保护及相应测试项的输入必须先闭合。使用托架/悬空状态，执行器断开或硬件禁用。没有接入成品电池的默认授权流程；本计划只规定经审核的限流板级测试。
