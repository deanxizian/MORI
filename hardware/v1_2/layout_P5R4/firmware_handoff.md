# P5R4 给固件与装配任务的增量

电路版本仍V1.2-H0.5-P5；GPIO、串口协议、执行器计数和连接器针号不变。motion/power为P5R3，rear/IMU为P5R4。本任务没有修改正式固件。

- ICM-42688-P U1.9已硬接GND，用作禁用FSYNC输入。不得配置为推挽INT2输出。U1.4的INT1仍为DRDY；不要依据库的默认引脚配置跳过寄存器核对。
- 板顶视图轴：+X向右、+Y向上、+Z出元件面。丝印与厂商传感器图一致；板安装于机身底面时，固件必须应用实际机械变换。旋转矩阵在机械拥有者确认安装姿态前保持BLOCKED，不能随手设为单位阵。
- WHO_AM_I、SPI模式、最大时钟、上电等待、复位和数据就绪按DS-000347配置；先以低速检查，再用最终线束提高到项目采样目标。保留错误/溢出计数、传感器时间戳与本机接收时间，不让错误样本继续参与平衡输出。
- rear J3是四芯分叉线束：1/2到power J19.1/2，3/4到motion J8.1/2。SW1承载信号，不承载电机电流。开关断开、拔线、插充电器后不得自动重新ARM；再次闭合也仍需显式本机解锁。
- rear J2.5是F1前原始VBUS，目标是F1开路时仍能禁止自由移动。检测线源端故障限流尚未设计完成；此项BLOCKED不能被固件消除，也不能将J2.5并到主输入J2.1。

实测日志模板见`test_records.csv`；目前所有条目NOT_TESTED。万用表和限流电源可开始断电/低功率检查，无法证明SPI瞬态、ESD或温升。
