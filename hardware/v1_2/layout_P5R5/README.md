## 降压回路与反馈

U60由(25,26)移至(27,26)mm，U70由(25,40)移至(26.25,40)mm。相应输入陶瓷、bootstrap电容及反馈组重新摆放和旋转，电感位置不变。芯片VIN与输入电容正端有明确顶层连接；芯片GND与100nF／两颗主输入电容负端也有明确顶层连接，不再各自仅依赖远处地层回路。另给C64负端补了直连地过孔，避免改线后输出电容地铜成为孤岛。

检查方法：在内存副本移除铺铜、所有过孔和非F.Cu铜线，再用KiCad原生连通关系验证每颗电容到IC对应引脚；最终文件重新填铜，额外读取真实填充多边形，含孔洞。**这是几何／连接证据，不是高频阻抗、纹波或温升仿真。**

## 源规则与明确例外

继续使用用户KiCad规则源，47条／44条启用，SHA-256 `5d49d0134ca8c32acc41736591db9e839c347a40a2baa061d32c9ce64a7c25b0`。[原规则快照](pcb-rules-source.json)。

- **R13局部偏离：** 源规则禁止内层走线。本版电源板仅在两个命名的反馈回流区域允许 `/GND` 的In1走线，用于独立安静回流；不是全面开放内层信号，也没有关闭整条检查。精确差异见[scoped_rule_change.json](reports/power/scoped_rule_change.json)。此项不声称完全符合源规则。
- **R14两处例外：** `/M5_EN` 的B.Cu转角(31,28)、(31,29.1)mm，完整0.5mm倒角会进入R60本体投影或违反间距，保留明确FAIL及位置；其余可行的自由转角已处理。保留R24焊盘侧接触，不能为了倒角切断连接。[逐角报告](reports/power/R14_corner_review.json)。
- 本器件引脚／连接器壳体出口，以及运动板架高U100下方承载电路，逐项列在各板`body_review_final.json`。不相关网络本体穿越筛查为0；没有GND／电源 blanket豁免。筛查是几何依据，不等于用户审美偏好全部自动通过。

运动板增加27项原生可见标记；电源板增加62项，并保留必要极性标记。接口号、功能、电压、Pin1/GND和TP60/61/70/71的标记分布在正反面；`G`为GND，`1G`为1脚且接GND。被连接器遮挡的正面长标签放到背面，完整针表仍见[connector_pinmap.csv](connector_pinmap.csv)。DUMP插座明确为 `D/VM`，背面说明`1:DUMP 2:VM`，**D不是GND**。长汇总标签未强塞进拥挤区域，未放置的尝试在`silkscreen_labels.json`透明保留。

## 载流与未闭合边界

保留运动5V的0.5A持续／0.75A峰值、交互5V的1.5A持续／2A峰值**设计目标**，不能当作已测额定。新模型包含R2.2的1mm×2.713mm短颈、70µm外层铜、1.6mm孔长、15/20/25µm孔铜和20/80°C温度假设。6.48A峰值场景在80°C／15µm假设下，短颈加四孔理想并联约7.95mV、51.5mW；原5mV分配只针对孔筒，不能覆盖短颈。

新SW主通道每路两颗1.0/0.45mm过孔是**串行换层**。交互2A峰值再加假定0.5A半纹波的保守DC场景，两孔约8.04mV、20.1mW；没有以外径增长替代孔铜面积。实际温升、交流寄生、均流、铜区收口、开关稳定性和PCB厂家孔铜规格仍需验证。[可运行模型与结果](../tools/evidence_P5R5.py) · [DC模型](reports/power/DC_model.json)。

S3的6.48A并发峰值预算仍高于现有6.3A主保险的名义电流，必须结合峰值持续时间、温度与熔断曲线复核；本轮未擅自加大保险。

外接PD／3S充电模块仍未选定，后板J2.5 RAW检测线仍缺源端限流；P5R4已记录的耐压配合、IMU钢网工艺、整机装配等问题继续BLOCKED。本次不更新价格、库存或预算结论。
