当前候选端子是 **SPH-004T-P0.5S** 和 **SSH-003T-P0.2-H**。新表采用基础系列名称，未逐项展开T/-H等后缀；因此只录为VENDOR_DOCUMENTED系列工艺参考，完整型号适用性仍待供应商工艺单确认。完整外径范围、实际CAM插座和插合面问题没有因此关闭。

此前A8中的Alpha2841/7仍是30 AWG外径/弯曲筛查参考，未成为已采购线材。不能把这两张通用表、Alpha目录和原CAM配线拼成“已经验证的成品线束”。

## 补入供应商要求的内容

最终加工图应由机械提供已检查的路线、分支和长度基准，采用硬件维护的针脚映射。供应商回签资料需包括：

1. 两端胶壳、端子完整料号与版本，以及实际配合插座；插合面朝向和Pin 1图示必须与硬件交接一致。
2. 同一根实际线材的完整型号、AWG、股数、导体截面、绝缘材质、外径及公差，不能只写“28/30 AWG线”。
3. 对应端子、该线材、压接模具/设备的过程单：剥线长度和公差、导体/绝缘压接尺寸、线芯与绝缘夹持、端子入壳保持，以及拉力试验方法和判定值。以上原表作为询证附件，不直接写为最终工艺。
4. 有动态弯折需求的线段，需要适用的弯曲半径与循环条件依据；供应商的首件压接与后续装机验证分开记录。

这份要求已可供内部设计和供应商后续回签使用。当前没有供应商联系人，也未发送询价、提交个人资料或下单。
