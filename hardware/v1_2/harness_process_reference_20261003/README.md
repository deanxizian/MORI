## 当前组合适用性

H06 研究候选为 **SPH-004T-P0.5S / SSH-003T-P0.2-H / Alpha 2841/7**。本次旧表用系列名和占位形式，没有给出该完整组合的批准工艺。原表说明导体压接高度受线芯构造与公差影响，绝缘压接高度由线材规格决定；因此这里没有给后者补数。

5 N 只转录为原表 `TENSILE` 栏参考，**没有自行定义为 MORI 验收下限**。原表未给这套组合的试验速度、有效长度、夹持方式、是否解除绝缘夹持、样本量及判定规则；更不能用线材目录允许拉力代替端子拉脱试验。导体夹持、绝缘夹持、端子入壳保持和动态弯折是分别验证的项目。

后续供应商工艺单需确认完整端子/线材料号与批次、适用工装、剥线公差、导体及绝缘压接尺寸、首件截面/外观、拉力试验方法与判定、入壳保持和导通错线检查。数值从经确认的原厂/供应商工艺单取得；此处旧表仅作为询证附件，尚未对外发送。
