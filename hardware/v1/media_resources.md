# 双 MCU 的媒体与软件资源边界

候选模块均为ESP32-S3-WROOM-1-N16R8，16MB Flash/8MB PSRAM，实际贴片模组25.5×18×3.1mm。两颗芯片通过同一内部协议协作；本机可用ESP-IDF5.5.2，但本轮没有构建V1正式固件，不把旧A0固件构建记录继承为V1验证。任务3可按依赖支持锁两个SDK版本，必须同时固定组件与模型的版本/哈希，并保持链路协议兼容。

交互侧应用占用27个可用普通GPIO，映射见版本CSV。Octal PSRAM占用35/36/37，USB19/20留隐藏调试，0留BOOT，3/45/46不用作应用。43/44会受到UART0启动功能影响：功放EN硬件拉低，启动打印期间不播放；正式串口日志走USB，不能再复用已分配的I2S/UART脚。屏幕RST接交互CHIP_EN并以软件命令复位，节省一个GPIO，必须验证GC9A01复位时序；不能又给一个不存在的“空闲GPIO”。运动侧轮驱FOC与AB有刷是互斥profile，不允许同时启用UART和PCNT占同脚。

| 资源 | 具体分配与负担 | 尚未证明 |

| 交互摄像头 | LCD_CAM 8bit DVP + LEDC XCLK + SCCB，8数据/4时序/2控制 | M0031模块图/FPC脚序、供电、像素时钟/模式时序；不直接接未经核验的3.3V |

圆屏选Waveshare19192，活跃区只有Ø32.4mm，和原模型58mm不一致，需改变框架及眼睛比例。纯黑底双眼可以局部矩形刷新，不搬整幅视频。起步20MHz/局部刷新，只有波形和并发压力测试通过后升40MHz；不能把115kB framebuffer放进无限增长队列。

OV2640有硬件JPEG能力，传感器驱动在[Espressif esp32-camera](https://github.com/espressif/esp32-camera)中有支持。M0031的完整模组电气资料仍欠缺。目标模式为按需1600×1200 JPEG拍照、持续跟踪先QVGA320×240 RGB565低帧率；**目标不等于已实现帧率**。RGB565单帧153600B，两帧307200B；15fps原始搬运约2.304MB/s。RGB888检测输入230400B/帧，JPEG解码又占CPU/内存，不能把压缩后大小直接当推理输入大小。8MB PSRAM还要容纳Wi-Fi/TLS、模型权重/中间张量、显示与AFE；DMA使用/PSRAM模式必须按选定ESP-IDF与驱动版本实测，不能仅凭总内存相加宣称够用。

参考[ESP-WHO](https://github.com/espressif/esp-who)的S3人脸检测示例和[ESP-DL](https://github.com/espressif/esp-dl)支持的具体模型；自定义载板需做BSP适配，官方开发板支持并不意味着本引脚表开箱运行。人脸检测不是全身跟随、身份重识别、障碍识别或防跌落。本地观测总时延目标250ms包含曝光、采集、预处理、推理、队列与UART。达不到则禁止视觉运动目标、保留拍照/交互并报告差距；不得改成云端直接闭环控制轮子。

单麦SEN0327能先降低器件、开孔、同步和算力复杂度。双麦可能支持空间降噪/波束成形，但需要已知间距、两路同步一致性、相位标定和AFE配置；增加成本和结构孔位，本轮不加。连续平衡时电机修正、皮带/齿轮、塑料腔共振可能淹没语音，台架需录制电机开/关及不同地面的谱图，麦克风通过柔性密封垫隔振但不堵声孔；刚性IMU不能因此改成软装。扬声器与麦克风声腔分离，减少啸叫。

AEC实际路径：网络/离线语音→解码→混音/限幅/音量→重采样到I2S播放格式→同一PCM一份送DAC、一份送参考环形缓冲→与麦克风流按测得延迟对齐→转16kHz/16bit的AFE `M+R`输入。参考不是原始TTS文本，也不是混音/增益前的文件。以实际所锁[ESP-SR AFE](https://docs.espressif.com/projects/esp-sr/en/latest/esp32s3/audio_front_end/README.html)输入格式配置；DMA underrun插入静音时参考也同步插静音。功放削波/结构传声仍会破坏AEC，必须测残余回声、误唤醒与双讲；失败时明确半双工降级，不能仅贴“AEC已支持”。1890扬声器连续额定仅0.25W，输出RMS上限1.414V，需实际测量和增益/PCM硬限制。

自定义“你好，Mori/莫里”有两条现实渠道：[ESP-SR官方社区TTS唤醒词申请](https://github.com/espressif/esp-sr/issues/88)允许按项目/社区条件申请免费模型，但没有MORI的交付承诺；[官方专属定制](https://docs.espressif.com/projects/esp-sr/en/latest/esp32s3/wake_word_engine/ESP_Wake_Words_Customization.html)收费，价格与周期需询价。社区流程会涉及公开项目/提交协议，**本任务未替用户提交**。不能写成“自定义一定收费”，也不能写成“改字符串免费完成”。任务3先用合法已有测试词或物理按钮验证音频，功能验收仍标MORI模型未交付；模型文件/授权/哈希/误唤醒与漏唤醒实测记录齐全后才通过。
