复刻指南

RIG-Hover (文文) 桌面 AI 平衡大师 | 全链路复刻指南

文档版本： V1.0

适用对象： 拥有 3D 打印设备与电子制作基础，渴望挑战“窄间距平衡算法”与“多模态交互”构型的爱好者。

RIG-Hover（中文名：文文）是陆吾智能 RIG 系列的进阶力作 。不同于四足形态的噜噜，它采用极致收窄的双轮平衡构型，配合头部 EM3 总线舵机的水平转向，实现了灵动滑行、视觉反馈与极具拟人化的摇头交互。

1.2 动力系统说明

  • ⚠️ 避坑预警：严禁使用普通减速电机！本项目依赖高频 LQR 平衡算法，必须使用带反馈的高精度无刷动力系统。

  • 舵机：需 1 个 EM3 总线舵机用于头部控制。

第二阶段：结构件制造 (3D 打印)

2.1 打印参数建议

  • 模型下载：MakerWorld - LuwuDynamics 主页 。

  • 推荐材料：PLA+（建议选择幻影紫或高对比黑配色） 。

  • 切片设置（参考拓竹 A1）：

    • 层高：0.2mm 。

    • 填充率：机身 15%，电机支架与轮毂建议 50% 以上（确保低重心稳定性） 。

    • 支撑设置：顶部 Z 距离 0.1mm，开启支撑以保护悬空结构 。

2.2 打印件清单

请确保打印以下组件，拆净支撑并用锉刀修整紧固位：

  • 平衡基座：电机固定架、极窄轮毂 (x2)、底座外壳。

  • 机身类：主躯干（Low-CG 布局）、电池盖、头部支撑件。

  • 交互部：头部外壳、屏幕盖、摄像头保护壳。

第三阶段：固件烧录 (注入灵魂)

烧录步骤（访问 https://tools.luwudynamics.ai，推荐使用支持 Web Serial 的 Chrome / Edge / Opera 浏览器）：

  1. 连接设备：使用 USB 数据线将主板连接到电脑，并连接电池、开启开关。

  2. 选择系列：进入平台首页，点击 RIG 系列 卡片。

  3. 选择型号：在设备列表中点选 RIG-Hover，进入固件烧录详情页。

  4. 开始烧录：点击「⚡ 注入灵魂 FW 3.7.0」按钮。

  5. 选择串口：在浏览器弹出的串口选择窗口中选择对应的串口。

  6. 等待完成：等待烧录进度完成（可点「☰ 查看日志」查看），过程中切勿断开连接；如需彻底清除旧配置，可在「⚙ 烧录参数」中勾选「擦写芯片」。

  7. 自动重启：烧录完成后设备将自动重启，即可进入下一阶段。

注意事项：

  • 请使用 Chrome、Edge 或 Opera 浏览器（需支持 Web Serial API）。

  • 烧录过程中请勿断开 USB 连接或关闭页面。

  • 如烧录失败，请按住设备 BOOT 按钮后再操作。

  • 首次烧录建议勾选「擦写芯片」；如未识别串口，请安装 CH340/CP210x 串口驱动。

第四阶段：总装与配置

4.1 舵机 ID 与电机映射

  • 舵机 ID 3：头部水平转向关节 。

  • 电机连接：请确保左右电机线位与主控板标识一致，避免平衡方向相反造成损坏 。

4.2 组装注意事项

  • 排线连接：FPC 排线座子连接屏幕和摄像头时请轻开轻合，插接方向请参考图片，避免烧坏器件。

  • 舵盘安装：正常安装舵盘时不要随意拔下舵盘转动，安装前需先开机让舵机自动回到中位。如果舵盘被拔下后重新插回，只需开机上电，舵机就会自动回到默认中位，之后再完成舵盘安装即可

  • 电机安装：当屏幕朝向使用者自身时，右手边对应的是11号电机，左手边对应的是21号电机。安装时不能将两个电机装反

4.3 零位标定 (至关重要)

  • ⛔ 警告：文文依靠 IMU 感知重心。首次上电必须进行“手扶调零” 。

  • 操作步骤：

    1. 手动扶正文文使其垂直于桌面。

5. 功能使用与维护

  • 交互：唤醒文文后，它会回答“我在”表示系统正常工作。

  • 常见问题 (FAQ)：

    • Q: 无法站立，直接“摔倒”？ 检查电池电量及 IMU 零位是否已校准 。

    • Q: 转向不灵敏？ 检查窄轮间距是否有杂物，或调整 LUWU OS 中的偏航轴增益 。

    • Q: 屏幕显示异常？ 重新插拔 FPC 排线并检查供电电压 。
