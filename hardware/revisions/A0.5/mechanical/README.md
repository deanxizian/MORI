# A0.5 独立机械校核与试打件

打开`MORI_Hardware_Fit_A0.5.blend`。这是原装配的独立副本，原`params.json`、Blender和已拆分零件包均未修改。蓝色表示候选外形包络，红色表示冲突/需重设计的接口，黄色表示试打件。电池和舵机模型不含尚未拿到尺寸的出线、安装耳、接头等部分。

当前得到的具体结果：

- 主控保守包络71×28×18，在中心(0,-25,123)时与现有承重框架相交约640.179 mm³，主要是头部支柱。与理想内球面最近只余0.182 mm，不能装配放行。18 mm高度是待测预留，不是厂家实测。71×28×10、中心(0,-31,119)仅是待验证的低矮安装目标，不能当成真实板尺寸或直接剪排针的依据。
- 电池候选39×71×18；试打托架内腔40.6×73，X方向与原托架相同，Y方向加长2.4。保留原吊杆中心和槽位。现位置托架/框架、托架/电池实体相交体积均为0；保持电池Z63需要约1.3 mm底部缓冲垫。这不是电池规格、电芯膨胀、强度或线缆验收。
- IMU官方CAD为25.4×17.78 PCB，产品最大包络25.6×17.8×4.6；两个孔直径2.5、孔距20.32，孔位相对板中心为(±10.16,+6.35)。试片孔径2.7供打印公差和孔距检查，**不是最终固定座**。软件仍需实测安装轴变换。
- 6805ZZ候选25×37×7不能直接替换24×36×6占位。图中轴承中心从146.2降至145.7，保持顶面149.2不变；轴承座、主轴、轴向保持、齿轮和支柱尚未联动改完。
