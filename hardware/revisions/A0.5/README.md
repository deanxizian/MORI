## 仍然卡住最终装配/制造的事项

- DevKit的71×28×18保守包络与现有框架相交约640.179mm³。主控先外置台架；低矮安装、更紧凑板或内部支柱修改需要进一步确定，不能直接缩放模型。
- 载板的部分去耦电容离IC过远，局部电源与回流还要重排；器件高度、插拔和线缆空间尚未通过装配检查。DRC通过只说明列出的电气几何规则满足。
- Ø60最终显示屏仍未确定；小GC9A01只用于台架。电池规格表有尺寸矛盾，充电电流、保护/均衡和再生路径资料未补齐。
- 同步带轮含轮毂总宽、皮带SKU、舵机安装耳/花键、25×37×7头轴承座/主轴仍需闭合。具体索取内容已写成 [采购问题清单](procurement_questions.md)。
- 所有实际上电、急停、热测试、惯量辨识、头部行程和自由平衡验证均为 **NOT_TESTED**。三个运动编译门仍为n。

## 文件入口

- `kicad/MORI_carrier.kicad_pro`：完整原生KiCad工程与本地库。
- `mechanical/MORI_Hardware_Fit_A0.5.blend`：独立装配校核副本。
- `mechanical/Battery_Tray_A05_TRIAL.stl`、`mechanical/IMU_20p32_Hole_Gauge.stl`：试打件，不是整机最终零件发布。
- `firmware/`：硬件最小验证基线；并行软件继续在根目录`software/`。
- `tools/`、`tests/`、`reports/`：生成脚本、测试及实际运行记录。
- `sources/manifest.json`：本轮厂家CAD/数据手册来源与哈希。

本目录作为A0.5增量使用。机械生成脚本读取现有MORI根目录的`params.json`、`reports/derived.json`和原Blender；不会替换这些文件。整机预算仍引用A0.4的未验证估算；新增隔离器件组预留US$1.50，试打托架相对旧托架按实心PLA估算增加0.301g，均非实测。
