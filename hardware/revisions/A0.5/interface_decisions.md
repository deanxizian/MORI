# A0.5 硬件接口决策 · 供并行软件任务合并

日期：2026-09-21。范围：硬件任务的执行基线与增量；不是实物验收。

1. **轮电机采用 Pololu 4863，保留 HW-SW-0.4 的 979.616 输出轴四倍频计数/转。** 传动比 `20.4086667:1 × 48 CPR = 979.616`，皮带暂按 1:1，轮径95 mm，轮距138 mm，每计数0.000304661522567 m。旧版5216/1204.44不再是硬件执行基线。软件可以继续合并此标定，但应保留可配置参数和转一圈实测验收。
2. ESP32-S3-DevKitC-1-N8R8 **v1.1**、DRV8833、LSM6DSOX、INA219、SER0037继续用于台架。GPIO、I²C地址、PWM映射和编译安全门均不变。`pinmap.csv` 与A0.4相同。最终整机显示屏仍未选定；GC9A01仅是台架显示后端，不能默认把Ø60显示目标缩小。
3. A0.5新增舵机电平/断电隔离：GPIO41 → U6 SN74LVC1T45 → `HEAD_SIGNAL_5V` → J10.3。U6的VCCA=3V3，VCCB=急停NC2之后的HEAD_5V，DIR=3V3，输出100k下拉。软件脉宽命令不变；新版板J10.3不再直连MCU。
4. 硬件基线固件修复LEDC初始化：ESP-IDF5.5.2使用`ledc_set_duty_and_update()`前调用`ledc_fade_func_install(0)`；启动ARM保持低，检查输出错误并锁存为驱动故障。模拟契约测试已复现旧问题并验证修复。软件任务已有相关修复时，审查差异合并，避免整体覆盖自己的故障处理、协议和调试成果。
5. `[x,y,z]_control=[-Y,X,Z]_Blender`。控制左轮是Blender中的Wheel_R/Motor_R；IMU实测安装矩阵仍不可默认identity。所有姿态、极性、时序、供电和急停实测状态保留NOT_TESTED。

软件合并后至少复核：电机型号/计数一处定义、轴映射、默认锁定、LEDC初始化和错误路径、过期命令/传感器故障后的禁用。软件现有更严格的协议或故障处理不应被A0.5最小固件替换。硬件任务没有改写`software/`，也没有启动新的软件任务。
