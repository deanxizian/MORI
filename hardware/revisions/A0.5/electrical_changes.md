# A0.5 电路与载板增量

保留A0.4模块方案：2S受保护母线、双编码器有刷驱动、分支5V逻辑/舵机、硬件看门狗、NC急停和电机母线耗能钳位。完整基线设计仍见`../../architecture.md`、`../../power_budget.md`、`../../safety.md`。A0.5没有把任何实测门改成PASS。

## 舵机断电后的信号隔离

原GPIO41直连舵机信号时，急停NC2切断舵机5V而信号仍可能为高。新增SN74LVC1T45DBVR：1脚VCCA=3V3，2脚GND，3脚A=HEAD_PWM，4脚B=HEAD_SIGNAL_5V，5脚DIR=3V3，6脚VCCB=HEAD_5V；C14/C15各100nF，R25输出100k下拉。J10.3改接B端，GPIO编号/脉宽均不变。

TI资料明确提供Ioff与VCC隔离：任一供电接地时端口高阻。此处选择它的依据是这些电源状态能力，不只是3.3V→5V电平转换。另一供电正在下降、残余电压和实际舵机输入电路仍需示波器验证，不能由“高阻”推断即时机械停止。[TI SN74LVC1T45数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc1t45.pdf)

台架验收补充：保持MCU通电且GPIO41分别低/高/PWM，断开NC2，同时记录HEAD_5V、J10.3、NC2电流与舵机行为；检测是否有反向供电、残余脉冲或复电跳动。复电前软件头部输出仍为禁用，不能自动重启。所有结果当前NOT_TESTED。

## 载板规则和未完成的工程审查

2层96×92×1.6载板，保持原四个安装孔和舵机/穿线开口。软件接口没有新增GPIO。原生KiCad网表与引脚映射是连接依据，导入路由后必须再跑KiCad DRC。

|网络|初始线宽 / 过孔外径-孔径 mm|用途|
|---|---|---|
|普通信号|0.25 / 0.60-0.30|数字、模拟测量|
|3V3|0.30 / 0.60-0.30|载板逻辑和IMU分配；ESP32核心电流在开发板本地|
|逻辑/舵机5V|0.80 / 1.00-0.50|外部稳压分支|
|电机输出|1.00 / 1.20-0.60|LM1/2、RM1/2|
|主母线/耗能|1.20 / 1.20-0.60|VMAIN、VM_DRV_IN、VM_MOTOR、DUMP_DRAIN|
|GND|0.80 / 1.00-0.50，加覆铜|功率回流/逻辑参考|

线间最小0.20，铣边/开孔铜间距0.50。Specctra把开孔作为普通keepout导出，为避免其套用0.20线间距，路由输入中的三个开孔禁布区额外扩大0.35；真实Edge.Cuts没有改变。规则、脚本、DSN/SES和原生DRC结果都保留。

3V3按载板分配电流暂估不超过100mA；35µm铜厚、0.30mm宽、100mm直线段的估算电阻为0.164Ω，100mA压降16.4mV。该估算不覆盖过孔、温升、连接器和实际路线，需要量测；不能用于电机或ESP32核心供电走线。

当前布局还必须复核：局部去耦距离、时序回流、采样地、VM_MOTOR钳位回路寄生、电容真实高度、连接器插拔和线束弯曲。现有几何距离约为U6-C14 11.0mm、U1-C2 15.8mm、U2-C3 17.7mm，需要人工局部重排/短回路优化后再制造；不能以DRC通过替代这一步。载板目前按**外置台架候选**管理，不能声称已装入Ø140机身。

物理验证之前不生成生产Gerber/钻孔文件，不下单载板。BOM新增器件组是US$1.50的预留，非供应商报价；A0.4整机质量/重心与预算仍是基线估算，未用试打件或载板路由结果冒充实物更新。
