1.46inch Touch LCD Module
The
1.46inch Touch LCD Module
is a 1.46inch IPS touch display module featuring a 412 × 412 high-definition resolution and support for 16.7M color display, delivering clear, detailed visuals with excellent image quality. It is equipped with a capacitive touch panel that offers responsive touch sensing and long-lasting durability. The module integrates the SPD2010 display and touch controller chip, with display and touch functions communicating via QSPI and I2C interfaces respectively, minimizing pin usage and simplifying hardware integration. An onboard level shifter makes it compatible with 3.3V / 5V power input, and the QSPI interface supports high-speed refresh. It can be used with host platforms that support QSPI, such as ESP32, Raspberry Pi Pico, and STM32.
