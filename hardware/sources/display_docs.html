1.28inch LCD Module

1.28inch LCD Module是一款 1.28 英寸圆形 IPS 彩屏模块，分辨率为 240 × 240，采用 GC9A01 驱动芯片，通过四线 SPI 接口通信。模块支持 3.3 V/5 V 电源输入，提供 Raspberry Pi、STM32、Arduino 三平台示例程序，适用于嵌入式显示、传感器数据可视化等应用场景。

通信协议​

该 LCD 使用四线 SPI 通信接口，相比并行接口可节省 GPIO 资源。SPI 通信通过时钟相位（CPHA）和时钟极性（CPOL）的组合控制数据传输时序，本模块使用 SPI Mode 0：CPOL = 0（空闲低电平），CPHA = 0（第一个边沿采样），高位在前，低位在后。
