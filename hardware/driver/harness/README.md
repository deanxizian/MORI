## 供线束厂复核的边界

- 针号按厂家接口图和板上1脚标记，用端面视图确认；不得照照片左右次序。两端同号并不代表任意市场成品线均直通。
- 两轮主干承受两轮总电流；左轮第二插口的真实馈通额定值未知。PH目录2A仅是规定线材下的组件额定条件。
- CAM主电源J702为BAT候选约3.87V，不能接UPS5V或3S电池；设备端1.25mm壳尚未冻结。CAM UART第三针仅为CAM侧3.3V电平参考。
- UPS J701.2和.5各有一条电源地线，不得合并省线。UPS两个XH2电源口可互插；5V/BAT必须分别标识和固定，样件断电通断后才可上电。
- SEN0693接口1脚两端不装接点，不增加中断线；UPS I²C只装当前定义的7/8脚。未确定的UPS壳不得临时用无额定数据的杜邦线放行。
- 供应商制作方式已由用户确定。当前没有向供应商发送内容或授权制造；所有 finished_length_mm 空白，必须由完整机械线路测量回填。
