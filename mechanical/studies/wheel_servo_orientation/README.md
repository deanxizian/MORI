## 结论

绕轮轴翻转180°能把偏心电机的长边转到下方，从上方释放15mm高度；但当前球腹收拢，两侧机身到下壳的实际最小间隙约0.8mm，未留充分打印座、装配公差和走线余量。它没有直接穿壳，但不能据此称为可装配。

横躺90°仅比倒装少释放0.5mm高度，却保留约9.9mm下壳间隙；当前几何下这是更值得继续设计的方向。朝前/朝后及左右相反90°均做了同尺度检查，结果详见JSON；最终方向需按实际接插件、线束和配重选定。

这些方案增加的是电机上方空间，两电机本体之间的8mm左右净宽没有扩大；双端输出也仍在轮轴高度，不能将本体间隙当成完整可用通道。电池托盘、固定片和浅电机座仍需同步重做，顶部降低数值不等于电池已经能下移相同距离。原电池、载板尚属包络，完整电源PCB尺寸未知。

另一种理解是调换左右输出朝向：在本体原中心翻转时，双端输出只是互换，中央净宽不增加。绕原外侧输出面掉头会把机身移向轮子，虽然中间几何净宽变大，但会与现有轮轴、轴承、转接盘等发生22对重叠，且壳间隙仅约0.13mm；不能直接在现有传动上采用。

## 方法和限制

使用Manifold三角实体求交，AABB只作初筛；最小间隙来自真实壳网格。另以标称内球壳检查电机本体完整包含性。既有座的冲突单列，未将其排除后冒充完整装配PASS。每个朝向另检查身体−15～15°、1°步长共31个姿态的电机最低点；这不是控制安全范围或连续数学证明。

S288几何来自项目已有原厂尺寸资料的简化模型，未拿到实物；完整线束出口、插头、固定件、输出转接、散热、打印强度和实际平衡仍未验证。原方向、壳体、电池与承重结构并未被本研究脚本覆盖。
