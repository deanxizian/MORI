# SCS0009 配套舵盘资料清单

状态：**BLOCKED — 用户明确保留 SCS0009，配套舵盘及依赖它的短轴、轴向锁紧等厂家资料后定型。** 本文件是待询资料清单，没有向厂家发送信息，也没有采购或更换为 SC09。

已建的 SCS0009 外壳、安装耳与轴位置依据 FEETECH A/0 图纸；这些资料不能证明当前舵盘、花键或锁紧螺钉占位准确。现有两侧俯仰轴承和 yaw 承重轴承负责承载，舵机只传递驱动转矩。

需要匹配实际采购套装/版本的以下内容，优先 STEP＋尺寸图：

1. 输出花键齿数、外径、齿根、齿形及有效插入长度；花键顶面相对舵机安装面的高度。
2. 原配圆舵盘的正反面尺寸：外径、盘厚、轴毂、花键深度、中心凹槽，全部连接孔的孔径、孔距/分度圆和角位置。
3. 中心锁紧螺钉的确切螺纹、头型和长度，允许最大旋入深度，以及厂家给出的锁紧要求。未知项不得以通用 M2 推定。
4. 原配舵盘与舵机安装后的完整轴向叠层，以及允许与禁止接触的壳面；有无原配垫圈、螺钉、轴套等附件。
5. 套装型号、舵盘材质及版本识别方式，确保图纸与实际供货一致。

收到后机械需完成：两只舵盘和传动件1:1替换；轴肩/短轴/轴向锁紧叠层；yaw 反力连杆与传动接口的薄壁复核；固定侧与转动侧分离、工具与装入路径、±60° yaw / −20°～+25° pitch 联合检查。后侧舵机耳螺母槽已在M1.43按用户确认采用，不依赖舵盘资料。不能只把舵盘外观替换就标为完成。

在此前，不批准这些依赖接口的零件加工，也不把几何占位当成已选定实物。此阻塞属于缺少型号配套资料，不等同于只能等待到货测量；完整厂家资料可提前解除。
