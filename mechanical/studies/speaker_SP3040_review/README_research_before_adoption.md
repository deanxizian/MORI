# SP3040 与立创近似款尺寸核对

2026-09-26。用户已选择所提供规格书中的 SP3040，本次按要求查找立创相似模具。当前总装仍为 M1.36，安装座未修改。

找到兴华鑫 **4230BOX-4Ω3W-2P1.25 / C49247023**。外形相近，但孔距、孔径不同，不能认定为 SP3040 的同一安装模具。两份图均没有单独标注安装耳厚度和前后位置的数值。

| 图纸参数 | 用户提供的 SP3040 | 兴华鑫 C49247023 |
|---|---|---|
| 箱体长×宽×厚（mm） | 42±0.3 × 30±0.3 × 9±0.5 | 41.4±0.2 × 29.8±0.2 × 9.1±0.2 |
| 含安装耳总长（mm） | 56±0.3 | 55.6±0.2 |
| 两孔中心距（mm） | 49±0.5 | 50.8（通用公差±0.3） |
| 孔径标注（mm） | 引线标2，未写直径符号 | 明确2×Ø3 |
| 耳厚/耳前后位置 | 无数值标注 | 无数值标注，侧视轮廓亦不同 |
| 引线长（mm） | 200 | 150±5 |
| 端子 | 2P1.25，具体系列待核 | 2P1.25，具体系列待核 |
| 阻抗/额定功率 | 4Ω / 3W | 4Ω / 3W |
| 标称谐振频率 | 660Hz | 1500Hz |

立创商品页简写为42×30×9.1mm，实际建模应采用原厂PDF第6页41.4×29.8×9.1mm，不能按商品简写放大。另有同系列8Ω2W的C49247022，不能作为当前4Ω方案的默认替换。

未核得与SP3040完全一致的49mm孔距、孔标注2mm的立创型号；这不等于断言立创没有。相似型号的尺寸不能直接标成SP3040的已确认尺寸。

## 安装待确认

SP3040选型本身已获用户授权。之前提出按图比例估算安装耳、外壳一体座配两枚M2螺钉的方案，用户要求先查立创，并未批准估算安装座。因此这次不改壳、不更换紧固件，也不混用不同型号的孔位。

继续SP3040时，42×30×9、56、49及孔标注2可用于名义参考模型；耳厚、前后位置、耳宽、圆角及振膜外形仍需明确标为ASSUMED，并在实物到货后校准。若改选立创款，应独立接收其尺寸和孔位，不能描述成同模具直接代换。

SP3040负载测试条件存在源文档冲突：第2页3W/96h，第7页英文1W/48h、中文2W/48h。额定表仍记载3W，但不能据此宣称可靠性、实际功放输出或连续工作资格已通过。C49247023的电声参数也不同，不认定声音等效。

本次没有采购；人民币报价、实物配合、振膜行程、声学表现和走线仍待核。所有hardware文件与contracts/components.json保持只读。
