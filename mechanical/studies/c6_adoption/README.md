# C6 已应用 · V1.2-M1.53

用户确认后，将固定偏航桥 Yaw_Base 既有左侧穿线口外边缘向外加宽 0.8 mm。原外半径 11.7 mm → 12.5 mm，移除约 22.0474 mm³；不增加零件或紧固件。主模型、电子细模、21 个 STL、预览和 M1.53-A1 装配工程／完整视频已同步。

- 与审查后的 M1.52 原生几何逐件比较：只改变 Yaw_Base，其余 200 件保持。轴承座、孔轴、紧固件及所有硬件变换保持。
- 21 个导出件均通过闭合拓扑和 Blender STL 回导检查。机器人本体仍为 16 件打印件，其余是既有试配／支撑等输出。
- 九条历史下部线路对当前 201 个原生实体：1404 次分组有限姿态检查，均满足 0.3 mm 名义净距下界；采用前的槽口有 52 次不足。最近的实际查询样本下界约 0.3996 mm，但它不是所有路线的全局最小值。
- 身体前后模块各 275 个平移位置重新检查；保存后的动画回读还检查了分壳、防脱与舵机台架预装。原生实体之外的对插分配包络、软线和人手操作未据此放行。
- 全部既有硬件源文件与硬件合同哈希保持。该检查发生在本次 PR 发布之前。

完整线束仍为 BLOCKED：恒定材料长度、上端固定／应力释放、FFC／FPC 及带线闭壳等尚未完成。九条候选线路、滑动导线约束和回弯固定未随槽口一并采用。原有 WeAct 等资料问题仍单独保留，局部结果不是整机装配完成。PA12 配合、强度和疲劳 NOT_TESTED；manufacturing_release=false。

数值清理：新切口转存 float32 前以 1e-7 mm 简化容差去除四个退化三角形；与未简化实体的对称差约 1.09e-7 mm³。独立批准参考与保存后实体的差异另记于检查报告；这不是打印配合公差。升版时也保留了已审查的头前壳碎片清理。失败尝试日志保存在 attempt1/、attempt2/、attempt3/，没有跳过失败项。
