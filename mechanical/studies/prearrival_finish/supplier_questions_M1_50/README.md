## 收到回复后的处理

1. 保留回复原文、附件及版本；将厂家给出的尺寸与照片估算字段分开登记。厂家回复不是实物测量。
2. 先核对型号、版本和插合视角，再把舵盘、线端和排线按 1:1 导入独立检查模型。
3. 根据实际两端基准补全线路与装配检查；结构变化仍先呈现具体方案供确认。
4. 完整恒定线长、固定/应力释放及带线装配通过后再出供应商制作图。当前曲线长度不能作为裁线长度。
