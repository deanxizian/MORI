# MORI 从 Blender 到实物成品

当前工作目录归入用户创建的 `/Users/dean/Documents/MORI`，本轮交付副本保留在本任务 outputs。后续以 MORI 项目目录为持续工作的主版本。

| 阶段 | 交付目标 | 进入下一阶段的依据 |
|---|---|---|
| 1. Blender 预研（当前） | 参数、真实分件、装配/爆炸、内部包络、尺寸与运动筛查、候选 STL | 查看实际检查报告，列明未验证项目；模型可以重新生成 |
| 2. 硬件选型与复测 | 电机/编码器、头部执行器、显示、轴承、轮胎、电池、主控/驱动/IMU、电源保护充电及线束 BOM | 每个器件有数据表、CAD 或实测；质量、电压/电流/力矩/行程和空间明确 |
| 3. 接口定型与结构打样 | 用真实器件替换包络；设计轴向锁紧、轮毂夹紧/胎圈、传动齿形/张紧、螺钉和嵌件 | 无未解决装配碰撞；切片检查、配合小样、外壳与承重件试打及实际装配 |
| 4. 电气集成与台架测试 | 接线图、保护与充电方案、线束固定、传感/编码器/电机方向验证 | 电池与电源模块匹配，堵转/峰值电流和散热受控；通信/反馈有效 |
| 5. 实物主动自平衡 | 真实质量/重心、力矩和轴承/轴载荷核算，轮控/IMU控制调试 | 外部测试夹具下逐步验证；没有将夹具作为机器人运行时第三接地点 |
| 6. 成品迭代 | 可靠装配、维修、噪声/温升/续航/跌落等实测，更新最终 BOM 和模型 | 实测记录与版本对应；解决已知问题后才扩大运行范围 |

硬件采购清单必须在第 2 阶段按预算、供应渠道和性能目标建立。本轮没有执行任何采购。更换电机尺寸、轮径或电池时，先更新包络，再检查几何、质量与控制可行性，不能让外观尺寸替代动力核算。

后续第一件实际工作：选出两台编码器减速电机和头部执行器的候选数据表，结合整机质量预算核算力矩、速度、电流与传动比，再修改当前模型。现有轮驱动的 1:1 带轮仅为占位；头部节圆比 14:8 对执行器行程有明确影响。
