# SSH-003T-P0.2-H：补充公开尺寸证据

2026-10-04。本次从 [JST 官方网站](https://www.jst-mfg.com/product/pdf/eng/eLBT.pdf)取得 LBT CONNECTOR A Type 目录，检查了第 2 页 Contact / Signal 图及其型号表。图中信号端子的完整料号确为 **SSH-003T-P0.2-H**，与 SH 目录列出的端子相同；不采用 LBT 胶壳，也不把 LBT 系列额定值移植到 CAM 接口。

[原始 PDF](JST_eLBT.pdf) · [原图第 2 页](contact_page2.png) · [下载记录与哈希](retrieval.json)

相较只用 3.9、0.8、1.35 mm 三个名义尺寸的方盒，本图还有以下明确标注，可作为后续端子外形重建的约束：

| 图上尺寸 | 对应位置；单位 mm |
|---|---|
| 3.9 | 侧视图总长 |
| 1.6 | 侧视右侧接触段的长度 |
| 2.0 | 从左端至中间压接翼右端的轴向距离 |
| 0.5、0.8 | 左端及中间压接翼的各自轴向宽度 |
| 0.8、0.45 | 端视图上部总宽、底部窄段宽度 |
| 1.35 | 侧视右侧接触体上、下边之间的尺寸 |

**需修正对证据的理解：** 原图在接触体下方画有锁止弹片，其最低点位于 1.35 mm 尺寸线下方。由图可判断，1.35 mm 不能直接当作包含弹片的完整最大高度；弹片高度、角度和形状公差在此页未给出。此处是图面关系判断，不是按比例测得的实物尺寸。

既有 CAM 端子方盒检查仍仅对其声明的 ASSUMED 包络有效，不能提升为真实端子穿入或锁止通过。后续详细重建还需补齐弹片及压接后外形，不能用本图中较窄的局部轮廓直接缩小旧包络并消除碰撞。

本目录的 LBT 信号用途表列 28 AWG、绝缘外径 0.6-0.8 mm；SH 目录列 32-28 AWG、0.4-0.8 mm。保留各自适用范围，不据此自行合并成新的压接验收标准。SH 专用手册、逐型号端子图和胶壳 CAD 仍处于[官方邮件申请入口已找到、文件未取得](../../supplier_made_harness/recheck_20261004/SH_DETAIL_ACCESS.md)状态。

主模型、线束候选尺寸、硬件源文件均未因本次资料补充而修改。供应商定制线长和装配图仍需项目完成；实际板端型号、配套胶壳和压接工艺尚未确认。
