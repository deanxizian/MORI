# CAM 四线放入根部固定槽

本候选补齐一个局部装配动作：根部扎带尚未安装时，四根绝缘导线从固定座前方 1.5 mm 处移入现有槽内。下方颈部四个端点保持不动，根部暂时抬高最多约 0.86 mm。未改 M1.47 主模型，也未增加孔、零件或紧固件。

![入座前](before_seating.png)
![导线入座](seated.png)

两图使用同一视角；图中没有扎带头和带身，因为这一步在安装扎带之前。四根完整上部导线及目录端子包络均参与计算，[整体图](complete_leads.png)显示它们的临时直立状态。

| 检查 | 结果与范围 |
|---|---|
| 有限位置复核 | 21 个位置 PASS |
| 位置之间的连续动作 | 256 个区间完整覆盖前后 1.5 mm 行程，PASS |
| 线径、长度 | 外径仍为 0.6604 mm；扇出段长度变化由原有末端 7 mm 直线段补偿，全程剩余直线段的保守下界大于 5.2 mm |
| 弯曲 | 整个候选动作的几何半径下界至少 7 mm；不代表线材动态寿命合格 |
| 线间与结构间隔 | 普通位置按 0.3 mm 筛查；固定槽接触面及裸端子按名义不穿透检查 |
| 原始实体 | 保留 214 个主模型实体；固定槽的计算分区合并后与原实体差值为零 |

最初方案把长度差放在上段弯曲之前，使四根线的转弯高度错开并发生干涉。现在让转弯段保持对齐，仅调整末端原有直线段。原[失败记录](../finite_screen.json)保留。计算中 0.0001 mm 的分区容差只用于归属既有接触面，不是削掉实体或增加装配间隙。

**还没完成：** 散端子从机身穿到此候选起点的完整路线、柔性扎带穿绕与收紧、端子入胶壳、其余七根跨关节线和排线。端子仍是目录外形重建包络，实际压接和手部操作未验证。完整线束为 BLOCKED，尚无供应商最终裁线图或制造放行。
