# MORI 后接口小板机械要求 · M1.12

本文件交给负责电路设计的任务。用户已允许新增这块小板；这里只定义安装和接口要求，没有设计充电电路、连接器引脚或电气保护。共享尺寸以 `config/geometry.json#/layout_cleanup/interface_pcb` 为准，接口记录在 `contracts/mechanical_interfaces.json#/rear_interface_pcb`。下面尺寸均为 mm，是机械提案，不是已选采购件的尺寸。

| 项目 | 当前要求 |
|---|---|
| PCB 板框 | 24 × 14，名义板厚 1.6；暂不需要异形板 |
| 放置方向 | 水平；顶面朝机器人 +Z，底面朝 −Z；两个接口都朝后方 −Y |
| 世界坐标 | PCB 中心 `(0, −65, 115)`；板框 X=−12…12，Y=−72…−58；上表面 Z=115.8，下表面 Z=114.2 |
| 板上二维坐标 | 左后角为 `(0,0)`，X 向右、Y 向机内；右前角 `(24,14)`。该坐标定义优先于绘图软件默认方向 |
| 安装孔 | 两个 Ø2.2 NPTH，坐标 `(3,11)`、`(21,11)`；孔中心禁铜直径 5.5，最终随 M2 小样复核 |
| 壳体安装方式 | 两个短安装耳直接并入身体上壳；安装耳压在 PCB 顶面两侧，从下方穿两枚 M2 试配螺钉入嵌件。没有独立打印接口支架 |
| 安装耳避件区 | 顶面左右两条边带：X=0…6.5 和 17.5…24，Y=0…14；不能放元件、裸露焊点或插头，避免安装耳压到器件 |
| 开关 | PCB 顶面；本体预留 10×9×8，底部落在顶面，侧向操作件朝 −Y；操作中心目标 `(0,−75,123)` |
| Type-C | PCB 底面，侧出型，插入口朝 −Y。当前总包络 10×10×4.4，中心 `(0,−74,112)`，外侧口面约 Y=−79 |
| 两接口位置 | 同一竖线上，开关在上，插入口中心 Z=112、开关操作中心 Z=123；中心距 11 |
| 壳体开口 | USB-C 12×6；开关 12×8。当前开口有选型余量，不能用它们反推连接器必须这样大 |
| 通用装件限高 | 顶面起 ≤9；底面起 ≤7。安装耳区及螺钉头区优先，不是整板任意位置都允许装满 |
| 对内出线 | 朝 +Y；线端与插头放在中部，避开两孔/安装耳。模型保留有限线束路径，尚未确定真实线束弯曲半径 |
| 外部插拔空间 | 已按 16×34×10 的 USB 插头外壳与 8.4×6×2.6 的插入端进行几何检查；真实线头还需复核 |

顶、底翻面并不自动让普通直插连接器朝向正确。请先选出能满足上表 **侧向操作/侧向插拔** 的开关和 USB-C，并回传原厂尺寸图或 STEP，再定两者的 footprint。若标准器件的轴高不能满足当前 11 mm 中心距，应反馈真实尺寸，由机械调整开口或板面高度；不要拉伸采购件或延长未定义的引脚假装能装。

开关、USB-C 和 PCB 目前均以橙色或金属色的 **PLACEHOLDER 要求包络** 表示。它们没有型号、焊盘或引脚定义。电源开关应如何实现物理禁驱/断电，以及 USB-C 是否承载 PD、充电或调试，由硬件任务按整机电源方案决定。这块小板不等同于已经选定的 3S 充电器。

请硬件任务回传：

1. 两个器件的厂家、完整型号、版本、尺寸图/STEP；连接器口和开关操作轴相对 PCB 表面的坐标。
2. KiCad PCB、含正反面器件的 STEP、实际板厚和孔径；保留本文件二维坐标或明确提供变换。
3. 顶底面最高点、焊脚/焊点、配对插头、线束出线方向、固定方式和板边退让。
4. 对外开关行程与手指操作要求；插着 Type-C 时是否能操作开关，需要实物确认。

装配顺序：先将上壳拆下，接口板从壳内对准两个后向开口，贴在两个安装耳下方，再从上壳敞开的底面拧紧两枚螺钉。接好可断开的线束后合壳。已检查的工具只是直径 4.2、长度 30 的杆体；螺丝刀头、手柄、嵌件耐热和实际插拔力尚未实测。先用局部后壳与真实连接器试打，不按整壳一次定型。

独立 Function_Button 及其壳体孔已按用户要求移除，未增加外置 RESET。
