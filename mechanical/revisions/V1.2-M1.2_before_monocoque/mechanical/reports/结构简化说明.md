# MORI V1.2-M1.2 — 支架简化说明

本次针对长而细的支撑路径与分散安装座做几何重构。未改变外壳、两轮、两轴中心、头部范围或原厂采购件比例。

| 区域 | 原结构 | 当前候选 |
|---|---|---|
| 随头骨架 | 拱杆、独立CAM板框、独立相机座 | 一体拱形宽肋骨架，后板框和前相机托合并；屏幕架仍可单独拆 |
| 屏幕架 | 细圆杆接到上横杆，接合方式未完成 | 两片平板加强肋、接触法兰与两枚试配M2螺钉；仍采用原厂三柱 |
| Pitch | 细斜杆叉架、单独舵机托 | 宽板叉架与舵机托合为一件，保留双侧轴承与两端试制限位 |
| Yaw | 四根立柱加承重环 | 两片整体侧壁加承重环，保留轴承、舵机拆卸空间及线束服务环让位 |
| 底盘 | 轮轴承多段杆式连接到顶板 | 双侧连续承重板、成对轴承座及电机后横梁 |
| 两电机座 | 长支撑伸到顶板 | 短平板法兰接后横梁，每侧两枚试配M3螺钉，电机座仍可拆 |
| 电池托架 | 四根44mm长吊杆 | 底盘两侧托边承重、滑轨托盘、两枚短限位螺钉；四长吊杆删除 |

所比较的打印支撑件从 **11件变为8件**。这是本次涉及的结构子集，不是全机器人零件总数。旧模型中多段杆本就合为同一打印件，不能把每一段杆都算成一次装配接头。新增可拆螺钉/螺母单独计入BOM，不宣称整机紧固件总数减少。

支撑件实体几何体积约 **109 → 144cm³**。用较宽连续板面换掉长杆，材料用量有所增加；不把“合并零件”说成减重。当前整机估算约 **1.07kg**，pitch运动件约 **160g**，至少±35%质量不确定度，完整假设见mass_budget.json。

- 本次运行结果：{'PASS': 21, 'FAIL': 0, 'NOT_TESTED': 12, 'BLOCKED': 9}。130组yaw/pitch联合姿态、保守线束分组检查、轮壳间隙、41步电池抽出路径、候选件网格及STL单位回读详见validation.json和export_manifest.json。
- 原厂LCD的两个连接器转换网格尚需保守代理，因此完整精确采购件装配仍BLOCKED；零交集不能表述为全部实物已装得下。
- 宽肋的弯扭刚度、FDM层间强度、热蠕变、跌落、疲劳、螺钉预紧、轴承寿命均 **NOT_TESTED**。这是一版更集中承重路径的候选设计，不是实测可靠性结论。
- 新增M2/M3、嵌件孔、轴承配合为试制接口；最终供应件与打印公差未冻结。全局壁厚、精确自交和全部工具手柄路径仍待专门检查。限位几何存在，但碰撞角度与失控冲击未认证。
- P1硬件已出80×45电源板，当前旧电源预留仅44×16×10，两者不兼容；完整装件、WeAct模块、稳压板与电源布局需另行整合。此次支架修改不冻结主控、电源及电池最终安装面。

## 拆装与试打顺序

1. 优先试打屏幕架的平面螺钉接合、Pitch轴承座、短电机法兰与电池滑轨小样，记录实际材料、方向和配合。头骨架与Pitch叉架分别安排层向，避免把所有受力都安排为层间拉伸。
2. 先组底盘/轮轴承/短电机座，再装滑轨托盘；电池维护先禁驱、断电并外部支撑，按原壳体路径拆轮/轴及上下壳，断开插头，卸两侧短限位螺钉，向前抽出托盘。托盘内嵌件随托盘移动，不拆热熔嵌件。
3. CAM与相机先装入一体头骨架，屏幕架最后用两枚螺钉连接，保留前侧工具通道。采购件的最终压紧/螺纹啮合与真实FPC必须在选型后补齐。
4. 先做轴承座与承重板静载、关节循环和紧固复检，再做整机平衡。试验负载须根据真实头重、加速度和装配材料确定；本项目未编造允许载荷。
