# MORI V1.2-M1.3 — 整体舱式结构

本次按用户进一步要求重新设计为围合承重结构。内部主要承重件只有三件：身体整体舱体、Yaw杯形承座、随pitch运动的头部器件舱。对应不同运动与维修需要，另保留屏幕短压框、电池托盘和电机短底盖。可编辑几何已实际生成，不是给旧杆架加一层遮挡外罩。

| 区域 | M1.2 | M1.3当前候选 |
|---|---|---|
| 身体 | 分开的底盘板、两电机座、Yaw座、舵机托与多块板架 | 一体开放前舱：轮轴承筒、电机舱、Yaw圆筒座、暂定板卡平台合并 |
| 双轴承座 | V形长板肋、独立Yaw轴颈和带支杆的下护罩 | 连续杯形承座，双侧pitch轴承、舵机座、Yaw轴颈和下护罩成为同一打印件 |
| 头内支撑 | 拱形骨架加CAM/相机平台 | 连续侧壁、后壁与前隔板，器件就近固定；顶部和底部留装配/运动开口 |
| 屏幕 | 两条长斜臂吊接到上方 | 薄压框直接连接相邻前壁；只保留到原厂三柱的短局部连接 |
| 电机维修 | 每台电机独立鞍座，长距离接到底盘 | 电机从底部插入，安装一块共用短底盖；电机与输出件可从下方取出 |
| 电池维修 | 侧托滑轨 | 保留滑轨与两枚短限位螺钉，向前抽出托盘 |

本次相同功能集合的打印件 **17 → 6件**。它包括板架、护罩与两块Yaw固定限位，范围比上一轮“11→8”更大，不可直接把两组计数当成同一分母。三个连续承重体之外的三件是短维修件；全机器人还有外壳、轮毂和采购件，详见BOM。

支撑件实体几何体积约 **174 → 292cm³**。连续舱壁增加材料：当前整机约 **1.26kg**，pitch约 **200g**。至少±35%不确定度；外壳按98%、薄壁承重舱按95%、其他支架按65%有效填充估算，未以低填充假设掩盖增重。

## 装配与试打

1. 三个主承重件分别打印；先检查杯形承座、头舱短轴座和底盘轴承筒的层向、孔配合及局部承载小样。短压框与底盖平放试打，滑轨按实际材料记录间隙。
2. 裸底盘在工作台支撑，轮轴/联轴器/轮子尚未安装时，从下方插入两台S288，再装0.5mm假设垫片和共用短底盖。之后装轴承、短轴和轮转接。底盖M2与垫片压缩量是试配接口，最终紧固仍需实物验证。
3. 电池禁驱/断电维护仍需按既有外壳顺序拆轮/轴与上下壳，拔插头、卸两侧短限位螺钉，向前抽出。头部拆前壳后卸两枚前壁螺钉，即可分离短压框/LCD；CAM和相机从开放舱口装入，采购件最终孔位与压紧方式待补齐。
4. 三个主件保持独立运动组：身体固定、Yaw杯座转动、Pitch器件舱俯仰。相对运动界面与维修盖需要分件，不能把这些面合并成一个刚体。
5. 先完成真实质量、静载与循环验证，再进行受保护的台架/实机平衡。

当前输入只有config/geometry.json与contracts/mechanical_interfaces.json。M1.2已保存在revisions/V1.2-M1.2_before_monocoque，实际同相机比较见renders/structure_comparison.jpg及structure_render_comparison.json。
