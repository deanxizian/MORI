# 每个候选打印件的作用与试打方向

当前BOM派生，方向只是候选，尚未切片或试打。采购参考件不列为打印件。

| 对象 | 作用 | 简化决定与打印提示 |
|---|---|---|
| Battery_Tray | 加宽电池托盘 / 平侧板直接限位 | Largest flat face down |
| Body_Lower | 身体下壳 | 保持球腹、轮窝与离地；局部沉孔需孔壁小样 |
| Body_Upper | 身体上壳 | 上壳承接外观与接口；原4点框架座需承载样件 |
| Coupon_Insert | 嵌件孔径阶梯试样 | 同材料配合小样，先于整件打印 |
| Coupon_Mating_Tab | 间隙试样配合片 | 同材料配合小样，先于整件打印 |
| Coupon_Plane_Fit | 平面装配间隙试样 | 同材料配合小样，先于整件打印 |
| Coupon_Wheel_Fit | 686ZZ / 双扁位配合试样 | 同材料配合小样，先于整件打印 |
| Display_Frame | 平直U形屏幕连接架 / 前面与底边齐平 | Rear planar rails on bed; review three optical seat supports |
| Dock_Pad_0 | 托架软接触垫 0 | 软接触垫，材料与压缩量待测；不混入硬壳STL |
| Dock_Pad_1 | 托架软接触垫 1 | 软接触垫，材料与压缩量待测；不混入硬壳STL |
| Dock_Pad_2 | 托架软接触垫 2 | 软接触垫，材料与压缩量待测；不混入硬壳STL |
| Dock_Pad_3 | 托架软接触垫 3 | 软接触垫，材料与压缩量待测；不混入硬壳STL |
| Drive_Bridge | 平直轮驱上座 / 锁紧柱并入侧壁 | Roof down; inspect underside pockets and bearing finish |
| Head_Front | 头前壳 / 一体相机遮光座 | 前壳一体相机遮光座，内壁哑黑处理；开口朝上/斜放由切片比较，窗口接合先试打 |

| Load_Frame | 主托板与两侧短板一体 / 平面轮廓 | Candidate: broad side face toward bed with brim; compare inverted deck orientation. Opposed PCB bosses and short side legs require limited supports; no slicing claim. |
| Motor_Retainer | 平板电机底盖 / 一体轴承鞍座 | Flat bottom on bed; verify short bearing overhang supports |
| Parking_Cradle | 独立停放 / 刷机 / 有线充电托架 | 独立维护支撑，平底向下；使用时车轮禁驱 |
| Pitch_Cradle | 等厚折角U形头托 / 后侧双斜壁 | Rear flat face down; inspect short shell lugs and transverse bores |
| Pitch_Yoke | 简洁双轴U托 / 四处舵机安装耳座 | Print side orientation requires slicer review; test insert and bearing coupons first |
| Wheel_Hub_L | 双扁位止转轮毂 L | Outer flat face down; shaft-fit coupon first |
| Wheel_Hub_R | 双扁位止转轮毂 R | Outer flat face down; shaft-fit coupon first |
| Yaw_Base | 插接Yaw承重桥 / 横向M3穿栓与一体限位 | Compare planar Y-end down with roof-down; tongue layer adhesion, bearing roundness and support removal need slicer and physical review. |
| Yaw_Reaction_Link | 可拆固定反力轴 / D形定位与舵盘夹口 | Axis vertical; keyed fit and split-clamp coupon required |
