# 每个候选打印件的作用与试打方向

当前BOM派生，方向只是候选，尚未切片或试打。采购参考件不列为打印件。

| 对象 | 作用 | 简化决定与打印提示 |
|---|---|---|
| Battery_Tray | 滑轨电池托盘 / 两侧短螺钉限位 | Largest flat face down |
| Body_Lower | 身体下壳 | 保持球腹、轮窝与离地；局部沉孔需孔壁小样 |
| Body_Upper | 身体上壳 | 上壳承接外观与接口；原4点框架座需承载样件 |
| Coupon_Insert | 嵌件孔径阶梯试样 | 同材料配合小样，先于整件打印 |
| Coupon_Mating_Tab | 间隙试样配合片 | 同材料配合小样，先于整件打印 |
| Coupon_Plane_Fit | 平面装配间隙试样 | 同材料配合小样，先于整件打印 |
| Display_Frame | 直立屏幕叉架 / 局部10°安装面 | Rear planar rails on bed; short seat overhangs need slicer review |
| Dock_Pad_0 | 托架软接触垫 0 | 软接触垫，材料与压缩量待测；不混入硬壳STL |

| Motor_Retainer | 横躺轮驱共用底盖 | Broad lower plane down |
| Parking_Cradle | 独立停放 / 刷机 / 有线充电托架 | 独立维护支撑，平底向下；使用时车轮禁驱 |
| Pitch_Cradle | 平板头托 / 直切角与短固定耳 | Rear flat face down; inspect local ears and shaft-hole bridges |

| Speaker_Mount | 外壳固定扬声器后盖 / 独立声腔 | 声腔的围壁是功能面；开口向上试打，密封与声学未测 |
