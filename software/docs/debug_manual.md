# MORI分阶段调试手册（HW-SW-0.4 / SW-0.4）

已按用户指令合并0.4软件接口，GPIO/安全门/保护阈值不变。上电前逐项核验本手册及hw_sw_0_4.md；接口测试通过不能代替下列实物前置检查。

当前全部实物步骤为 **NOT_TESTED**。这是模块台架候选，非冻结装机BOM。轮子由1:1候选皮带连接独立6 mm轮轴，电机不承载轮子；有效半径、齿数、传动弹性/摩擦/齿隙、整机质量和重心都未辨识。只有两轮主动平衡，断电/急停/严重故障会倒下；不承诺断电站立、自起或回充。支撑托架仅用于测试保护，不是运行时第三接地点。

先将用户明确提供的、已经识别的本地端口填入`MORI_PORT`；本文命令不会自动运行。当前交付没有连接设备或烧录。需要烧录时另行核对端口、板卡v1.1、供电隔离和镜像SHA，不使用`reports/compile_only/DO_NOT_FLASH_gated_coverage/`中的任何镜像。

通用记录模板在`config/hardware_test_record.template.json`。每步复制一份，填写实际命令、版本/哈希、UTC、操作者、仪器/校准、实测值与最大值、原始记录链接、停止原因和签字；没有数据保持NOT_TESTED，失败填FAIL。每一阶段都必须有上一阶段PASS证据，不能用主机测试替代。

## 0. 断电检查 — NOT_TESTED

**前置**：电池/USB/舵机支路全部隔离；机械支撑已准备，电机/头线束与轮轴可独立检查。阅读根AGENTS、params及尺寸表，确认开发板和IMU当前需外置台架，不能缩放实物硬塞。

**命令**（只操作本机文件）：

```sh
bash software/scripts/test_host.sh
python3 -m unittest discover -s software/tests -p 'test_*.py' -v
python3 software/scripts/verify_delivery.py --require-current-handoff
```

**观测/阈值**：恰好2轮电机+1位置舵机；pinmap快照逐线对照board.h；19/20及43/44保留，无35–37/启动脚误用。nSLEEP拆上拉并有硬件下拉，0.39Ω改装、外部看门狗、物理急停逻辑及回灌钳位须由硬件任务提供可检查记录。保险、BMS、匹配充电器/电池及电源反接防护未定则禁止进入出力阶段。电气连通/绝缘阈值由硬件原理图与器件规格签字后填写，软件不能编造阻值合格线。

J4/J5为自定义XH6：1绿GND、2白B原始5V、3黄A原始5V、4蓝DEVKIT_5V、5黑M2、6红M1，不是原厂排母线序；必须看针号/通断而非颜色。四条A/B先经3.3V供电的SN74LVC14AD（输入容忍5.5V）；禁止5V直入ESP32。控制left接模型R（X正），right接模型L。

**停止**：任一接线不符、装配干涉、轮壳/轮胎间隙不足、线束接触传动、缺失电源安全链。记录逐脚通断与真实照片；不改机械坐标或GPIO来凑测试。

## 1. 限流供电且电机禁用 — NOT_TESTED

**前置**：轮子悬空/机身有托架，头传动断开；功率级与平衡/头/轴四个编译门全关闭。硬件负责人先确定限流值与供电路径，确认试验电源是否可吸收回灌；未经确认不接电机母线。

USB前拔**整个J12逻辑降压模块线束，J14保持连接**，由USB经DevKit 5V/J14供编码器；USB逻辑与外部5V互斥，独立电池仅按已核验路径供电机/头。USB模式禁止Wi-Fi，逻辑含编码器电流预算<500mA，实际USB与线缆能力未测。通电后测原始A/B高电平约5V、转换后约3.3V及低电平/边沿，签字阈值以器件逻辑电平规格为准；超过MCU额定或转换器漏装立即停止。

**命令**：

```sh
python3 software/tools/mori_cli.py capture --port "$MORI_PORT" --seconds 60 --output software/reports/DEVICE_disabled.csv
python3 software/tools/mori_cli.py send --port "$MORI_PORT" --output software/reports/DEVICE_info.csv --command info --command status
```

**观测/阈值**：INFO固件SHA、IDF v5.5.2、安全门=0；ARM低、四桥输入低、头PWM无脉冲。示波器覆盖上电、复位及已授权下载过程；GPIO38为v1.1 RGB，不用GPIO48 RGB旧板。确认整段都没有非预期使能脉冲。配置8MB Flash，PSRAM目前未启用，不能据INFO断言物理板卡容量/版本已通过。

**停止**：ARM/桥/头有非预期脉冲、电源限流、异常升温或实际端口/板卡不符。记录电压、电流、波形时间范围及最大脉冲宽度（没有脉冲须保存仪器证据），然后隔离供电排查。

## 2. 单模块读数与独立舵机核验 — NOT_TESTED

**前置**：轮驱动持续禁用；I2C由控制任务独占；分别接IMU、INA、电池分压、两NTC和手转编码器。仅断电时改接线。初次头中心用独立受控舵机测试源，拆传动，记录真实中心/方向/范围后才签字开启head门。

**命令**：

```sh
python3 software/tools/mori_cli.py capture --port "$MORI_PORT" --seconds 60 --output software/reports/DEVICE_modules.csv
python3 software/tools/mori_cli.py send --port "$MORI_PORT" --output software/reports/DEVICE_calibrate.csv --command calibrate
python3 software/tools/check_mount.py software/reports/实际测量记录.json
```

**观测/阈值**：IMU地址0x6A/ID0x6C/416Hz/±2g/±500°/s配置、原始与旋转后数据；六面和前倾按direction_checks.md执行。1024个健康静止不同样本才能READY：|gyro|<0.08rad/s、|加速度模长−g|<0.35m/s²、|pitch|<3°、两轮速度<0.01m/s，偏置方差≤0.0001(rad/s)²。在轮功率禁用但逻辑供电有效时手转每个轮子，按同一起止标记累积10圈，候选期望9796.16个边沿（整数计数有边界量化），1:1齿数、有效周长及允许测量误差须记录；48 CPR已含x4，不能再乘4。

比较ADC的VMAIN电压与同节点校准万用表读数；该节点可能与VM_MOTOR隔离，不能用它声称检测所有回灌尖峰。INA有符号母线电流与参考表，不能当每绕组电流。NTC用已知电阻和温度参考校准；开短路模拟应在断电改线并确认电气安全后做。原始ADC≤9或≥4081无效；NTC分压<0.08或>3.05V无效，软件温区0–65°C。测量误差合格线须由硬件/标定记录确定，当前未填。测不到有效值、传感器轴不符、计数跳变都停止，不解锁。

头验证门通过后才发`head 0`，再`head 10`和`head -10`逐步核验；上限±50°不是可直接尝试的实测结论。有效脉宽、供电瞬态、线缆阻力和输出中心误差逐项记录；不使用FS90或连续旋转舵机代替SER0037候选。

## 3. 悬空单电机低占空 — NOT_TESTED

**前置**：上一阶段PASS；拆nSLEEP上拉/下拉、电流限制、外部心跳超时、急停/钳位等功率级检查已签字，才允许本地设置POWER_STAGE_VERIFIED；ENABLE_BALANCE仍n。轮子悬空、工具/线束远离皮带，机身保持校准姿态。方向未确认不启平衡。

**命令**（先校准并等READY，然后显式连续发送）：

```sh
python3 software/tools/mori_cli.py send --port "$MORI_PORT" --output software/reports/DEVICE_L_pulse.csv --command 'arm bench' --command 'duty 0.03 0'
python3 software/tools/mori_cli.py send --port "$MORI_PORT" --output software/reports/DEVICE_R_pulse.csv --command 'arm bench' --command 'duty 0 0.03'
```

每条arm是一次独立人工授权；不要写循环重复脉冲。需要反向时另行明确输入−0.03。3%是低占空探索命令，不保证能克服摩擦；不动不能据此宣称电机失效，也不能盲目加大。上限12%，固定授权200ms，软件提前8ms截止，duty/重复arm不续期。

**观测/阈值**：示波器真实出力≤200ms且占空≤12%；只有指定侧旋转；逻辑正输出、原始编码器计数和控制速度一致。帧计算最大≤1800us、无IMU遗漏。软件保护起点|母线电流|≤1.30A、电机NTC≤65°C，实际硬件签字上限若更严则从严。保持车体倾角<20°，异常时物理急停并接住/托住。

**停止**：方向不符、相电流/母线电流无法解释、超时、nFAULT、卡齿/摩擦/跳齿、限流/温升过快。原始观测标FAIL，禁止confirm_signs硬写通过。没有测每绕组电流时，不可宣称0.39Ω改装效果或热安全通过。

## 4. 双电机、回灌、急停与看门狗 — NOT_TESTED

**前置**：左右单轮方向PASS，功率级仍有真实支撑与可吸收/钳制回灌的路径；BMS/保险/充电安全不能靠软件替代。硬件工程师定义允许的总线峰值/钳位和关断响应。

**命令**：

```sh
python3 software/tools/mori_cli.py send --port "$MORI_PORT" --output software/reports/DEVICE_dual_pulse.csv --command 'arm bench' --command 'duty 0.03 0.03'
```

在受控低能量条件下逐项试物理急停、nFAULT、控制任务停止/复位/失去DRDY、USB拔插；每次独立记录。急停必须直接切硬件安全链，不能只发送串口命令。软件故障恢复需要明确`ack`，随后重新calibrate；ack不再出力。

**观测/阈值**：GPIO42只随健康完成帧翻转；停止控制帧就停止喂狗；ARM不绕过链路，所有复位/故障禁用。记录实际nSLEEP/轮输入关断最大延迟、母线回灌峰值、signed INA电流和仪器带宽。软件检测VMAIN>8.65V故障，但不能覆盖被隔离的VM_MOTOR尖峰。分别在VMAIN和VM_MOTOR同步示波器捕获；回灌钳位R14=25.5kΩ0.1%、R15=10kΩ0.1%、R16=2.2MΩ1%，估算开启8.73–9.04V，必须实测开启、迟滞、峰值和能量/热响应。软件阈值不是硬件峰值许可；硬件更严的绝对额定/钳位值须先填入记录。8ms IMU年龄也不是正常延迟合格线。

**停止**：任一链路不能切断、出现自动重新出力、母线超过已签字限值、供电无吸收路径或电流/温度越限。所有失效项恢复后都须重新人工解锁；不得增加软件“已确认”常量。

## 5. 台架辨识 — NOT_TESTED

**前置**：功率、关断、计数/输出符号、IMU矩阵PASS；机体有受控防摔/约束，测量仪器齐备。电机#4863、2S、电池/最终质量都仍是候选；约1.0kg仅质量预算，非称重结果。

**命令**：以阶段3的显式低占空短脉冲逐次探索，采集`DEVICE_identification_日期.csv`；必要扩大试验必须另行工程审查、接口变更及风险约束，不能突破本软件台架上限绕过许可。

**观测/阈值**：齿数、实际轮周长/转速/计数、速度—占空—母线电压关系、正反摩擦死区、皮带弹性/齿隙、真实电流（相/母线分别）、扭矩、质量、重心、惯量与热曲线。记录各试验持续时间、初末温度和最大值；没有长时数据不能判稳态/热余量。模型参数置信区间、可用扭矩/安全温升边界及闭环裕量须有人审核，目前没有预填“调好”的增益。

**停止**：保护任一触发、模型残差不能解释、所需输出持续饱和、扭矩/热余量不足。默认增益0保持；不能通过提高电流/倾倒阈值让曲线好看。

## 6. 防摔保护下平衡 — NOT_TESTED

**前置**：前五步PASS，有已审核的质量/惯量/延迟/扭矩数据与初始增益方案。四安全门按实际项目分别核验，其中平衡功能门只为此阶段明确打开；本地操作者可立即触及物理急停。托架/保护绳不得掩盖运行时仅两轮的事实。

**命令顺序**：`calibrate`→观察READY→`confirm_signs`→`gains <经审查kp kd kv ki>`→`arm balance`。不提供未辨识实机增益；尖括号占位不是可发送命令。每一条由操作者显式输入，可先用CLI `validate`检查格式，不能用测试用的任意增益充当调参结果。

**观测/阈值**：起始解锁|pitch|<3°，正常纠偏无粗暴全局斜率；差动仅剩余余量。计算/传输最大≤1800us，无正常缺样/命令溢出，持续饱和>200ms、倾倒>20°、过流/温/压、急停/nFAULT均锁存FAULT并允许倒入保护。观察`stop`后目标归零且本地平衡继续；500ms通信中断只撤销目标。任何输出符号导致倾倒放大立即急停，不现场猜改PID正负。

**停止**：任一保护、不可控振荡、接近防摔边界、机身/头部/线缆干涉、轮胎打滑、延迟异常。接住/放托架后才主动disarm；不能将成功编译或短时托住当自由平衡PASS。

## 7. 安全场地低速运动与逐项负载 — NOT_TESTED

**前置**：受保护平衡有完整真实日志/重复性证据，场地平整无人靠近运动路径，操作者有硬急停与接住/支撑方案；没有手机App/无线急停替代品。

**命令**：先`move 0.02 0`短时目标，再`stop`；测得可控后逐级增加，不自动循环或补发。孤立命令500ms后会自动撤销运动目标；持续指令必须由后续明确设计的操作者控制产生，当前工具不会替人持续刷新。转向输入单位是差动duty，不是rad/s。

**观测/阈值**：记录最大速度/俯仰、任务最大值/分位数、丢弃/遗漏、左右温度、剩余输出余量与停车距离。先无头/无屏/无无线，再分别加入屏幕、已验证头部±10°动作、最后才是使用已核验非USB逻辑供电时经授权的后台无线负载（USB台架模式始终禁Wi-Fi）；单变量比较。头误差/线缆阻力要独立测量，不能凭视觉认为不扰动平衡。

电池<6.8V告警并禁止新解锁/撤销运动目标，<6.6V请求人工支撑，<6.0V严重禁用。提前移入托架，不承诺自行停稳或回充。最终正常运行温度、续航与停止距离目前均NOT_TESTED。

**停止**：低电支撑请求、任何FAULT、场地有人进入、异常滑移/摇摆/头干涉/日志异常。托住后disarm并记录原因，不自动清故障重试。
