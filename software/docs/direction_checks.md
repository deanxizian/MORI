# 坐标、编码器与控制符号离线核验

机械坐标来自根params.json/derived.json，不建立第二套机械定义。Blender前方−Y，控制右手系x前、y左、z上：`control=(-Blender_Y, Blender_X, Blender_Z)`。控制left=Blender Wheel_R/Motor_R（X正），control right=模型L（X负）；线束按控制左右标记。**这不等于IMU原始轴的安装矩阵**。安装矩阵R在`firmware_work/firmware/main/mount_config.h`，当前identity仅未验证占位；输出及编码器符号保持交接的左+1/右−1。每次更改必须加接口变更单，重新编译并保存image SHA。

编码器DEVKIT_5V供电，原始A/B约0–5V，先经3.3V供电的SN74LVC14AD再入MCU。两路同时反相不改变相序，不能据此签字方向。USB逻辑供电须拔整个J12、保留J14，具体线序见hw_sw_0_4.md。

## 不出力的测量

1. 功率级禁用、头PWM禁用、刚性固定IMU。在六个姿态分别让控制+x/−x/+y/−y/+z/−z竖直向上，每面静止记录原始三轴加速度至少2.5秒，保留原始CSV，剔除人为晃动须有记录。上指轴的加速度计比力应约+g。检查模长与偏置，不只看pitch。
2. 求raw→control的**正交且det=+1**矩阵；反射矩阵被软件拒绝。±轴交换可以是有符号置换，斜装需要完整旋转。不得按丝印直接签字。更新配置后重复六面，不改变±2g与±500°/s换算。
3. 手扶机身向前倾：顶部朝控制+x。`pitch=atan2(-ax,az)>0`，控制gyro-y>0。手动回正反号。实际方向与理论有一处不符都停止；不能在PD符号上补错来掩盖R错误。
4. 轮驱动供电隔离、逻辑及编码器供电有效时，手动转每个独立轮轴，让接地点对应向前滚动，记录原始计数变化和带轮/电机方向。两侧应用encoder_sign后均正。48计数已含A/B全部边沿x4；精确齿比22³×23/(12×10³)，输出轴979.616计数/转。轮周长/计数=0.000304661522567m，1:1皮带仅暂定。慢速速度用8帧累计计数/实际累计时间（约19.2ms）；一计数量化约0.01584m/s，不是416Hz单帧高精度测速。
5. 功率级核验完成后才悬空单轮≤12%/≤200ms测试。正逻辑输出应使该轮向前滚动，对应的编码器速度应正。保留左右视频及原始记录；分别调整motor_sign或encoder_sign，禁止两者一起猜着改。冻结不动的编码器在静止时无法与断线区分；当前驱动>20%且速度<0.004m/s持续200ms才判异常，台架≤12%不能靠它证明编码器接线健康。

复制`config/mount_measurements.template.json`到有日期的测量记录，填写六面均值、前倾原始gyro、左右手转计数、输出观察和操作人/原始文件/固件SHA。运行：

```sh
python3 software/tools/check_mount.py software/reports/实际测量记录.json
```

该工具只检查数值一致性（六面向量误差暂取≤0.35m/s²，手动gyro-y>0.05rad/s、交叉轴<25%）；不判定真实仪器来源，不写固件，不自动开启axes或signs。上述容差是软件核验起点，须与实际传感器标定协调。记录仍须人审，随后才允许设置axes验证门及显式confirm_signs。

## 唯一输出结构

速度目标先限加速度0.2m/s²；慢速速度误差`ve=v_ref−(vL+vR)/2`经小增益和积分生成限幅±5°的theta_ref。姿态PD是唯一公共力矩：

`u_raw=kp*(pitch−theta_ref)+kd*(gyro_y−bias)`。

公共输出限制±0.65，差动只能使用`0.65−|u|`的剩余余量，`uL=u−yaw, uR=u+yaw`。yaw输入是占空比分量，目标斜率0.4 duty/s；公共姿态纠偏无全局慢斜率。没有另一路轮速PID叠加。积分在输出/倾角饱和时冻结并限幅；持续饱和会锁存故障。增益默认0，协议的允许范围是拒绝异常输入的边界，不是调参建议。

物理符号推理：小角倒立摆有`theta_ddot≈g/l*theta−a_wheel/l`。正前倾需要轮子向前加速，将接地点追到重心下面；反向输出会放大倾倒。正速度误差要求正倾角参考，直立时初始负力矩使轮子后移以建立前倾，随后姿态反馈追上。`tools/check_control_signs.py`用假设长度0.15m只验证这个符号关系，**没有使用真实MORI质量/惯量，也没有证明闭环稳定或调好增益**。

头部外啮合8:14，名义舵机角=−1.75×头角，pulse=1500−12.962963×头角(us)。±50°软件初限约852–2148us，仅名义映射；初次中心/方向/可用范围必须拆传动用独立受控测试源核验并签字。未核验固件保持无PWM，不能为了找中绕过head门。装回传动从±10°开始，逐步检查线缆、齿隙、阻力，不假定壳体±60°机械目标已经可用。
