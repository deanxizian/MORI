# 实时性边界与测量（SW-0.4）

所有器件/电机/硬件时序证据：**NOT_TESTED**。`SIMULATED_*.csv` 中500 us采样开销、20 us提交开销是模拟HAL的输入常数，不是ESP32测量。主机编译耗时也不是控制计算耗时。

## 周期与预算

姿态DRDY 416 Hz，名义周期1/416 = 2.403846 ms（抖动统计用整数2404 us）。计算+传输目标≤1800 us；约604 us余量不能全部当作可用调度延迟。8 ms缺样等待和样本年龄阈值只作严重失效后备。已解锁帧间隔不在1–6 ms内会锁存TIMING；它也不是正常抖动的合格范围。满足计算预算仍不证明闭环相位裕量。

|---|---|---|---|
| IMU采样及器件滤波群延迟 | 受ODR/内部滤波/同步影响；台架施加已知运动并用参考测量 | null | NOT_TESTED |
| DRDY到任务唤醒 | GPIO16 ISR时间戳 → 帧开始；wake_us及max_wake_us | null | NOT_TESTED |

400 kHz I2C的线速分析（不是测量）：状态读约4字节×9位=90 us；12字节读约15×9位=337.5 us；INA两字节读约5×9位=112.5 us。IMU合计约427.5 us；监测帧再增加约112.5 us及ADC/软件开销。这不包含START/STOP间隔、器件时钟拉伸、调度或驱动等待；故障时1 ms API超时可以被多次事务累加，最终1800 us预算会禁用。停止执行的CPU只能由外部看门狗/急停切断，不能由这段代码自证安全。

PWM20 kHz周期50 us。ESP-IDF本地LEDC头文件说明update不是同周期立即生效；不能把`pwm_submit_us`当作物理延迟。初次驱动唤醒保留2 ms等待。台架授权deadline固定在arm后200 ms，软件提前8 ms截止以保留正常帧间隔/提交余量；仍须测得所有启动/中断/故障情况下最大真实通电时长≤200 ms。

## 任务和数据所有权

- 核1优先级23 `balance_io`：独占I2C，包括初始化、IMU和INA；读取PCNT及ADC，执行控制。没有运行时malloc/printf。IDF I2C/ADC/PCNT/LEDC错误日志在初始化后静音，错误经状态/遥测报告。底层同步I2C调用使用栈上的操作数组（本地IDF v5.5.2源码已查）。短临界区只交换ISR时间戳和故障位。LEDC的四路轮驱动同步更新在motor_init禁用阶段逐路调用，预建内部fade记录/同步对象，避免首次控制提交才分配；提交错误锁存driver失效并保持ARM低。
- 核0 console优先级3：严格解析，SPSC命令队列容量8，不直接写控制状态；每帧最多处理2条。满队列锁存FAULT，撤销待处理请求。RT回复队列32，满队列同样故障；解析错误回复队列16，满时计数。
- 核0 logger优先级2：遥测队列16，发送不等待控制；每40帧及状态变化尝试快照，丢弃计数明确。115200波特不能承载416 Hz全量文本。日志队列满不阻塞控制。
- 核0 head优先级2：约20 ms轨迹更新；目标通过覆盖队列传递。陈旧>50 ms或自身间隔>100 ms时停PWM，相同目标revision不得自行恢复，需新显式head命令。真实停PWM延迟受调度影响，NOT_TESTED。急停对轮驱动必须有物理链；舵机5V故障隔离由硬件决定。
- 核0 display优先级1：SPI DMA每块240×8×2=3840字节，最多两笔队列，每块等DMA完成后复用缓冲。渲染分辨率独立，GC9A01适配仅240×240 SPI。无控制锁、无I2C调用；DMA内存只在任务初始化分配。
- Wi-Fi没有初始化。USB台架模式始终禁止Wi-Fi；后续无线测试必须采用已核验的非USB逻辑供电，单独加入后台低优先级负载，不能绕过本地解锁或替代硬件急停。

## 统计口径

CSV回放给出已记录行的p50/p95/p99/max（nearest-rank）。`max_*`由设备每帧维护，不因串口抽样漏峰；复位后重新计数。三套全帧直方图统计run/wake/jitter，100 us一桶，`*_upper_us`为桶上界，4294967295表示>3200 us。为将统计自身计入预算，直方图在下一帧开始收录前一已完成帧；快照所指的完成帧已入桶。不是精确微秒分位数，不能与抽样分位数混称。

run_us边界到最后一次时钟读取；其后少量赋值与心跳GPIO写入的尾部开销需外部捕获计入总延迟。完整数据通路的最坏延迟 = 器件采样/滤波 + 唤醒 + 传输/融合/控制 + PWM实际锁存 + 电机/皮带响应；当前仅预置CPU和总线钩子，没有填造总延迟。

`sample_missed`记录通知合并造成的缺样（events−1）和等待超时；`log_dropped`是设备遥测队列满，`command_overflows`、`reply_dropped`分别为命令与回复丢弃。主机按INFO中的stride估算缺失遥测行并另数复位/时间回退；状态变化可产生额外行，所以该缺失数仅为估计。坏行单独计数并保留原文。串口ACK RTT只表示往返排队/传输耗时，不是单向控制延迟。

## 实测记录要求

先禁用功率级采至少60 s基线，再依次加入屏幕、头部（已验证）、控制台洪泛、日志阻塞、候选无线负载，最后才进行受保护出力。每个组合保存固件SHA、配置、端口、UTC、原始JSONL/CSV、仪器型号/采样率/探头点、所有最大值、分位数和计数增量。计算+传输任一帧>1800 us、正常运行任何IMU遗漏、心跳不随控制失健康而停止，均FAIL并禁止继续平衡；其他抖动容许值须根据辨识和相位裕量明确签字，当前NOT_TESTED。

电压测量边界：ADC采样节点为VMAIN，监测周期约8帧不能捕获全部瞬态，且与VM_MOTOR可能隔离。软件过压8.65V保持不变；回灌峰值、钳位开启/迟滞与能量耗散须在VM_MOTOR用示波器验证，不能用ADC日志最大值替代。所有当前硬件时序最大值保持null / NOT_TESTED。
