# 历史资料索引

当前设计看 [M1.52 状态](CURRENT_STATUS.md)，以下目录用于追溯。`before_*` 表示改动前保存的快照；目录名称不代表该方案已采用。旧版本尺寸、接口及 PASS 不能覆盖当前合同。

| 历史范围 | 入口与边界 |
|---|---|
| 归档前首页 | [原 README](archive/README_before_2026-10-06.md)，保留其旧内容和原路径文字，链接以原项目根目录为基准 |
| A0 初始机械 | 根目录 params.json、scripts/、models/、renders/、exports/，不定义 V1.2 |
| V1 旧硬件 | [hardware/v1](../hardware/v1/)，不作为当前接线依据 |
| 旧软件台架 | [software/README](../software/README.md)，HW-SW-0.4／A0 历史 |
| V1.2 PCB 修订 | [hardware/v1_2/kicad](../hardware/v1_2/kicad/)，当前版本以硬件首页列出的四板为准 |
| 机械研究与候选 | [mechanical/studies](../mechanical/studies/)，包含成功、失败和未采用方案 |

历史脚本、参数与较小报告保留在 Git 中；旧模型、重复图片、视频和大型计算数据保留本地，未全部上传。详见 [归档范围](GITHUB_ARCHIVE.md)。
