# V1.2 实时性与测量

S288单包：20字节命令+26字节反馈，8N1共460线比特，6Mbps理论净线时76.667us；两轮最低153.333us。这**不含**转向保护时间、执行器处理、DMA/中断、重试或同步偏差，不是测量值。

`mori_uart_divider`按STM32F4 OVER8求BRR，48MHz→0x10、96MHz→0x20可得到名义6Mbps；50MHz近似除8为6.25Mbps（4.167%），1000ppm预算拒绝；复位HSI16MHz不能得到6Mbps。本构建未打开PLL/UART，候选96MHz在硬件契约仍ASSUMED_NOT_IMPLEMENTED。名义整除不能证明晶振精度、边沿、反射、收发器延迟或长线可靠性。

`mori_bus`单次交易从TX_DMA→WAIT_TC→RX，有一个绝对deadline；DMA完成仍保持TX，TC才释放。每轮每周期一次、无实时路径重试；一轮超时轮换到另一轮并计数，不无限阻塞。控制必须同时检查左右年龄、偏差和反馈错误/timeout标志。一个结构正确的CRC包不代表执行器健康。

`timing.h/c`接受单调us显式打点：DRDY、调度唤醒、SPI完成、融合完成、控制完成、最后轮UART TC。维护每段last/max、100us宽32桶直方图、周期max、丢弃计数；最后一桶>=3100us。桶不能冒充精确p99，原始记录在非实时任务中导出。时间逆序/缺段无效，不静默填零。所有函数无堆分配、打印或锁等待。身体IMU矩阵det必须+1，采样时间来自DRDY锁存，不用网络到达时刻。

旧A0的416Hz/1.8ms预算保留在旧报告，不能当新ICM/S288实测或确定设计参数。新控制阈值必须按稳定性/总延迟辨识确定并进入参数版本。严重IMU超时只做故障后备，不是正常预算。

外部心跳只由 `mori_motion_step` 健康完成帧翻转逻辑状态；尚未映射GPIO。禁止独立PWM/定时器自动喂狗。实际端口应在全帧输出事务完成且再次核验年龄后提交心跳；故障先请求已核验的硬件禁驱，不能依赖失效CPU发送某种舵机包。

交互域 RGB565360×360帧缓冲259200字节，启动时一次分配PSRAM；QSPI最大16行条带11520字节、单项队列，DMA回调前不复用。当前API要求调用者提供已核验内部DMA缓冲，主循环未启用物理提交。40MHz/四数据线理想裸像素传输12.96ms只是理论值；仍需命令开销/PSRAM/并发/帧年龄/最小堆实测，不能据此保证帧率。
