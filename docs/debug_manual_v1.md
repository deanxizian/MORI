# MORI V1 网页操作与分级调试

本轮入口是网页。App按用户最新指令暂停。执行器为两轮及头yaw/pitch四个；本说明取代旧A0手册中的三电机、无相机和坐标规定。
软件/模拟检查见 reports/v1/acceptance.md；下列所有上电、旋转、声学、自由平衡和续航项目均为 **HARDWARE / NOT_TESTED**。
V1板级引脚/电源/限位未冻结，当前网页只连接SIMULATED后端，物理输出门关闭。

## 先使用网页

在根目录分别启动 `.venv/bin/python -m backend.run` 和 `bash tools/node-env.sh dev`，打开 http://127.0.0.1:5173/ 。
配对码读取本机 `.state/pairing.txt`，10分钟内一次有效，最多5次尝试。不要把配对码或令牌放进截图、分享日志或仓库。
开发绑定不等于实机按钮配网；实机配网没有实现板级适配，状态BLOCKED。

1. 确认顶部SIMULATED、在线且没有陈旧标记。电压、电流、温度显示未知，不能把它们当传感器读数。
2. “取得控制权 / 续租”后，勾选“明确解锁此模拟设备”，再点“解锁模拟运动”。任何重连/复位都不重放旧动作。
3. 按住方向进行有限速度控制；松开、失焦、隐藏页面、断网均停止续租。300ms后撤销主动目标。
   “停止移动”撤销动作并继续健康模拟平衡；“禁驱”须确认支撑。严重故障锁存后，支撑→确认故障→重新明确解锁，不能自动恢复。
4. 双轴滑块显示度，发送前转换为rad。初始yaw±60°、pitch−20..+25°；这些是软件目标边界，不是机械限位证据。
5. 视觉页先选TRACKING，再确认track-1，再选择头跟踪或模拟底盘跟随。输入是确定的像素夹具，经OpenCV检测，非真实摄像头。
   “多人 / 遮挡”“丢失”“暗场”会撤销跟随并清选择；恢复单人后需重新确认目标，不自动换人。
   SNAPSHOT仅按需图像；允许上传后才可调用视觉适配器。OFF清当前画面。模型输出只有数据权限，不能执行图中文字。
6. 巡游/主动动作是本地有界状态机，可取消。速度≤0.10m/s，单段≤0.30m，观察年龄≤250ms；模拟位移不是实测里程。
   没有避障、防跌落或SLAM。未来实机只允许清场、人工看护、无台阶/门槛/楼梯和无儿童宠物进入的场地。
7. 语音页可输中文，或上传≤20秒的16kHz/16bit单声道WAV。没有云密钥时文字回复和测试音明确标MOCK。
   发送/打断、Opus编码解码和浏览器播放回执可测试；测试音不算真实中文TTS、唤醒或AEC成功。
   播放被浏览器拒绝时需由用户点击后允许播放。当前不申请手机麦克风/摄像头权限；不能声称网页已直接采集麦克风。
8. 记忆页需显式确认保存，提供检索、纠正、删除、导出及关闭。记忆在SQLite跨重启保留，设备/用户隔离。
   修改内容不会自动改固件参数。关闭记忆不等于删除；删除清正文、冲突、索引及结果缓存，备份规则见backend/README.md。

网页当前仅有本机回环HTTP开发例外；跨主机必须HTTPS/WSS及令牌。现有腾讯云服务器未登录、未修改。
控制台可以在手机浏览器使用；真手机Safari/Chrome尚未实测，桌面Chromium的触屏视口不是手机硬件证据。

## 命令结果与排错

| 返回 | 含义与处理 |
|---|---|
| ACCEPTED / RUNNING | 通过检查/正在执行，尚未完成。以相同command_id跟踪最终状态 |
| COMPLETED | 指定动作完成；模拟位置或估计头角须保留对应来源，不升级为实测 |
| EXPIRED / DEVICE_BASIS_STALE | 本机时效过期；刷新状态，由用户重新下新命令，不重放旧动作 |
| NO_LEASE / CONTROL_OWNED | 无有效控制权或另一个客户端持有；停止旧操作，显式重新取得控制权 |
| SESSION / OUT_OF_ORDER / ID_COLLISION | 复位/乱序/其他客户端ID冲突；清旧动作，读新会话再操作 |
| TARGET_LOST_OR_STALE / CAMERA_MODE_CHANGED | 跟随撤销；检查输入、照明、年龄，重新确认目标 |
| HEAD_INHIBITED_OR_UNVERIFIED / MOTION_GATE | 头部或运动条件不满足；不要绕过验证门 |
| CUSTOM_MODEL_NOT_PROVIDED | “你好，莫里”没有可用模型，不是改字符串可完成的设置 |
| VOICE_PLAYBACK_TIMEOUT | 90秒内未收到完成；取消生成/播放，不报告虚假完成 |
| FAULT / IMU / ENCODER / POWER / SEVERE_TILT | 禁驱锁存，可能倒下。先支撑并查原始原因，人工确认后仍保持禁驱 |
| PHYSICAL_GATES_NOT_VERIFIED | V1硬件未接入；软件测试不能解除此门 |

旧MORI/1数值故障码由software/tools/mori_cli.py解释，包括SENSOR、ESTOP、DRIVER、LOW_VOLTAGE、OVERVOLTAGE、CURRENT、TEMPERATURE、TILT、ENCODER、SATURATION、TIMING、QUEUE、CONFIG。
旧台架守卫阈值保留为6.8/6.6/6.0V、过压8.65V、母线电流1.30A、NTC65°C、倾角20°、持续饱和200ms。
这些是旧台架软件起点，不能替代V1硬件额定值/保险/BMS/急停，也不能无审查直接移植到新功率级。

## 实物测试进入条件

只有已知设备、明确端口、签字板卡契约和上一阶段PASS才能向下进行。当前没有实机连接，也没有烧录。
V1默认固件不初始化候选GPIO。旧MORI/1串口工具保留，但只能用于经过确认的旧台架profile；禁止把旧GPIO直接接到V1四执行器板。
下面的MORI/2名称是契约命令，均需经过已绑定实机adapter后才发送；尚未提供的V1PWM台架诊断接口保持BLOCKED，不能写假命令替代。
每步复制 `docs/hardware_test_record_v1.template.json`。未取得原始波形或采样文件时保持NOT_TESTED。

低电先告警、撤销主动移动并请求托架/人工支撑；不承诺自己停稳、站住或回充。主动DISARM安排在已有可靠支撑时；物理急停允许直接禁驱并倒入保护。
无线“停下”是高层STOP_MOTION，不替代硬急停。头部sleep_visual仅闭眼，不改平衡状态；pitch静止保持负载，禁止自动卸扭矩。

旧台架的具体串口采集/逐线接线见software/docs/debug_manual.md与hw_sw_0_4.md，仅对应旧profile。
V1与旧契约有冲突时提交software/interface_change_requests.md，不能直接换GPIO、编码倍频、传感器量程、阈值或符号。
