## 软件与制造状态

2026-10-07 的 F412RE 交叉编译和软件回归记录见 [审查复核](REVIEW_CLOSURE.md)。这些是编译／主机证据，真实时钟、GPIO、总线和控制端口仍待接通；旧 F413 验收不能代表当前 P5R7 的实机验证。本次机械 PR 没有重跑软件验收。

`PASS` 只针对记录中的具体检查；`FAIL` 表示该检查未通过；`NOT_TESTED` 表示未执行；`BLOCKED` 表示缺少输入或仍有未解决事项；`NOT_APPLICABLE` 表示不适用。整机保持 **PROTOTYPE / UNVALIDATED**，`manufacturing_release=false`。
