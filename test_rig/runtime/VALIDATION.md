## 0.1.11 审查修复（仅离线，尚未部署）

PR #20 的自动审查发现两项问题，已用模拟设备在 0.1.10 重现：

- 停止确认期间的一次通信超时或过温，可能被后续正常、静止反馈掩盖，
  从而错误允许运动恢复。0.1.11 保留停止异常计数、首次异常和有界末段，
  无论最终禁能/静止是否确认，均阻止重新使能；正常停止请求也不能清除该故障。
- 每轮遥测回调与控制器相互引用；循环 GC 暂停时，重复恢复会保留旧控制器
  及整份报告。0.1.11 在每轮退出的 finally 中移除回调，包含异常退出路径。

新增回归覆盖双轮、停止过渡/确认、短暂超时/过温/警告、延长停稳等待拒绝、
故障跨启动保留，以及 GC 关闭下五轮控制器的释放。实车仍为 0.1.10；
上述现场确认不能转为 0.1.11 的实物结果。行驶参数与主动保护阈值未调整。
Mac/Python 3.12 的 77 项跨平台测试通过，完整 79 项（含 Linux 管道测试）
纳入 PR 的 Ubuntu CI；运行源码清单已按 0.1.11 重新生成并校验。
