# 输入资料与来源

本轮仅收到用户的中文文字需求，已存档为 `user_brief_zh.txt`。没有收到整机参考图、爆炸图、供应商 CAD、尺寸图或器件数据表，因此未做参考图片对照。

所有执行器、电池、PCB、连接器、轴承与传动尺寸均是本项目明确声明的 **PLACEHOLDER / 待选型包络**；不得引用为任何真实型号的参数。没有编造扭矩、电流、质量、供电能力或孔距来源。

软件：本机 Blender 5.2.1 LTS，Python 3.13；Blender 内置 bpy/bmesh/mathutils/numpy；Manifold 3.5.3 三角实体布尔库由 pip 实际安装。其许可证与包元数据随 `scripts/vendor/manifold3d-3.5.3.dist-info/` 保留。渲染全部来自 bpy 创建的同一套模型，无图像生成工具介入。
